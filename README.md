## 📌 สถานะล่าสุด (ทิศทางหลัง feedback อาจารย์)
- 🎯 **โฟกัสใหม่:** "ติวเตอร์เตรียมสอบ **HSK** สำหรับคนไทย" (เริ่ม HSK 1–2)
- 🎓 **เป้าหมายของระบบ:** จากคนไม่มีพื้นฐาน → ระดับที่สอบ HSK 1 ผ่านได้ (แผนเรียน ~8 สัปดาห์)
- 📊 **สิ่งที่โครงงานพิสูจน์ได้:** gain score จาก pre/post mock (ทดลอง 5–10 คน ~10 วัน) + AUC/ablation — รายงานเป็นแนวโน้มคะแนน ไม่ใช่ข้อสรุปว่าสอบผ่าน
- ✅ **จุดต่างที่ยืนยันแล้ว:** วินิจฉัยจุดผิดตามภาษาแม่ไทย (Thai-L1) + Knowledge Tracing — ไม่มีคู่แข่งรายใดทำ
- ✂️ **ตัด/เลื่อน (future work):** ออกเสียงละเอียด, AI สนทนาเต็มรูป, กล้อง OCR, ซับซีรีส์
