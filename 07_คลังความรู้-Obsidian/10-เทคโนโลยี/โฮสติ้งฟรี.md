# โฮสติ้งฟรี

**คืออะไร:** ชุดบริการโฮสต์ฟรี (ยืนยันเงื่อนไขปี 2026 แล้ว) ที่ทำให้จีนรู้ใจรันได้จริงด้วย **งบ 0 บาท** — deploy อัตโนมัติผ่าน `git push` ทั้งชุด

## สถาปัตยกรรม

```
Next.js PWA (Vercel/CF Pages) → FastAPI (HF Spaces) → Supabase
   ออฟไลน์: Dexie/IndexedDB       pyBKT·FSRS·jieba      Postgres+Auth
```

## ชุดที่เลือก (3 ชิ้น)

| ชั้น | บริการ | เงื่อนไขฟรีที่ต้องรู้ |
|---|---|---|
| เว็บ (frontend) | **Vercel** หรือ **Cloudflare Pages** | โฮสต์ [[Next.js-PWA]] · push ขึ้น GitHub แล้ว deploy เอง |
| Backend ML | **Hugging Face Spaces** | รัน [[FastAPI]] เป็น Docker container · **RAM 16GB** (พอสำหรับ [[pyBKT]] + pandas สบาย ๆ) |
| ฐานข้อมูล | **Supabase** | PostgreSQL ฟรี 500MB + Auth 50k MAU (ดู [[Supabase]]) |

## เรื่อง "หลับ" — จุดที่ต้องระวังก่อนเดโม

- **HF Spaces:** ไม่มีคนเรียก **48 ชม. → หลับ** แต่**ข้อมูล/แอปไม่หาย** ปลุกได้เมื่อมี request (แค่ตื่นช้าครั้งแรก) → ตั้ง **keep-alive ping ก่อนวันเดโม/นำเสนอ** กันหน้าแตก
- **Supabase:** ไม่มี query **7 วัน → โปรเจกต์ pause** → cron ping ไว้เช่นกัน

## ❌ ห้ามใช้ (เช็กแล้วปี 2026)

| บริการ | ทำไมไม่เอา |
|---|---|
| Render free | RAM แค่ **512MB** — รัน pyBKT/pandas ไม่ไหว |
| Fly.io | เลิกให้ tier ฟรีแล้ว |
| Railway | เลิกให้ tier ฟรีแล้ว |
| Koyeb | เลิกให้ tier ฟรีแล้ว |

บทเรียน: บทความ "โฮสต์ฟรี" เก่า ๆ ในเน็ตเชื่อไม่ได้แล้ว — เงื่อนไขฟรีเปลี่ยนเร็วมาก ต้องเช็กปีปัจจุบันเสมอ (กติกาทีม: อย่าเดา ตรวจก่อนอ้าง)

## วิธี deploy

1. push โค้ดขึ้น GitHub repo ของทีม
2. Vercel/CF Pages + HF Spaces ผูกกับ repo → build อัตโนมัติทุกครั้งที่ push
3. API key / secret ทั้งหมดใส่ env ของแต่ละบริการ — **ห้าม commit `.env`** (มี `.gitignore` กันแล้ว)

## เกี่ยวข้องกับ

- [[Next.js-PWA]] — ตัวเว็บที่ขึ้น Vercel/Cloudflare Pages
- [[FastAPI]] — backend ที่ขึ้น HF Spaces (Docker)
- [[Supabase]] — DB + Auth (รายละเอียดโควตาฟรี)
- [[pyBKT]] · [[FSRS]] — งาน ML ที่ทำให้ต้องการ RAM มากกว่า 512MB
- [[NLP-จีน-และเสียง]] — jieba/pypinyin/edge-tts รันบน backend ตัวเดียวกัน
