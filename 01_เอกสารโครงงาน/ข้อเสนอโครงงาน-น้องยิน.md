## 1.1 ที่มาและความสำคัญของปัญหา

ในปัจจุบันภาษาจีนกลาง (Mandarin) ได้กลายเป็นภาษาต่างประเทศที่มีความสำคัญลำดับต้น ๆ ของประเทศไทย โดยมีจำนวนผู้เรียนเพิ่มขึ้นอย่างต่อเนื่อง ทั้งในระดับมัธยมศึกษา อุดมศึกษา และกลุ่มคนทำงาน อีกทั้งการสอบวัดระดับความรู้ภาษาจีน (HSK: Hanyu Shuiping Kaoshi) ยังถูกใช้เป็นเกณฑ์มาตรฐานในการศึกษาต่อและการทำงานอย่างแพร่หลาย ความต้องการเครื่องมือช่วยเรียนภาษาจีนที่มีประสิทธิภาพจึงเพิ่มสูงขึ้นตามไปด้วย

อย่างไรก็ตาม วิธีการเรียนและแอปพลิเคชันที่มีอยู่ในตลาดส่วนใหญ่ยังมีข้อจำกัดสำคัญ กล่าวคือ มุ่งเน้นการ "ท่องจำคำศัพท์" (recognition) ซึ่งซ้ำซากและน่าเบื่อ แต่ไม่ได้ฝึก "การนำไปใช้จริง" (production) เช่น การออกเสียงและการแต่งประโยค นอกจากนี้แอปพลิเคชันระดับสากลยังออกแบบบทเรียนแบบ "เหมือนกันสำหรับผู้เรียนทุกชาติ" โดยไม่คำนึงว่าผู้เรียนมีภาษาแม่ (First Language: L1) ใด ทั้งที่ในทางภาษาศาสตร์ ภาษาแม่เป็นตัวกำหนดรูปแบบความผิดพลาดของผู้เรียนอย่างมีนัยสำคัญ (L1 transfer / language interference)

สำหรับผู้เรียนชาวไทย ความท้าทายมีลักษณะเฉพาะที่แตกต่างจากผู้เรียนชาติอื่น แม้ภาษาไทยจะเป็นภาษาที่มีวรรณยุกต์ทำให้คนไทย "ฟัง" วรรณยุกต์จีนได้ค่อนข้างดี แต่กลับมีปัญหาในการ "ออกเสียง/ผลิตเสียง" วรรณยุกต์ให้ถูกต้อง โดยมักนำระบบเสียงของภาษาไทยมาแทน (เช่น ความสับสนระหว่างเสียงที่ 2 กับเสียงที่ 3 การลากเสียงที่ 4 ยาวเกินไป) รวมถึงเสียงม้วนลิ้น zh/ch/sh ที่ไม่มีในภาษาไทย และความผิดเชิงไวยากรณ์ที่เกิดจากการถ่ายโอนโครงสร้างประโยคแบบไทย ปัญหาเฉพาะกลุ่มเหล่านี้แทบไม่มีแอปพลิเคชันใดในตลาดนำมาวิเคราะห์และแก้ไขอย่างเป็นระบบ แม้แต่แอปที่มีหน้าจอภาษาไทยก็เพียงแปลส่วนติดต่อผู้ใช้ แต่ไม่ได้ปรับ "วิธีการสอน" ให้เหมาะกับจุดอ่อนของคนไทย

ด้วยเหตุนี้ คณะผู้จัดทำจึงเสนอพัฒนาระบบติวเตอร์ภาษาจีน "น้องยิน (Nong Yin)" ที่นำแนวคิดการสร้างแบบจำลองผู้เรียน (Learner Model) มาประยุกต์ใช้ โดยอาศัยทฤษฎีและเทคนิคที่ได้รับการยอมรับทางวิชาการ ได้แก่ การติดตามความรู้ของผู้เรียน (Knowledge Tracing) เพื่อประเมิน "ความแม่นยำรายทักษะ" ของผู้เรียนแต่ละคน การทบทวนแบบเว้นช่วง (Spaced Repetition) เพื่อจัดตารางทบทวนให้ผู้เรียนทบทวนคำในจังหวะที่กำลังจะลืมพอดี และการวิเคราะห์เปรียบต่าง (Contrastive Analysis) ระหว่างภาษาไทยกับภาษาจีน เพื่อวินิจฉัยและแก้ไขความผิดพลาดที่เกิดเฉพาะกับผู้เรียนชาวไทย ระบบนี้จึงไม่ใช่เพียงแอปพลิเคชันท่องศัพท์ทั่วไป แต่เป็นระบบที่ "เรียนรู้ตัวผู้เรียน รู้ว่าผู้เรียนอ่อนตรงไหน และปรับการสอนให้เฉพาะบุคคล" ซึ่งสามารถประเมินผลได้ในเชิงวิทยาศาสตร์

## 1.2 วัตถุประสงค์

1.2.1 เพื่อพัฒนาระบบติวเตอร์ภาษาจีนในรูปแบบเว็บแอปพลิเคชัน (Progressive Web App) สำหรับผู้เรียนชาวไทยที่สามารถใช้งานได้แม้ในสภาวะออฟไลน์

1.2.2 เพื่อพัฒนาแบบจำลองผู้เรียน (Learner Model) ที่ติดตามและประเมินความแม่นยำรายทักษะ (per-skill mastery) ของผู้เรียนแต่ละคนด้วยเทคนิค Knowledge Tracing

1.2.3 เพื่อพัฒนาคลังวินิจฉัยความผิดพลาดเฉพาะผู้เรียนชาวไทย (Thai-L1 Error Catalog) ครอบคลุมด้านวรรณยุกต์ การออกเสียง และไวยากรณ์ โดยอาศัยหลักการวิเคราะห์เปรียบต่างไทย-จีน

1.2.4 เพื่อนำอัลกอริทึมการทบทวนแบบเว้นช่วง (Free Spaced Repetition Scheduler: FSRS) มาจัดตารางทบทวนเฉพาะบุคคล ให้มีประสิทธิภาพดีกว่าการทบทวนด้วยตารางคงที่

1.2.5 เพื่อพัฒนาฟีเจอร์เชิงโต้ตอบที่ขับเคลื่อนด้วยปัญญาประดิษฐ์ (LLM) ซึ่งทำงานร่วมกับแบบจำลองผู้เรียน ได้แก่ การสร้างแบบฝึก/ตัวอย่างเฉพาะบุคคล และคู่สนทนาภาษาจีนที่ปรับเนื้อหาตามจุดอ่อนของผู้เรียนแต่ละคน

1.2.6 เพื่อประเมินผลเชิงทดลองว่าระบบสามารถช่วยให้ผู้เรียนชาวไทยจดจำคำศัพท์และพัฒนาทักษะภาษาจีนได้ดีขึ้นจริง โดยวัดด้วยตัวชี้วัดมาตรฐาน (เช่น ความแม่นยำในการทำนาย และอัตราการจดจำเมื่อเทียบกับวิธีพื้นฐาน รวมถึงการเปรียบเทียบแบบจำลอง BKT กับ Deep Knowledge Tracing)

## 1.3 ฮาร์ดแวร์ ซอฟต์แวร์ เครื่องมือ และเทคโนโลยีที่ใช้ในการศึกษา

### 1.3.1 ฮาร์ดแวร์ (Hardware)
- เครื่องคอมพิวเตอร์โน้ตบุ๊ก (Notebook Computer) จำนวน 2 เครื่อง — [ระบุรุ่น]
- ไมโครโฟน/หูฟัง สำหรับฟังและฝึกออกเสียง

### 1.3.2 ภาษาและฐานข้อมูลที่ใช้ในการพัฒนา (Programming Languages & Database)
- Python — ภาษาหลักของส่วนประมวลผล (learner model, การวินิจฉัย, การจัดตาราง)
- TypeScript / JavaScript — สำหรับส่วนติดต่อผู้ใช้ (เว็บ/PWA)
- SQL — จัดการฐานข้อมูล โดยใช้ SQLite (ระยะต้นแบบ) และ/หรือ PostgreSQL (Supabase) เมื่อขยายระบบ

### 1.3.3 เฟรมเวิร์กและไลบรารีหลัก (Frameworks & Core Libraries)
- React / Next.js — สร้างส่วนติดต่อผู้ใช้แบบ Progressive Web App รองรับการใช้งานออฟไลน์
- FastAPI (Python) — พัฒนาส่วนหลังบ้าน (Engine แยกเป็นบริการ ใช้ร่วมกับหลายช่องทางได้)
- py-fsrs — ไลบรารีจัดตารางทบทวนแบบเว้นช่วง (FSRS)
- pyBKT — ไลบรารี Bayesian Knowledge Tracing สำหรับประเมินความแม่นยำรายทักษะ (mastery)
- jieba — ตัดคำภาษาจีน (Chinese Word Segmentation)
- pypinyin — แปลงอักษรจีนเป็นพินอินพร้อมวรรณยุกต์
- makemeahanzi — ข้อมูลแยกส่วนประกอบอักษรจีน (สำหรับวิเคราะห์จุดอ่อนระดับอักษร)
- edge-tts / MeloTTS — สังเคราะห์เสียงอ่านภาษาจีน (ฟรี) สำหรับสื่อการฟังและการฝึก

### 1.3.4 บริการปัญญาประดิษฐ์ (AI Services)
- โมเดลภาษาขนาดใหญ่ (LLM) เช่น Google Gemini หรือ Typhoon — ใช้แบบไม่เก็บสถานะ (stateless) เพื่ออธิบายความหมาย/ไวยากรณ์เป็นภาษาไทย ให้ข้อเสนอแนะต่อประโยคที่ผู้เรียนแต่ง และสร้างตัวอย่างประโยค (ออกแบบให้สลับผู้ให้บริการได้)

### 1.3.5 เครื่องมือพัฒนาและทดสอบ (Development & Testing Tools)
- Visual Studio Code — โปรแกรมเขียนโค้ด
- Git และ GitHub — ระบบควบคุมเวอร์ชันและจัดเก็บซอร์สโค้ดบนคลาวด์
- Node.js และ npm — จัดการแพ็กเกจและรันสคริปต์
- ชุดข้อมูลคำศัพท์ HSK 3.0 (โอเพนซอร์ส) — ใช้เป็นคลังคำศัพท์ตั้งต้น

## 1.4 วิธีการศึกษา

การพัฒนาโครงงานใช้กระบวนการแบบเป็นลำดับขั้นและทำซ้ำเป็นรอบ (Iterative) ควบคู่กับการทดสอบกับผู้เรียนจริงและการรับข้อเสนอแนะจากอาจารย์ที่ปรึกษาเป็นระยะ โดยมีขั้นตอนดังนี้

1.4.1 ศึกษาทฤษฎีและงานวิจัยที่เกี่ยวข้อง ได้แก่ การทบทวนแบบเว้นช่วง (Spaced Repetition / Forgetting Curve), การติดตามความรู้ของผู้เรียน (Knowledge Tracing), และการวิเคราะห์เปรียบต่างระบบเสียง/ไวยากรณ์ไทย-จีน

1.4.2 ศึกษาเครื่องมือและเทคโนโลยีที่ใช้พัฒนา (py-fsrs, pyBKT, jieba, pypinyin และการเรียกใช้ LLM)

1.4.3 รวบรวมและจัดเตรียมคลังคำศัพท์ HSK และจัดทำคลังความผิดพลาดเฉพาะผู้เรียนชาวไทย (Thai-L1 Error Catalog) โดยผู้ร่วมพัฒนาที่เชี่ยวชาญภาษาจีนเป็นผู้กำหนดและตรวจสอบความถูกต้อง

1.4.4 ออกแบบฐานข้อมูลและสถาปัตยกรรมระบบ โดยแยกส่วนแบบจำลองผู้เรียน (Engine) ออกจากส่วนติดต่อผู้ใช้ เพื่อให้นำกลับมาใช้ซ้ำได้

1.4.5 พัฒนาแบบจำลองผู้เรียน ได้แก่ การประเมินความแม่นยำรายทักษะด้วย pyBKT, การวินิจฉัยความผิดด้วยคลัง Thai-L1, และการจัดตารางทบทวนด้วย FSRS

1.4.6 พัฒนาเว็บแอปพลิเคชัน ได้แก่ บัตรคำ (flashcard), แบบฝึกแต่งประโยคพร้อมข้อเสนอแนะ, และหน้าสรุปความคืบหน้า (dashboard)

1.4.7 ทดลองใช้งานกับผู้เรียนจริง (รวมถึงผู้ร่วมพัฒนาที่เป็นผู้เรียนภาษาจีนระดับเริ่มต้น) และเก็บบันทึกการตอบเพื่อใช้เป็นข้อมูล

1.4.8 ประเมินผลเชิงทดลอง (วัดความแม่นยำของการทำนาย, เปรียบเทียบอัตราการจดจำกับวิธีพื้นฐาน, และทำการศึกษาแบบ ablation) แล้วปรับปรุงระบบ และจัดทำรายงาน

## 1.5 ขอบเขตของโครงงาน

### 1.5.1 ขอบเขตของระบบ
โครงงานนี้พัฒนาในรูปแบบเว็บแอปพลิเคชัน (PWA) สำหรับผู้เรียนภาษาจีนที่มีภาษาไทยเป็นภาษาแม่ ครอบคลุมระดับ HSK เริ่มต้น (HSK 1–2 ตามมาตรฐาน HSK 3.0) ดำเนินการโดยคณะผู้จัดทำ 2 คน ภายในระยะเวลาประมาณ 4 เดือน โดยมีโมดูลการทำงานดังนี้

1. **ระบบคลังคำศัพท์และบัตรคำ (Vocabulary & Flashcard):** จัดเก็บคำศัพท์ HSK พร้อมพินอิน ความหมายภาษาไทย และเสียงอ่าน
2. **แบบจำลองผู้เรียน (Learner Model):** ประเมินความแม่นยำรายทักษะ (คำ/เสียงวรรณยุกต์/พยัญชนะ) ด้วย Knowledge Tracing (pyBKT)
3. **การวินิจฉัยจุดอ่อนเฉพาะคนไทย (Thai-L1 Diagnosis):** จัดหมวดความผิดและเทียบกับคลัง Thai-L1 แล้วสอน/ฝึกซ้ำแบบเจาะจง
4. **การจัดตารางทบทวน (Spaced Repetition):** ใช้ FSRS กำหนดว่าควรทบทวนทักษะ/คำใดเมื่อใด
5. **แบบฝึกการนำไปใช้ (Production):** การแต่งประโยคสั้นพร้อมข้อเสนอแนะจาก LLM โดยเน้นจับความผิดแบบคนไทย
6. **หน้าสรุปความคืบหน้า (Progress Dashboard):** แสดงพัฒนาการเชิงบวก เช่น ทักษะที่แม่นแล้ว/ที่ต้องทบทวน
7. **การสร้างเนื้อหาเฉพาะบุคคลด้วย AI (AI Content Generation):** ใช้ LLM สร้างประโยคตัวอย่าง แบบฝึก และตัวลวง โดยอ้างอิงจากคำและจุดอ่อนของผู้เรียน
8. **คู่สนทนาภาษาจีนที่ขับเคลื่อนด้วย AI (AI Conversation Partner):** สนทนาภาษาจีนกับผู้เรียน โดย LLM ทำงานร่วมกับแบบจำลองผู้เรียน เพื่อสอดแทรกคำ/เสียงที่ผู้เรียนยังไม่แม่นและให้ข้อเสนอแนะแบบเจาะจงคนไทย
9. **การวิเคราะห์การออกเสียง (Pitch Contour Feedback):** แสดงเส้นเสียงของผู้เรียนเทียบกับเสียงที่ถูกต้องด้วยการประมวลผลระดับเสียง (โดยไม่ใช้ระบบรู้จำเสียงเต็มรูปแบบ)

**สิ่งที่อยู่นอกขอบเขต (จัดเป็นงานในอนาคต):** การสแกนอักษรจีนจากกล้องด้วยการประมวลผลภาพ (multimodal OCR), การให้คะแนนการออกเสียงจากเสียงพูดจริงด้วยระบบรู้จำเสียงเต็มรูปแบบ (ASR-based pronunciation scoring), การให้บริการแบบหลายผู้ใช้ผ่าน MCP server ระยะไกล, และฟังก์ชันผู้ช่วยทั่วไป (เช่น ปฏิทิน/แจ้งเตือนนัดหมายชีวิต) ที่ไม่เกี่ยวข้องกับการเรียนภาษาโดยตรง

### 1.5.2 คำจำกัดความ
1. **Learner Model (แบบจำลองผู้เรียน):** แบบจำลองที่เก็บสถานะความรู้ของผู้เรียนรายบุคคล ประกอบด้วยความแม่นยำรายทักษะ จุดอ่อน และประวัติการตอบ
2. **Knowledge Tracing (การติดตามความรู้):** เทคนิคที่ประเมิน/ทำนายว่าผู้เรียนจะตอบทักษะถัดไปถูกหรือไม่ จากประวัติการตอบ
3. **Mastery (ความแม่นยำ):** ระดับความเชี่ยวชาญของผู้เรียนต่อทักษะหนึ่ง ๆ คำนวณด้วย Bayesian Knowledge Tracing (pyBKT)
4. **Spaced Repetition (การทบทวนแบบเว้นช่วง):** วิธีจัดตารางทบทวนตามเส้นโค้งการลืม เพื่อทบทวนก่อนจะลืมพอดี โดยใช้อัลกอริทึม FSRS
5. **Thai-L1 / L1 Transfer:** อิทธิพลของภาษาแม่ (ภาษาไทย) ที่ส่งผลต่อรูปแบบความผิดพลาดในการเรียนภาษาจีน
6. **Thai-L1 Error Catalog (คลังความผิดเฉพาะคนไทย):** ชุดข้อมูลรูปแบบความผิดที่ผู้เรียนชาวไทยมักทำในภาษาจีน พร้อมวิธีตรวจจับและวิธีสอนซ้ำ
7. **HSK:** การสอบวัดระดับความรู้ภาษาจีนกลางมาตรฐานสากล (ใช้บัญชีคำศัพท์ตามมาตรฐาน HSK 3.0 / GF0025-2021)
8. **Production vs Recognition:** การ "นำไปใช้/ผลิต" (พูด แต่งประโยค) เทียบกับการ "จดจำได้" (เลือกคำตอบถูก)

## 1.6 ประโยชน์ที่คาดว่าจะได้รับ

1.6.1 ได้สถาปัตยกรรมและต้นแบบของแบบจำลองผู้เรียน (Learner Model) ที่ออกแบบเป็นบริการอิสระ (frontend-agnostic engine) ซึ่งนำกลับมาใช้ซ้ำและต่อยอดได้ เป็นผลงานด้านการออกแบบระบบและวิศวกรรมซอฟต์แวร์

1.6.2 ได้องค์ความรู้และวิธีการประยุกต์เทคนิค Knowledge Tracing และ Spaced Repetition (FSRS) เข้ากับโดเมนการเรียนภาษาจีนสำหรับผู้เรียนชาวไทย ซึ่งยังไม่มีการศึกษาเฉพาะเจาะจง เป็นผลงานเชิงวิจัยที่สามารถอ้างอิงและต่อยอดได้

1.6.3 ได้ทรัพยากรเชิงคำนวณใหม่ ได้แก่ คลังความผิดเฉพาะผู้เรียนชาวไทย (Thai-L1 Error Catalog) และเมทริกซ์ทักษะ (Q-matrix) ที่จับคู่คำศัพท์กับทักษะ ซึ่งเป็นชุดข้อมูล/ฐานความรู้ที่นักวิจัยหรือผู้พัฒนารายอื่นสามารถนำไปใช้ต่อได้

1.6.4 ได้ผลการประเมินประสิทธิภาพของอัลกอริทึมเชิงปริมาณ (เช่น ค่า AUC ของการทำนาย อัตราการจดจำเทียบกับวิธีพื้นฐาน และการศึกษาแบบ ablation) ซึ่งเป็นการพิสูจน์เชิงประจักษ์ตามระเบียบวิธีทางวิทยาการคอมพิวเตอร์

1.6.5 ได้แสดงความสามารถในการบูรณาการเทคโนโลยีหลายด้านเข้าด้วยกัน ทั้งการประมวลผลภาษาธรรมชาติ (NLP ภาษาจีน) การสร้างแบบจำลองผู้เรียน/การเรียนรู้ของเครื่อง การพัฒนาเว็บแอปพลิเคชันแบบ PWA และการออกแบบฐานข้อมูลและสถาปัตยกรรมระบบ

1.6.6 ได้ฐานสำหรับการต่อยอดเชิงวิชาการในอนาคต เช่น การยกระดับเป็น Deep Knowledge Tracing การเพิ่มการประเมินการออกเสียงด้วยการประมวลผลสัญญาณเสียง การขยายไปสู่ภาษาอื่น หรือการเปิดให้บริการผ่านมาตรฐาน MCP
