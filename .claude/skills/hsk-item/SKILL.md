# Skill: สร้างข้อสอบรูปแบบ HSK (+ Q-matrix + Thai-L1)

สร้าง "ข้อสอบ 1 ข้อ" ที่ **ตรวจได้ด้วย rule (มีเฉลยตายตัว)** — ตรงกับ feedback อาจารย์ที่ให้เลี่ยง LLM ตรวจไวยากรณ์อิสระ

## รับ input
- **ระดับ HSK** (เริ่มที่ 1–2) และ/หรือ **คำศัพท์เป้าหมาย** และ/หรือ **ทักษะ/จุดผิดที่อยากทดสอบ**
- ถ้า input ไม่ครบ ให้เลือกค่าที่เหมาะสมกับ HSK 1–2 แล้วบอกที่เลือก

## ประเภทข้อที่ทำได้ (ทุกแบบมีเฉลยชัด → auto-grade ได้)
1. **เลือกความหมาย** (คำจีน → เลือกคำแปลไทยถูก)
2. **เลือกพินอิน** (คำจีน → เลือกพินอินถูก) — ดักจุดผิดวรรณยุกต์/เสียงคนไทยได้
3. **ฟังแล้วเลือก** (เสียง → เลือกคำ/รูป) — ทดสอบการฟัง
4. **เรียงคำเป็นประโยค** (tap-tiles → ลำดับถูกเดียว) — ทดสอบไวยากรณ์แบบมีเฉลย
5. **เติมคำในช่องว่าง** (เลือกจากตัวเลือก)

## ต้องคืนค่าครบทุกช่อง
```
- ประเภทข้อ:            (1-5 ข้างบน)
- ระดับ HSK:            
- โจทย์:                (ภาษาไทย + คำ/ประโยคจีนพร้อมพินอิน)
- ตัวเลือก:             (3-4 ตัว; ตัวลวงควรสะท้อนจุดผิดที่คนไทยพลาดจริง)
- เฉลย:                
- ทักษะที่ทดสอบ (Q-matrix): เช่น [วรรณยุกต์2/3, เสียง-zh, ลำดับคำ]
- Thai-L1 ที่ดัก:        จุดผิดคนไทยที่ข้อนี้จับ (ถ้ามี) + เหตุผลสั้น ๆ
- หมายเหตุการตรวจ:       ตรวจด้วย rule ยังไง (เทียบเฉลย / ลำดับที่ถูก)
```

## หลักการสำคัญ
- **ตัวลวง (distractors) ต้อง "มีความหมาย"** — สะท้อนจุดที่คนไทยมักพลาด (เช่น เสียง 2 vs 3, zh↔j) เพื่อให้ข้อสอบวินิจฉัย Thai-L1 ได้ ไม่ใช่ตัวลวงสุ่ม
- เฉลยต้อง **ตายตัวเดียว** (auto-grade ได้) — เลี่ยงข้อปลายเปิดที่ต้องใช้ AI ตัดสิน
- ผูกทุกข้อกับ **ทักษะใน Q-matrix** เพื่อให้ pyBKT อัปเดตความแม่นรายทักษะได้
- ภาษาจีนถูกต้อง + พินอินถูกวรรณยุกต์เสมอ

ถ้าถูกขอ "หลายข้อ" ให้สร้างเป็นชุด + สรุปตาราง Q-matrix รวม (ข้อไหนทดสอบทักษะไหน)
