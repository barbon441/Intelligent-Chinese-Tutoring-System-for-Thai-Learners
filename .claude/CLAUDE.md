# โปรเจกต์: จีนรู้ใจ (中文知心) — ติวเตอร์เตรียมสอบ HSK อัจฉริยะสำหรับคนไทย

> Claude อ่านไฟล์นี้อัตโนมัติเมื่อทำงานในโปรเจกต์ · รายละเอียดเต็มดูใน `HANDOFF-จีนรู้ใจ.md`

## โปรเจกต์คืออะไร
เว็บแอป (PWA) ช่วยคนไทย**เตรียมสอบ HSK** โดยวินิจฉัยจุดที่คนไทยมักพลาด (Thai-L1) แล้วเจาะติว
- ทีม: นายวรเดช ปิ่นทอง (6604101376) · นางสาวหฤทัย ยุวรัตน์ (6604101407) — วิทยาการคอมพิวเตอร์ ม.แม่โจ้
- โจทย์: นักศึกษา 2 คน, 4 เดือน, งบ 0 (ใช้ของฟรี/โอเพนซอร์สเท่านั้น)

## 🎯 ทิศทาง (หลัง feedback อาจารย์ — สำคัญ!)
- **กลุ่มเป้าหมาย:** คนไทย**ไม่มีพื้นฐาน** → เตรียมสอบ **HSK 1–2**
- **เป้าหมายวัดได้:** จาก 0 → สอบ HSK 1 ผ่าน (วัดด้วย pre/post mock exam)
- **ประเมินผล:** ใช้**รูปแบบข้อสอบ HSK (มีเฉลย)** ตรวจด้วย rule ของเราเอง — **ไม่ใช้ LLM ตรวจไวยากรณ์อิสระ**
- **ออกเสียง:** เน้น "สื่อสาร/ฟังเข้าใจ" ไม่ใช่ native (HSK 1-2 ไม่สอบพูด) → วิเคราะห์เสียงละเอียด = future work

## 🧠 แกนวิชาการ (จุดต่างที่ตรวจสอบแล้วว่าไม่มีใครทำ)
1. **Knowledge Tracing (pyBKT)** — วัดความแม่นรายทักษะ (เทรนด้วยข้อมูล **คนไทยเราเอง** ไม่ใช่ global)
2. **วินิจฉัย Thai-L1** — คลังจุดผิดเฉพาะคนไทย (วรรณยุกต์ 2/3, zh/ch/sh, ไวยากรณ์ถ่ายโอน)
3. **FSRS** — ทบทวนแบบเว้นช่วง
4. **Q-matrix** — จับคู่ข้อสอบ ↔ ทักษะ

## 🛠️ Tech Stack (ฟรีทั้งหมด)
- Frontend: **Next.js (PWA, Serwist)** + Tailwind + Dexie (IndexedDB ออฟไลน์)
- Backend: **FastAPI (Python)** — รัน pyBKT, FSRS, jieba, pypinyin
- DB: **Supabase (PostgreSQL)** · LLM: **Gemini Flash** (เรียกจาก server, key ใน env)
- โฮสต์ฟรี: **Cloudflare Pages** (เว็บ) + **Hugging Face Spaces** (backend ML) + Supabase
