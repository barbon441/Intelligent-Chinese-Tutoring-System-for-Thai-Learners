## สไลด์ 2 — ที่มาและความสำคัญของปัญหา

**หัวเรื่อง:** ภาษาจีนสำคัญ แต่แอปเรียนไม่แก้จุดอ่อนเฉพาะคนไทย

**เนื้อหา:**
- คนไทยเรียนภาษาจีนมากขึ้นต่อเนื่อง ทั้งเพื่อเรียนต่อ ทำงาน และท่องเที่ยว
- แต่แอปยอดนิยม (Duolingo, HelloChinese) เน้นท่องจำซ้ำ และใช้บทเรียนชุดเดียวสอนทุกชาติเหมือนกัน ไม่คำนึงถึงภาษาแม่ของผู้เรียน
- คนไทยมีจุดอ่อนเฉพาะจากการถ่ายโอนภาษาแม่ (L1 transfer): วรรณยุกต์เสียง 2 กับ 3 สับสน · เสียงม้วนลิ้น zh/ch/sh ที่ไทยไม่มี · ไวยากรณ์เรียงตามแบบไทย
- ยังไม่มีแอปใดวิเคราะห์จุดอ่อนเหล่านี้อย่างเป็นระบบ
- "จีนรู้ใจ" จึงวัดจุดอ่อนรายบุคคล แล้วเจาะสอนเฉพาะจุด

---

## สไลด์ 3 — วัตถุประสงค์ของโครงการ

**หัวเรื่อง:** วัตถุประสงค์ของโครงการ

**เนื้อหา:**
1. พัฒนาเว็บแอป (PWA) ติวเตอร์ภาษาจีนที่ใช้งานออฟไลน์ได้
2. สร้างแบบจำลองผู้เรียนเพื่อวัดความแม่นรายทักษะ (Knowledge Tracing)
3. สร้างคลังวินิจฉัยจุดผิดเฉพาะคนไทย (Thai-L1 Error Catalog)
4. พัฒนาระบบทบทวนอัจฉริยะ (FSRS) พร้อม AI คู่สนทนา/สร้างเนื้อหา
5. ประเมินผลเชิงทดลอง (AUC, retention, ablation study)

---

## สไลด์ 4 — เครื่องมือและเทคโนโลยี

**หัวเรื่อง:** เครื่องมือและเทคโนโลยี (ฟรี/โอเพนซอร์สทั้งหมด)

**เนื้อหา:**
- AI / Machine Learning: pyBKT (Knowledge Tracing), py-fsrs (Spaced Repetition), LLM (Gemini Flash / Typhoon)
- เว็บแอป (PWA): React / Next.js, FastAPI, Python
- NLP ภาษาจีน: jieba, pypinyin, edge-tts
- ฐานข้อมูล: Supabase (PostgreSQL) / SQLite
- โฮสต์ฟรี: Cloudflare Pages, Hugging Face Spaces

## สไลด์ 5 — ขอบเขตของโครงงาน

**หัวเรื่อง:** ขอบเขตของโครงงาน

**เนื้อหา:**
รูปแบบ: เว็บแอป (PWA) · กลุ่มเป้าหมาย: ผู้เรียนชาวไทย · ระดับ HSK 1–2

โมดูลหลัก:
- คลังคำศัพท์ + บัตรคำ
- แบบจำลองผู้เรียน (ความแม่นรายทักษะ)
- วินิจฉัยจุดผิดเฉพาะคนไทย (Thai-L1)
- ทบทวนแบบเว้นช่วง (FSRS)
- แต่งประโยค + AI คู่สนทนา
- วิเคราะห์การออกเสียง + Dashboard
- ใช้งานออฟไลน์ได้

## สไลด์ 6 — ประโยชน์ที่คาดว่าจะได้รับ

**หัวเรื่อง:** ประโยชน์ที่คาดว่าจะได้รับ

**เนื้อหา:**
- ได้สถาปัตยกรรมแบบจำลองผู้เรียนที่นำไปใช้ซ้ำได้
- ประยุกต์ Knowledge Tracing + FSRS กับการเรียนภาษาจีนของคนไทย
- ได้ทรัพยากรใหม่: Thai-L1 Error Catalog + Q-matrix
- มีผลวัดอัลกอริทึมเชิงปริมาณ (AUC, ablation)
- เป็นฐานต่อยอดงานวิจัยด้านการเรียนภาษาด้วย AI
- ผู้เรียนไทยได้เครื่องมือที่เจาะจุดอ่อนของตัวเอง เรียนตรงจุดและเร็วขึ้น

## สไลด์ 9 — จุดเด่น (มากกว่าแค่คลังคำ)

**หัวเรื่อง:** จุดเด่น — มากกว่าแค่คลังคำ

**เนื้อหา:**
- รู้ว่าคุณอ่อนตรงไหน แล้วเน้นเป็นพิเศษ ไม่สอนเหมือนกันหมดทุกคน
- เก่งจุดที่คนไทยมักพลาด เช่น วรรณยุกต์สับสน และเสียงที่ไทยไม่มี
- ผิดแล้วได้เข้าใจจริง ไม่ใช่แค่เด้งคำเดิมมาทำซ้ำ
- ได้ฝึกออกเสียงและแต่งประโยคเอง
- ทวนคำตอนกำลังจะลืมพอดี ไม่เสียเวลากับคำที่แม่นแล้ว
- เรียนที่ไหนก็ได้ แม้ไม่มีเน็ต
