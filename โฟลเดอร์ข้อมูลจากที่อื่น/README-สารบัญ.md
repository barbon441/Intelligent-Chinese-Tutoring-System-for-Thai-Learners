## 🗄️ `คลังเก็บ-แนวคิดเดิม-ผู้ช่วยLINE/` — เก็บไว้อ้างอิง (ไม่ได้ทำต่อ)
แนวคิดแรกก่อนเปลี่ยนทิศทาง: **知音/น้องยิน = ผู้ช่วย AI ส่วนตัวบน LINE** (ความจำ + File Vault + สรุปแชต)
เก็บไว้เผื่ออยากย้อนดูที่มา — ไม่ใช่โปรเจกต์ที่ทำอยู่แล้ว

- PROJECT_PLAN.md — แผนผู้ช่วย LINE (ของบอล)
- แผนโปรเจกต์-น้องยิน-ฉบับรวม.md — แผนรวม (LINE assistant)
- โครงร่างโครงงาน-น้องยิน.md — โครงร่าง 1.1–1.9 (LINE assistant)
- แผนที่โปรเจกต์-น้องยิน.md — แผนที่โปรเจกต์
- สรุปสั้น-น้องยิน.md — สรุปสั้น
- บันทึกการคุยกับอาจารย์.md — บันทึกที่มาของแนวคิด LINE assistant

## 📌 สรุปสั้น: จะเริ่มตรงไหน
1. อยากดูข้อเสนอล่าสุด → `จีนรู้ใจ-ปัจจุบัน/1-ข้อเสนอโครงงาน/ข้อเสนอโครงงาน-น้องยิน (ฉบับแก้ไข).md`
2. อยากเข้าใจภาพรวมโปรเจกต์ → `จีนรู้ใจ-ปัจจุบัน/2-แผนและสรุป/HANDOFF-จีนรู้ใจ.md`
3. เตรียมพรีเซนต์ → โฟลเดอร์ `3-นำเสนอ/`
