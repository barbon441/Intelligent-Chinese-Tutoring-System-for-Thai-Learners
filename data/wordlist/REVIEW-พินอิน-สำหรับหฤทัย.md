## 🔴 ต้องแก้แน่ ๆ — เลือกเสียงผิด (15 คำ)

| คำ | ในไฟล์ (ผิด) | ที่ควรเป็น | หมายเหตุ | ✍️ หฤทัยแก้ |

| 都 | Dū | **dōu** | Dū = ชื่อสกุล/เมืองหลวง · dōu = ทั้งหมด (ความหมาย HSK1) |  |

## 🟡 ต้องเคาะกติกา (9 คำ)

**① คำที่มี 儿 (儿化) — เขียนยังไงดี?** เสียงจริงคือพยางค์เดียว (nǎr) แต่ไฟล์เราเขียนแยกช่องว่าง (nǎ r) · สำคัญเพราะแอปเราระบายสีวรรณยุกต์ทีละพยางค์ — ถ้าแยกช่องว่างจะกลายเป็น 2 สี ทั้งที่ออกเสียงพยางค์เดียว

| 面条儿 | miàn tiáo r | miàn tiáor (เขียนติด) |  |
| 哪儿 | nǎ r | nǎr (เขียนติด) |  |
| 那儿 | nà r | nàr (เขียนติด) |  |

| 这儿 | zhè r | zhèr (เขียนติด) |  |
