# โครงร่างโครงงาน

ชื่อโครงงาน (ไทย): ผู้ช่วยปัญญาประดิษฐ์ส่วนบุคคลบน LINE ที่มีความจำคล้ายมนุษย์และเรียนรู้ตัวตนผู้ใช้ (รองรับภาษาไทย)

ชื่อโครงงาน (อังกฤษ): A Personal AI Assistant on LINE with Human-like Memory that Learns Its User

ชื่อผลิตภัณฑ์: 知音 (น้องยิน)

โครงงานนี้พัฒนาผู้ช่วยปัญญาประดิษฐ์บน LINE ที่จดจำผู้ใช้ข้ามการสนทนา เรียนรู้ความชอบและตัวตนของผู้ใช้ จัดเก็บไฟล์ที่ส่งผ่าน LINE ไม่ให้สูญหาย และสรุปบทสนทนาให้ได้ ส่วนที่พัฒนาขึ้นเองและเป็นแกนของโครงงานคือระบบความจำ (Memory Engine) ที่รองรับภาษาไทยและประเมินผลได้เชิงปริมาณ ส่วนความสามารถในการตอบสนทนาใช้โมเดลภาษาสำเร็จรูปจึงไม่ต้องฝึกโมเดลขึ้นใหม่

---

## 1.1 ที่มาและความสำคัญของปัญหา

LINE เป็นแอปพลิเคชันสื่อสารที่คนไทยใช้มากที่สุด มีผู้ใช้ประมาณ 54–56 ล้านคน และถูกใช้เป็นเครื่องมือทำงานหลักในชีวิตประจำวัน แต่ผู้ใช้จำนวนมากพบปัญหาคือ ข้อความในแชตมีจำนวนมากจนค้นหาข้อมูลเก่าได้ยาก ไม่มีระบบสรุปบทสนทนา และต้องตอบคำถามซ้ำ ๆ ด้วยตนเอง นอกจากนี้ไฟล์ รูปภาพ และวิดีโอที่ส่งผ่าน LINE จะถูกเก็บไว้เพียงระยะเวลาหนึ่ง หลังจากนั้นอาจเปิดหรือดาวน์โหลดไม่ได้ และเมื่อบริการ LINE Keep ปิดตัวลง (สิงหาคม 2567) จึงเกิดช่องว่างด้านที่จัดเก็บไฟล์ถาวรที่ค้นหาได้

ผู้ช่วยปัญญาประดิษฐ์ทั่วไปแม้ตอบได้ดี แต่เมื่อเริ่มการสนทนาใหม่ก็จะลืมผู้ใช้ ไม่รู้จักตัวตนของผู้ใช้ และไม่ได้อยู่ในช่องทางที่คนไทยใช้ทุกวัน ขณะที่แชตบอตในประเทศไทยที่มีอยู่ส่วนใหญ่พัฒนาขึ้นเพื่อใช้งานเชิงธุรกิจ จึงยังไม่มีผู้ช่วยส่วนบุคคลที่จดจำและเรียนรู้ตัวตนของผู้ใช้แต่ละคนได้อย่างต่อเนื่อง

โครงงานนี้จึงพัฒนา น้องยิน ผู้ช่วยปัญญาประดิษฐ์ส่วนบุคคลบน LINE เพื่อแก้ปัญหาดังกล่าว โดยมีแกนสำคัญอยู่ที่ระบบความจำที่จดจำและเรียนรู้ผู้ใช้ได้ และรองรับภาษาไทย ซึ่งภาษาไทยเป็นภาษาที่มีทรัพยากรด้านการประมวลผลจำกัดและไม่มีการเว้นวรรคระหว่างคำ จึงเป็นโจทย์ที่ท้าทายและมีคุณค่าในการศึกษา

## 1.2 วัตถุประสงค์

1. พัฒนาผู้ช่วยปัญญาประดิษฐ์บน LINE ที่จดจำบริบทการสนทนาข้ามเซสชันได้
2. พัฒนาระบบความจำระยะยาวที่เรียนรู้ตัวตนและความชอบของผู้ใช้ และรองรับภาษาไทย
3. พัฒนาระบบจัดเก็บไฟล์ที่ดาวน์โหลดและเก็บไฟล์ก่อนหมดอายุ พร้อมค้นหาได้
4. ออกแบบกลไกความเป็นส่วนตัวและการควบคุมข้อมูลของผู้ใช้ ให้สอดคล้องกับ พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล (PDPA)
5. ประเมินประสิทธิภาพของระบบความจำด้วยชุดทดสอบ ตัวชี้วัด และการทดลองเปรียบเทียบ

## 1.3 ฮาร์ดแวร์ ซอฟต์แวร์ เครื่องมือ และเทคโนโลยีที่ใช้ในการศึกษา

- ฮาร์ดแวร์: เครื่องคอมพิวเตอร์ส่วนบุคคลสำหรับพัฒนาและทดสอบ
- ภาษาและเฟรมเวิร์ก: Python และ FastAPI
- การเชื่อมต่อ LINE: ไลบรารี line-bot-sdk-python (รุ่น 3) ผ่าน LINE Messaging API
- โมเดลภาษา: Gemini 2.5 Flash (รุ่นใช้งานฟรี) และ Typhoon สำหรับภาษาไทย โดยมีทางเลือกใช้ Ollama ร่วมกับ OpenThaiGPT เพื่อรันในเครื่อง
- โมเดลฝังเวกเตอร์ (embeddings): BGE-M3 ที่รองรับภาษาไทย
- ฐานข้อมูลและการค้นคืนเชิงเวกเตอร์: Supabase (PostgreSQL ร่วมกับ pgvector) หรือ Oracle Database 23ai
- ที่จัดเก็บไฟล์: Cloudflare R2
- การเปิดให้บริการ (hosting): Google Cloud Run หรือ Koyeb
- เครื่องมือพัฒนา: Git, GitHub และ Visual Studio Code

เครื่องมือทั้งหมดเลือกใช้รุ่นที่ไม่มีค่าใช้จ่ายหรือมีต้นทุนต่ำ เพื่อให้ดำเนินโครงงานได้โดยใช้งบประมาณใกล้ศูนย์

## 1.4 วิธีการศึกษา

1. ศึกษาเอกสารและงานที่เกี่ยวข้อง ได้แก่ เอกสารของ LINE Messaging API ระบบความจำสำหรับโมเดลภาษา ชุดทดสอบความจำในบทสนทนา และการประมวลผลภาษาไทย
2. ออกแบบสถาปัตยกรรมของระบบ โดยแยกส่วนแกนระบบความจำออกจากส่วนเชื่อมต่อ LINE เพื่อให้นำกลับมาใช้ซ้ำและทดสอบได้ง่าย
3. พัฒนาเป็นขั้นตอน โดยทำส่วนที่ใช้งานได้จริงก่อน เรียงจากบอตตอบกลับพื้นฐาน ระบบจัดเก็บไฟล์ ระบบความจำและการสรุปบทสนทนา การเรียนรู้ตัวตนผู้ใช้ และกลไกความเป็นส่วนตัว
4. พัฒนาระบบความจำเป็น 3 ระดับ คือ ความจำระยะสั้น (ข้อความล่าสุด) การสรุปบทสนทนาเมื่อข้อความยาวขึ้น และความจำระยะยาวที่ค้นคืนข้อมูลที่เกี่ยวข้องมาช่วยตอบ ร่วมกับเทคนิคการสกัดข้อเท็จจริงจากบทสนทนา การลดน้ำหนักความจำเก่าตามเวลา (อ้างอิงเส้นโค้งการลืมของ Ebbinghaus) การค้นคืนแบบผสมระหว่างคำสำคัญและเวกเตอร์ และการจัดการการตัดคำภาษาไทย
5. ประเมินผลโดยสร้างหรืออ้างอิงชุดทดสอบภาษาไทย วัดด้วยตัวชี้วัดด้านการค้นคืน (เช่น recall@k, precision@k, MRR, nDCG) ความแม่นยำของคำตอบ เวลาตอบสนอง และทำการทดลองเปรียบเทียบ (ablation) เช่น เปรียบเทียบระบบที่มีและไม่มีการลดน้ำหนักความจำ

## 1.5 ขอบเขตของโครงงาน

- ระบบทำงานบนแพลตฟอร์ม LINE ผ่านบัญชีทางการ (LINE Official Account)
- รองรับการสนทนาภาษาไทยเป็นหลัก และภาษาอังกฤษพื้นฐาน
- ระบบจัดเก็บไฟล์เก็บได้เฉพาะไฟล์ที่ผู้ใช้ส่งหาบอทหรือไฟล์ในกลุ่มที่บอทเป็นสมาชิก ไม่ใช่การสำรองข้อมูลทั้งหมดใน LINE
- ใช้โมเดลภาษาสำเร็จรูปเป็นส่วนตอบสนทนา ไม่มีการฝึกโมเดลภาษาขนาดใหญ่ขึ้นใหม่ ส่วนที่พัฒนาเองคือระบบความจำและระบบที่อยู่รอบ ๆ
- ดำเนินงานด้วยเครื่องมือที่ไม่มีค่าใช้จ่ายหรือต้นทุนต่ำ
- ฟีเจอร์ส่วนขยายที่จะทำเมื่อมีเวลาและสามารถตัดออกได้ ได้แก่ การเปิดให้ปัญญาประดิษฐ์อื่นเรียกใช้ผ่านมาตรฐาน MCP, การค้นข้อมูลจากเว็บ และระบบแปลภาษา

## 1.6 ประโยชน์ที่คาดว่าจะได้รับ

- ผู้ใช้มีผู้ช่วยส่วนตัวบน LINE ที่จดจำเรื่องราวของผู้ใช้ เก็บไฟล์ไม่ให้สูญหาย และสรุปบทสนทนาได้ ช่วยลดงานที่ต้องทำซ้ำ
- ได้ต้นแบบระบบความจำที่รองรับภาษาไทย พร้อมผลการประเมินที่เป็นองค์ความรู้ด้านระบบความจำของปัญญาประดิษฐ์และการประมวลผลภาษาไทย
- เป็นต้นแบบที่ต่อยอดได้ เช่น เปิดให้ปัญญาประดิษฐ์อื่นเรียกใช้ระบบความจำผ่านมาตรฐาน MCP
- ผู้พัฒนาได้ฝึกทักษะการออกแบบระบบ การประมวลผลภาษาธรรมชาติ และการประเมินผลเชิงทดลอง

## 1.7 ระยะเวลาดำเนินงาน

ระยะเวลาดำเนินงานประมาณ 4 เดือน เริ่มปลายเดือนมิถุนายนถึงตุลาคม พ.ศ. 2569 โดยช่วงปลายเดือนมิถุนายนเป็นการเริ่มโครงงานและจัดทำข้อเสนอ ส่วนการพัฒนาหลักอยู่ในเดือนกรกฎาคมถึงตุลาคม

|:---:|---|:---:|:---:|:---:|:---:|:---:|
| 1 | ศึกษาเอกสารและงานที่เกี่ยวข้อง และจัดทำข้อเสนอโครงงาน | █████ | | | | |
| 2 | ออกแบบสถาปัตยกรรมระบบ และตั้งค่าสภาพแวดล้อม | █████ | | | | |
| 3 | พัฒนาระบบจัดเก็บไฟล์ | █████ | █████ | | | |
| 4 | พัฒนาระบบความจำ และการสรุปบทสนทนาภาษาไทย | | █████ | █████ | | |
| 5 | พัฒนาการเรียนรู้ตัวตนผู้ใช้ การลดน้ำหนักความจำ และการค้นคืนแบบผสม | | | █████ | █████ | |

## 1.10 ลักษณะโครงงานที่พัฒนา

เป็นโครงงานพัฒนาซอฟต์แวร์ประเภทแชตบอตอัจฉริยะบนแพลตฟอร์ม LINE ที่ผสมระหว่างงานพัฒนาระบบและงานวิจัยเชิงทดลอง ในด้านการพัฒนาระบบประกอบด้วยบริการฝั่งเซิร์ฟเวอร์ ระบบจัดเก็บไฟล์ และการเชื่อมต่อ LINE ส่วนงานวิจัยเชิงทดลองคือการออกแบบระบบความจำขึ้นเองและประเมินผลด้วยชุดทดสอบและตัวชี้วัด โครงงานนี้จึงเป็นงานด้านวิทยาการคอมพิวเตอร์ที่ครอบคลุมการออกแบบอัลกอริทึม โครงสร้างข้อมูลและการค้นคืนสารสนเทศ การประมวลผลภาษาธรรมชาติ และการประเมินผลเชิงปริมาณ
