## 1.1 ที่มาและความสำคัญของปัญหา

ในปัจจุบันภาษาจีนกลาง (Mandarin) ได้กลายเป็นภาษาต่างประเทศที่มีความสำคัญลำดับต้น ๆ ของประเทศไทย โดยมีจำนวนผู้เรียนเพิ่มขึ้นอย่างต่อเนื่อง ทั้งในระดับมัธยมศึกษา อุดมศึกษา และกลุ่มคนทำงาน อีกทั้งการสอบวัดระดับความรู้ภาษาจีน (HSK: Hanyu Shuiping Kaoshi) ยังถูกใช้เป็นเกณฑ์มาตรฐานในการศึกษาต่อและการทำงานอย่างแพร่หลาย ความต้องการเครื่องมือช่วยเรียนภาษาจีนที่มีประสิทธิภาพและช่วยเตรียมสอบได้อย่างตรงจุดจึงเพิ่มสูงขึ้นตามไปด้วย

อย่างไรก็ตาม แอปพลิเคชันที่มีอยู่ในตลาดส่วนใหญ่ยังมีข้อจำกัดสำคัญ 2 ประการ ประการแรกคือ ออกแบบบทเรียนแบบ "เหมือนกันสำหรับผู้เรียนทุกชาติ" โดยไม่คำนึงว่าผู้เรียนมีภาษาแม่ (First Language: L1) ใด ทั้งที่ในทางภาษาศาสตร์ ภาษาแม่เป็นตัวกำหนดรูปแบบความผิดพลาดของผู้เรียนอย่างมีนัยสำคัญ (L1 transfer / language interference) และประการที่สองคือ มักเป็นการฝึกแบบ "ท่องซ้ำทั่วไป" ที่ไม่ได้วินิจฉัยเป็นรายบุคคลว่าผู้เรียนอ่อนทักษะใด และไม่ได้ผูกการเรียนเข้ากับเป้าหมายที่วัดผลได้ชัดเจน เช่น การสอบผ่าน HSK ระดับที่กำหนด

สำหรับผู้เรียนชาวไทย ความผิดพลาดมีลักษณะเฉพาะที่แตกต่างจากผู้เรียนชาติอื่นอันเกิดจากการถ่ายโอนจากภาษาไทย เช่น ความสับสนในการ "แยกแยะ/รับรู้" วรรณยุกต์เสียงที่ 2 กับเสียงที่ 3 (ซึ่งงานวิจัยชี้ว่าเป็นคู่เสียงที่คนไทยพลาดมากที่สุด) การรับรู้เสียงพยัญชนะม้วนลิ้น zh/ch/sh/r ที่ไม่มีในภาษาไทย และความผิดเชิงไวยากรณ์จากการถ่ายโอนโครงสร้างประโยคแบบไทย เช่น ลำดับคำขยาย (ภาษาจีนวางคำขยายไว้หน้าคำหลักในรูป ขยาย + 的 + คำหลัก ซึ่งตรงข้ามกับภาษาไทย) จุดอ่อนเฉพาะกลุ่มเหล่านี้ปรากฏอยู่ในทักษะที่ข้อสอบ HSK วัดได้จริง (การฟังและการอ่าน) แต่แทบไม่มีแอปพลิเคชันใดนำมาวิเคราะห์และซ่อมเสริมอย่างเป็นระบบ

ด้วยเหตุนี้ คณะผู้จัดทำจึงเสนอพัฒนาระบบติวเตอร์ภาษาจีน "น้องยิน (Nong Yin)" ที่นำแนวคิดการสร้างแบบจำลองผู้เรียน (Learner Model) มาประยุกต์ใช้ โดย**จำกัดขอบเขตให้ชัดเจนที่การเตรียมสอบ HSK ระดับ 1–2 (มาตรฐาน HSK 3.0)** และเน้นเฉพาะทักษะที่ตรวจให้คะแนนได้อย่างเป็นปรนัย ระบบอาศัยทฤษฎีและเทคนิคที่ได้รับการยอมรับทางวิชาการ ได้แก่ การติดตามความรู้ของผู้เรียน (Knowledge Tracing) เพื่อประเมิน "ความแม่นยำรายทักษะ" ของผู้เรียนแต่ละคน การทบทวนแบบเว้นช่วง (Spaced Repetition) เพื่อจัดตารางทบทวนคำในจังหวะที่กำลังจะลืมพอดี และการวิเคราะห์เปรียบต่าง (Contrastive Analysis) ระหว่างภาษาไทยกับภาษาจีน เพื่อวินิจฉัยความผิดพลาดที่เกิดเฉพาะกับผู้เรียนชาวไทย ระบบนี้จึงไม่ใช่เพียงแอปพลิเคชันท่องศัพท์ทั่วไป แต่เป็นระบบที่ "เรียนรู้ตัวผู้เรียน รู้ว่าผู้เรียนอ่อนตรงไหน และปรับการทบทวน/ฝึกให้เฉพาะบุคคล" เพื่อพาผู้เรียนไปสู่เป้าหมายการสอบผ่าน HSK 1–2 ซึ่งสามารถประเมินผลได้ในเชิงวิทยาศาสตร์

## 1.2 วัตถุประสงค์

1.2.1 เพื่อพัฒนาระบบติวเตอร์เตรียมสอบ HSK ระดับ 1–2 (มาตรฐาน HSK 3.0) ในรูปแบบเว็บแอปพลิเคชัน (Progressive Web App) สำหรับผู้เรียนชาวไทย ที่ส่วนหลักสามารถใช้งานได้แม้ในสภาวะออฟไลน์

1.2.2 เพื่อพัฒนาแบบจำลองผู้เรียน (Learner Model) ที่ติดตามและประเมินความแม่นยำรายทักษะ (per-skill mastery) ของผู้เรียนแต่ละคนด้วยเทคนิค Knowledge Tracing (pyBKT)

1.2.3 เพื่อพัฒนาคลังวินิจฉัยความผิดพลาดเฉพาะผู้เรียนชาวไทย (Thai-L1 Error Catalog) ในขอบเขตที่วัดได้จากข้อสอบ HSK 1–2 ครอบคลุมการรับรู้วรรณยุกต์ (โดยเฉพาะเสียงที่ 2/3) การแยกแยะเสียงพยัญชนะม้วนลิ้น และไวยากรณ์ระดับต้น (เช่น ลำดับคำขยาย) โดยอาศัยหลักการวิเคราะห์เปรียบต่างไทย-จีน

1.2.4 เพื่อนำอัลกอริทึมการทบทวนแบบเว้นช่วง (Free Spaced Repetition Scheduler: FSRS) มาจัดตารางทบทวนคำศัพท์เฉพาะบุคคล ให้มีประสิทธิภาพดีกว่าการทบทวนด้วยตารางคงที่

1.2.5 เพื่อพัฒนาโมดูลฝึกและวัดผลตามรูปแบบข้อสอบ HSK 1–2 ได้แก่ แบบฝึกการฟัง แบบฝึกการอ่าน และข้อสอบเสมือนจริงแบบจับเวลา (Mock Exam) ซึ่งป้อนผลการตอบเข้าสู่แบบจำลองผู้เรียนเพื่อวินิจฉัยจุดอ่อนอย่างต่อเนื่อง

1.2.6 เพื่อประเมินผลเชิงทดลองว่าระบบสามารถช่วยให้ผู้เรียนชาวไทยจดจำคำศัพท์และพัฒนาทักษะที่จำเป็นต่อการสอบ HSK 1–2 ได้ดีขึ้นจริง โดยวัดด้วยตัวชี้วัดมาตรฐาน ได้แก่ ความแม่นยำเชิงทำนายของแบบจำลอง (AUC) และอัตราการจดจำเมื่อเทียบกับวิธีพื้นฐาน

## 1.3 ฮาร์ดแวร์ ซอฟต์แวร์ เครื่องมือ และเทคโนโลยีที่ใช้ในการศึกษา

### 1.3.1 ฮาร์ดแวร์ (Hardware)
- เครื่องคอมพิวเตอร์โน้ตบุ๊ก (Notebook Computer) จำนวน 2 เครื่อง — [ระบุรุ่น]
- ไมโครโฟน/หูฟัง สำหรับสื่อการฟัง

### 1.3.2 ภาษาและฐานข้อมูลที่ใช้ในการพัฒนา (Programming Languages & Database)
- Python — ภาษาหลักของส่วนประมวลผล (learner model, การวินิจฉัย, การจัดตาราง)
- TypeScript / JavaScript — สำหรับส่วนติดต่อผู้ใช้ (เว็บ/PWA)
- SQL — จัดการฐานข้อมูล โดยใช้ SQLite (ระยะต้นแบบ) และ/หรือ PostgreSQL (Supabase) เมื่อขยายระบบ

### 1.3.3 เฟรมเวิร์กและไลบรารีหลัก (Frameworks & Core Libraries)
- React / Next.js — สร้างส่วนติดต่อผู้ใช้แบบ Progressive Web App รองรับการใช้งานออฟไลน์
- FastAPI (Python) — พัฒนาส่วนหลังบ้าน (Engine แยกเป็นบริการ ใช้ร่วมกับหลายช่องทางได้)
- py-fsrs — ไลบรารีจัดตารางทบทวนแบบเว้นช่วง (FSRS)
- pyBKT — ไลบรารี Bayesian Knowledge Tracing สำหรับประเมินความแม่นยำรายทักษะ (mastery)
- jieba — ตัดคำภาษาจีน (Chinese Word Segmentation) เพื่อควบคุมให้เนื้อหาอยู่ในโควตาคำศัพท์ของระดับ
- pypinyin — แปลงอักษรจีนเป็นพินอินพร้อมวรรณยุกต์ (รองรับ pinyin ในระดับ HSK 1–2)
- edge-tts / MeloTTS — สังเคราะห์เสียงอ่านภาษาจีน (ฟรี) สำหรับสื่อการฟังและข้อสอบฟัง

### 1.3.4 บริการปัญญาประดิษฐ์ (AI Services) — ส่วนเสริม (Optional)
- โมเดลภาษาขนาดใหญ่ (LLM) เช่น Google Gemini หรือ Typhoon — ใช้แบบไม่เก็บสถานะ (stateless) เป็น**ฟีเจอร์เสริม**เพื่ออธิบายความหมาย/ไวยากรณ์เป็นภาษาไทยและช่วยสร้างตัวอย่างประโยค (ออกแบบให้สลับผู้ให้บริการได้ และไม่ใช่ส่วนที่ใช้ประเมินผลของโครงงาน)

### 1.3.5 เครื่องมือพัฒนาและทดสอบ (Development & Testing Tools)
- Visual Studio Code — โปรแกรมเขียนโค้ด
- Git และ GitHub — ระบบควบคุมเวอร์ชันและจัดเก็บซอร์สโค้ดบนคลาวด์
- Node.js และ npm — จัดการแพ็กเกจและรันสคริปต์
- ชุดข้อมูลคำศัพท์ HSK 3.0 (โอเพนซอร์ส) — ใช้เป็นคลังคำศัพท์ตั้งต้น (ระดับ 1 = 300 คำ, ระดับ 2 = 500 คำ ตามข้อสอบจริง)

## 1.4 วิธีการศึกษา

การพัฒนาโครงงานใช้กระบวนการแบบเป็นลำดับขั้นและทำซ้ำเป็นรอบ (Iterative) ควบคู่กับการทดสอบกับผู้เรียนจริงและการรับข้อเสนอแนะจากอาจารย์ที่ปรึกษาเป็นระยะ โดยมีขั้นตอนดังนี้

1.4.1 ศึกษาทฤษฎีและงานวิจัยที่เกี่ยวข้อง ได้แก่ การทบทวนแบบเว้นช่วง (Spaced Repetition / Forgetting Curve), การติดตามความรู้ของผู้เรียน (Knowledge Tracing), และการวิเคราะห์เปรียบต่างระบบเสียง/ไวยากรณ์ไทย-จีน

1.4.2 ศึกษาเครื่องมือและเทคโนโลยีที่ใช้พัฒนา (py-fsrs, pyBKT, jieba, pypinyin และ edge-tts/MeloTTS)

1.4.3 รวบรวมและจัดเตรียมคลังคำศัพท์และหลักสูตร HSK 1–2 (มาตรฐาน 3.0) และจัดทำคลังความผิดพลาดเฉพาะผู้เรียนชาวไทย (Thai-L1 Error Catalog) โดยผู้ร่วมพัฒนาที่เชี่ยวชาญภาษาจีนเป็นผู้กำหนดและตรวจสอบความถูกต้อง

1.4.4 ออกแบบฐานข้อมูลและสถาปัตยกรรมระบบ โดยแยกส่วนแบบจำลองผู้เรียน (Engine) ออกจากส่วนติดต่อผู้ใช้ เพื่อให้นำกลับมาใช้ซ้ำและขยายไประดับที่สูงขึ้นได้ในอนาคต

1.4.5 พัฒนาแบบจำลองผู้เรียน ได้แก่ การประเมินความแม่นยำรายทักษะด้วย pyBKT, การวินิจฉัยความผิดด้วยคลัง Thai-L1, และการจัดตารางทบทวนด้วย FSRS

1.4.6 พัฒนาเว็บแอปพลิเคชัน ได้แก่ บัตรคำ (flashcard), โมดูลฝึกการฟัง, โมดูลฝึกการอ่าน, ข้อสอบเสมือนจริงแบบจับเวลา (Mock Exam) และหน้าสรุปความคืบหน้า (dashboard)

1.4.7 ทดลองใช้งานกับผู้เรียนจริง (รวมถึงผู้ร่วมพัฒนาที่เป็นผู้เรียนภาษาจีนระดับเริ่มต้น) และเก็บบันทึกการตอบเพื่อใช้เป็นข้อมูล

1.4.8 ประเมินผลเชิงทดลอง (วัดความแม่นยำของการทำนายด้วย AUC, เปรียบเทียบอัตราการจดจำกับวิธีพื้นฐาน, และทำการศึกษาแบบ ablation) แล้วปรับปรุงระบบ และจัดทำรายงาน

## 1.5 ขอบเขตของโครงงาน

### 1.5.1 ขอบเขตของระบบ
โครงงานนี้พัฒนาในรูปแบบเว็บแอปพลิเคชัน (PWA) สำหรับผู้เรียนภาษาจีนที่มีภาษาไทยเป็นภาษาแม่ **โดยจำกัดขอบเขตที่การเตรียมสอบ HSK ระดับ 1–2 ตามมาตรฐาน HSK 3.0** (ระดับ 1: คำศัพท์ 300 คำ / ไวยากรณ์ 48 จุด, ระดับ 2: คำศัพท์ 500 คำ / ไวยากรณ์ 129 จุด) ครอบคลุมทักษะที่ข้อสอบระดับนี้วัดได้และตรวจให้คะแนนได้อย่างเป็นปรนัย คือ **การฟังและการอ่าน** ดำเนินการโดยคณะผู้จัดทำ 2 คน ภายในระยะเวลาประมาณ 4 เดือน โดยมีโมดูลการทำงานดังนี้

1. **ระบบคลังคำศัพท์และบัตรคำ (Vocabulary & Flashcard):** จัดเก็บคำศัพท์ HSK 1–2 พร้อมพินอิน ความหมายภาษาไทย และเสียงอ่าน
2. **แบบจำลองผู้เรียน (Learner Model):** ประเมินความแม่นยำรายทักษะ (คำ/เสียงวรรณยุกต์/พยัญชนะ/ไวยากรณ์) ด้วย Knowledge Tracing (pyBKT)
3. **การวินิจฉัยจุดอ่อนเฉพาะคนไทย (Thai-L1 Diagnosis):** จัดหมวดความผิดและเทียบกับคลัง Thai-L1 แล้วจัดการทบทวน/ฝึกซ้ำแบบเจาะจง
4. **การจัดตารางทบทวน (Spaced Repetition):** ใช้ FSRS กำหนดว่าควรทบทวนทักษะ/คำใดเมื่อใด
5. **โมดูลฝึกการฟัง (Listening Practice):** ข้อสอบฟังตามรูปแบบ HSK 1–2 รวมถึงแบบฝึกแยกแยะคู่เสียงขั้นต่ำ (minimal pair) ของวรรณยุกต์เสียง 2/3 และพยัญชนะม้วนลิ้น เพื่อวินิจฉัยจุดอ่อนแบบคนไทยโดยไม่ต้องใช้ระบบรู้จำเสียงพูด
6. **โมดูลฝึกการอ่าน (Reading Comprehension):** ข้อสอบอ่านตามรูปแบบ HSK 1–2 (จับคู่/ถูก-ผิด/เลือกตอบ) โดยควบคุมคำศัพท์ให้อยู่ในระดับด้วย jieba
7. **ข้อสอบเสมือนจริงแบบจับเวลา (Mock Exam):** ประกอบข้อสอบฟัง+อ่านเต็มรูปแบบ จับเวลาและให้คะแนนตามเกณฑ์จริง (สเกล 200 คะแนน ผ่าน 120) พร้อมป้อนข้อมูลเข้าสู่แบบจำลองผู้เรียน
8. **หน้าสรุปความคืบหน้า (Progress Dashboard):** แสดงพัฒนาการเชิงบวก เช่น ทักษะที่แม่นแล้ว/ที่ต้องทบทวน และความพร้อมสอบโดยประมาณ

**สิ่งที่อยู่นอกขอบเขต (จัดเป็นงานในอนาคต):**
- **การประเมิน/ดัดการออกเสียงจากเสียงพูดจริง และการวิเคราะห์เส้นเสียง (Pitch Contour / ASR-based pronunciation scoring)** — เนื่องจากข้อสอบ HSK ระดับ 1–2 ไม่มีส่วนการสอบพูด (การสอบพูด/HSKK บังคับตั้งแต่ระดับ 3 ขึ้นไป) โครงงานนี้จึงจำกัดการวิเคราะห์เสียงไว้เพียงการ "แยกแยะ/รับรู้" ในโมดูลการฟังเท่านั้น
- **แบบฝึกแต่งประโยคที่ตรวจด้วย LLM (Production / open-ended writing)** — เนื่องจากไวยากรณ์จีนมีความยืดหยุ่นสูง ทำให้การตรวจประโยคปลายเปิดอัตโนมัติยังไม่น่าเชื่อถือเพียงพอในกรอบเวลานี้ (จะพัฒนาในรูปแบบ "เรียงคำเป็นประโยค" ที่มีคำตอบชัดเจนเมื่อขยายไป HSK 3)
- **คู่สนทนาภาษาจีนที่ขับเคลื่อนด้วย AI (AI Conversation Partner) และการสร้างเนื้อหาอัตโนมัติด้วย LLM** — เป็นฟีเจอร์เสริมที่ยังไม่นับเป็นส่วนหลักของการประเมินผล
- **การขยายไปยัง HSK ระดับ 3–9** (สถาปัตยกรรมออกแบบให้รองรับการต่อยอด)
- การสแกนอักษรจีนจากกล้อง (multimodal OCR), การให้บริการหลายผู้ใช้ผ่าน MCP server ระยะไกล และฟังก์ชันผู้ช่วยทั่วไปที่ไม่เกี่ยวข้องกับการเรียนภาษาโดยตรง

### 1.5.2 คำจำกัดความ
1. **Learner Model (แบบจำลองผู้เรียน):** แบบจำลองที่เก็บสถานะความรู้ของผู้เรียนรายบุคคล ประกอบด้วยความแม่นยำรายทักษะ จุดอ่อน และประวัติการตอบ
2. **Knowledge Tracing (การติดตามความรู้):** เทคนิคที่ประเมิน/ทำนายว่าผู้เรียนจะตอบทักษะถัดไปถูกหรือไม่ จากประวัติการตอบ
3. **Mastery (ความแม่นยำ):** ระดับความเชี่ยวชาญของผู้เรียนต่อทักษะหนึ่ง ๆ คำนวณด้วย Bayesian Knowledge Tracing (pyBKT)
4. **Spaced Repetition (การทบทวนแบบเว้นช่วง):** วิธีจัดตารางทบทวนตามเส้นโค้งการลืม เพื่อทบทวนก่อนจะลืมพอดี โดยใช้อัลกอริทึม FSRS
5. **Thai-L1 / L1 Transfer:** อิทธิพลของภาษาแม่ (ภาษาไทย) ที่ส่งผลต่อรูปแบบความผิดพลาดในการเรียนภาษาจีน
6. **Thai-L1 Error Catalog (คลังความผิดเฉพาะคนไทย):** ชุดข้อมูลรูปแบบความผิดที่ผู้เรียนชาวไทยมักทำในภาษาจีน พร้อมวิธีตรวจจับและวิธีสอนซ้ำ
7. **HSK:** การสอบวัดระดับความรู้ภาษาจีนกลางมาตรฐานสากล (ใช้บัญชีคำศัพท์ตามมาตรฐาน HSK 3.0 / GF0025-2021)
8. **Mock Exam (ข้อสอบเสมือนจริง):** ชุดข้อสอบที่จำลองโครงสร้าง เวลา และเกณฑ์คะแนนของข้อสอบ HSK จริง เพื่อฝึกและเก็บหลักฐานการตอบป้อนแบบจำลองผู้เรียน
9. **AUC (Area Under the ROC Curve):** ตัวชี้วัดความแม่นยำเชิงทำนายของแบบจำลอง มีค่าระหว่าง 0–1 ยิ่งเข้าใกล้ 1 ยิ่งทำนายถูก-ผิดของผู้เรียนได้แม่นยำ

## 1.6 ประโยชน์ที่คาดว่าจะได้รับ

1.6.1 ได้สถาปัตยกรรมและต้นแบบของแบบจำลองผู้เรียน (Learner Model) ที่ออกแบบเป็นบริการอิสระ (frontend-agnostic engine) ซึ่งนำกลับมาใช้ซ้ำและต่อยอดไป HSK ระดับสูงขึ้นหรือภาษาอื่นได้ เป็นผลงานด้านการออกแบบระบบและวิศวกรรมซอฟต์แวร์

1.6.2 ได้องค์ความรู้และวิธีการประยุกต์เทคนิค Knowledge Tracing และ Spaced Repetition (FSRS) เข้ากับการเตรียมสอบ HSK สำหรับผู้เรียนชาวไทย ซึ่งยังไม่มีการศึกษาเฉพาะเจาะจง เป็นผลงานเชิงวิจัยที่สามารถอ้างอิงและต่อยอดได้

1.6.3 ได้ทรัพยากรเชิงคำนวณใหม่ ได้แก่ คลังความผิดเฉพาะผู้เรียนชาวไทย (Thai-L1 Error Catalog) และเมทริกซ์ทักษะ (Q-matrix) ที่จับคู่คำศัพท์/ข้อสอบกับทักษะ ซึ่งเป็นชุดข้อมูล/ฐานความรู้ที่นักวิจัยหรือผู้พัฒนารายอื่นสามารถนำไปใช้ต่อได้

1.6.4 ได้ผลการประเมินประสิทธิภาพของอัลกอริทึมเชิงปริมาณ (เช่น ค่า AUC ของการทำนาย อัตราการจดจำเทียบกับวิธีพื้นฐาน และการศึกษาแบบ ablation) ซึ่งเป็นการพิสูจน์เชิงประจักษ์ตามระเบียบวิธีทางวิทยาการคอมพิวเตอร์

1.6.5 ได้แสดงความสามารถในการบูรณาการเทคโนโลยีหลายด้านเข้าด้วยกัน ทั้งการประมวลผลภาษาธรรมชาติ (NLP ภาษาจีน) การสร้างแบบจำลองผู้เรียน/การเรียนรู้ของเครื่อง การพัฒนาเว็บแอปพลิเคชันแบบ PWA และการออกแบบฐานข้อมูลและสถาปัตยกรรมระบบ

1.6.6 ได้ฐานสำหรับการต่อยอดเชิงวิชาการในอนาคต เช่น การขยายไป HSK ระดับ 3 (เพิ่มส่วนการเขียนแบบเรียงคำและการวินิจฉัยลำดับคำ) การยกระดับเป็น Deep Knowledge Tracing การเพิ่มการประเมินการออกเสียงด้วยการประมวลผลสัญญาณเสียง หรือการขยายไปสู่ภาษาอื่น
