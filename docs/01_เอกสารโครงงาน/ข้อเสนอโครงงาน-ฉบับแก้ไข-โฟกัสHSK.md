## 1.1 ที่มาและความสำคัญของปัญหา

ปัจจุบันภาษาจีนเป็นภาษาต่างประเทศที่คนไทยเรียนเพิ่มขึ้นอย่างต่อเนื่อง และการสอบวัดระดับความรู้ภาษาจีน (HSK) ถูกใช้เป็นเกณฑ์ทั้งการศึกษาต่อและการสมัครงาน แต่ผู้เริ่มต้นที่เรียนด้วยตนเองมักไม่มีใครคอยบอกว่าตนเองอ่อนตรงไหน ควรย้อนกลับไปทบทวนอะไร และก้าวหน้าไปถึงไหนแล้ว การเรียนจึงกลายเป็นการเปิดบทเรียนผ่านไปทีละบทโดยไม่รู้ว่าคืบหน้าจริงหรือไม่ และผู้เรียนจำนวนหนึ่งเลิกกลางทางก่อนถึงวันสอบ ยิ่งไปกว่านั้นภาษาแม่ของผู้เรียนยังเป็นตัวกำหนดรูปแบบความผิดที่เกิดซ้ำ ๆ ผู้เรียนที่ใช้ภาษาแม่ต่างกันจึงมักผิดคนละจุด [9] โดยจุดพลาดที่พบบ่อยในผู้เรียนชาวไทยคือการแยกวรรณยุกต์เสียงที่ 2 กับเสียงที่ 3 ซึ่งเส้นเสียงไม่ตรงกับวรรณยุกต์ไทยตัวใดพอดี [8] เสียงม้วนลิ้น zh ch sh r ที่ไม่มีในภาษาไทย จึงมักฟังเพี้ยนเป็นเสียงไทยที่ใกล้เคียง [9] [10] [11] และการเรียงคำตามโครงสร้างประโยคไทย เช่น ตำแหน่งของคำขยาย [12] [13] ซึ่งจุดเหล่านี้ปรากฏในข้อสอบ HSK ทั้งพาร์ตการฟังและการอ่าน

หัวใจของการติวคือการมีผู้ที่จำได้ว่าผู้เรียนคนนี้พลาดเรื่องใดซ้ำ ๆ อธิบายได้ว่าผิดเพราะสาเหตุอะไร กำหนดให้กลับไปทบทวนเฉพาะเรื่องที่กำลังจะลืม และบอกได้ว่าก้าวหน้าไปถึงไหนแล้วและเหลืออีกเท่าใดจึงจะถึงเป้าหมาย หน้าที่ทั้งสี่อย่างนี้คือสิ่งที่โครงงานนี้ตั้งใจทำให้เกิดขึ้นโดยอัตโนมัติ ในเว็บแอปพลิเคชันที่ออกแบบเจาะจงสำหรับผู้เรียนชาวไทย

คณะผู้จัดทำจึงเสนอพัฒนาเว็บแอปพลิเคชันติวภาษาจีน "จีนรู้ใจ" ที่ทำหน้าที่เสมือนติวเตอร์ส่วนตัวของผู้เรียนแต่ละคน สำหรับผู้เรียนชาวไทยที่ยังไม่มีพื้นฐาน ทั้งผู้ที่ต้องการเรียนภาษาจีนขั้นต้นและผู้ที่ตั้งเป้าสอบ HSK ระดับ 1–2 โดยเริ่มปูจากระบบเสียงและวรรณยุกต์ก่อน แล้วจึงไล่ระดับสู่คำศัพท์และประโยค ระบบใช้แบบจำลองผู้เรียน (Learner Model) ร่วมกับสามแนวคิดที่ทำหน้าที่แทนติวเตอร์คนละด้าน ได้แก่ การติดตามความรู้ของผู้เรียน (Knowledge Tracing) ซึ่งจำว่าผู้เรียนแม่นหรืออ่อนทักษะย่อยใด [1] [2] การวิเคราะห์เปรียบต่างไทย-จีน (Contrastive Analysis) ซึ่งอธิบายว่าที่ผิดนั้นเกิดจากภาษาแม่อย่างไร [9] และการทบทวนแบบเว้นช่วง (Spaced Repetition) ซึ่งกำหนดว่าควรกลับมาทบทวนคำใดเมื่อใดก่อนที่จะลืม [3] [5] ทั้งนี้การยึดรูปแบบข้อสอบ HSK เป็นกรอบทำให้ทุกข้อมีเฉลยตายตัว ระบบจึงตรวจคำตอบด้วยกติกาเทียบเฉลยได้เองโดยไม่ต้องใช้ปัญญาประดิษฐ์ตัดสิน และแสดงความก้าวหน้าให้ผู้เรียนเห็นได้ตลอดจนเดินต่อไปจนถึงวันสอบ

## 1.2 วัตถุประสงค์

1.2.1 เพื่อพัฒนาเว็บแอปพลิเคชันที่ทำหน้าที่เสมือนติวเตอร์ส่วนตัวสำหรับผู้เรียนชาวไทยที่ยังไม่มีพื้นฐานภาษาจีน ครอบคลุมตั้งแต่บทเรียนพื้นฐานเสียงที่เทียบพินอินกับเสียงภาษาไทยและวรรณยุกต์ 4 เสียง ไปจนถึงการเตรียมสอบ HSK ระดับ 1–2 ในรูปแบบที่ติดตั้งลงหน้าจอมือถือได้และใช้ทบทวนต่อได้แม้สัญญาณอินเทอร์เน็ตไม่เสถียร พร้อมระบบสมาชิกสำหรับเก็บความก้าวหน้ารายบุคคล และระบบผู้ดูแลสำหรับจัดการคำศัพท์ บทเรียน และแบบทดสอบ

1.2.2 เพื่อพัฒนาแบบจำลองผู้เรียน (Learner Model) ที่ประเมินว่าผู้เรียนแต่ละคนแม่นหรืออ่อนในทักษะย่อยใด ด้วยเทคนิคการติดตามความรู้ของผู้เรียน (Knowledge Tracing) โดยเรียนรู้จากข้อมูลการตอบของผู้เรียนชาวไทยที่ระบบเก็บเอง

1.2.3 เพื่อสร้างคลังข้อผิดพลาดเฉพาะผู้เรียนชาวไทย (Thai-L1 Error Catalog) พร้อมตารางจับคู่ข้อสอบกับทักษะ (Q-matrix) สำหรับวินิจฉัยว่าผู้เรียนตอบผิดเพราะสาเหตุใด แล้วเสริมแบบฝึกซ่อมให้ตรงจุด

1.2.4 เพื่อจัดตารางทบทวนคำศัพท์เฉพาะบุคคลตามหลักการทบทวนแบบเว้นช่วง (Spaced Repetition) ด้วยอัลกอริทึม FSRS พร้อมแสดงความก้าวหน้ารายทักษะว่าผู้เรียนแม่นทักษะใดแล้วและเหลือทักษะใดที่ต้องทบทวน และประมาณการจากผลการตอบจริงว่าเหลือเวลาอีกประมาณเท่าใดจึงจะเรียนครบตามเป้าหมายของระดับ

1.2.5 เพื่อพัฒนาแบบฝึกและการวัดผลตามรูปแบบข้อสอบ HSK ได้แก่ แบบฝึกรายทักษะ ควิซท้ายหมวดสำหรับเก็บคะแนนระหว่างเรียน และข้อสอบจำลองแบบจับเวลาที่ให้คะแนนตามเกณฑ์จริง โดยทุกข้อตรวจด้วยกติกาเทียบเฉลยที่กำหนดไว้ล่วงหน้า ไม่ใช้ปัญญาประดิษฐ์ตัดสินคำตอบ

1.2.6 เพื่อประเมินผลของระบบด้วยการทดลองกับผู้เรียนจริง โดยเปรียบเทียบคะแนนข้อสอบจำลองก่อนเรียนกับหลังเรียน ร่วมกับการวัดความแม่นยำเชิงทำนายของแบบจำลอง (ค่า AUC) และการทดลองปิดส่วนประกอบ (ablation) เพื่อดูว่าคลังข้อผิดพลาดเฉพาะคนไทยช่วยให้ระบบทำนายได้แม่นขึ้นจริงหรือไม่

## 1.3 ฮาร์ดแวร์ ซอฟต์แวร์ เครื่องมือ และเทคโนโลยี

### 1.3.1 ฮาร์ดแวร์ (Hardware)
- เครื่องคอมพิวเตอร์โน้ตบุ๊ก (Notebook Computer) จำนวน 2 เครื่อง
  - Lenovo Legion 5 16IRX9 (มีการ์ดจอแยก)
  - Lenovo IdeaPad Slim 5i
- หูฟังหรือลำโพง สำหรับตรวจสอบคุณภาพสื่อการฟัง

### 1.3.2 ภาษาและฐานข้อมูลที่ใช้ในการพัฒนา (Programming Languages and Database)
- TypeScript — ส่วนติดต่อผู้ใช้ (เว็บ)
- Python — ส่วนประมวลผลหลังบ้าน แบบจำลองผู้เรียน และสคริปต์เตรียมข้อมูล
- SQL (PostgreSQL ผ่านบริการ Supabase) — ฐานข้อมูลคำศัพท์ ผู้ใช้ และบันทึกการตอบทุกข้อ

### 1.3.3 เฟรมเวิร์กและไลบรารีหลัก (Frameworks and Core Libraries)
- Next.js / React + Tailwind CSS — พัฒนาเว็บแอปแบบ Progressive Web App ติดตั้งลงหน้าจอมือถือได้
- FastAPI (Python) — พัฒนาส่วนบริการหลังบ้าน แยกออกจากส่วนหน้าจอเพื่อให้นำไปใช้ซ้ำได้
- pyBKT — ไลบรารีการติดตามความรู้ของผู้เรียนแบบเบย์ (Bayesian Knowledge Tracing)
- ts-fsrs / py-fsrs — ไลบรารีจัดตารางทบทวนแบบเว้นช่วงด้วยอัลกอริทึม FSRS [7]
- jieba — ตัดคำภาษาจีน สำหรับควบคุมระดับคำศัพท์ในโจทย์
- pypinyin — แปลงอักษรจีนเป็นพินอินพร้อมวรรณยุกต์
- edge-tts — สังเคราะห์เสียงอ่านภาษาจีนสำหรับสื่อการฟังและข้อสอบฟัง

### 1.3.4 บริการปัญญาประดิษฐ์ (AI Services)
- โมเดลภาษาขนาดใหญ่ (LLM) เช่น Gemini แบบไม่เก็บสถานะ (stateless) เรียกใช้จากฝั่งเซิร์ฟเวอร์ — ใช้เป็นส่วนเสริมช่วยร่างคำอธิบายภาษาไทยและตัวอย่างประโยคเท่านั้น ไม่ใช้ตัดสินคำตอบของผู้เรียน
- Ollama (เครื่องมือรันโมเดลภาษาในเครื่องของผู้พัฒนา) — ทางเลือกที่วางแผนจะทดลองในเฟสถัดไป ไม่ใช่ส่วนที่ระบบหลักต้องพึ่งพา

### 1.3.5 เครื่องมือพัฒนา ทดสอบ และบริการที่ใช้ให้บริการระบบ (Development, Testing and Deployment)
- Visual Studio Code — โปรแกรมเขียนโค้ด
- Git และ GitHub — ควบคุมเวอร์ชันและทำงานร่วมกันสองคน
- Node.js และ npm — จัดการแพ็กเกจและรันสคริปต์
- Supabase (ฐานข้อมูลและระบบสมาชิก), Vercel (ให้บริการเว็บ), Render (ให้บริการส่วนหลังบ้าน) — ใช้แพ็กเกจฟรีทั้งหมด
- ชุดข้อมูลคำศัพท์ HSK 3.0 และพจนานุกรม CC-CEDICT — ใช้เป็นคลังคำตั้งต้น

## 1.4 วิธีการศึกษา

1.4.1 ศึกษาทฤษฎีและงานวิจัยที่เกี่ยวข้อง ได้แก่ การทบทวนแบบเว้นช่วง การติดตามความรู้ของผู้เรียน การเปรียบเทียบระบบเสียงกับไวยากรณ์ไทย-จีน การเรียนรู้ด้วยการทดสอบซึ่งใช้เป็นหลักการของควิซท้ายหมวด [6] และการฝึกการรับรู้เสียงด้วยคู่เสียงต่างกันจุดเดียวซึ่งใช้เป็นหลักการของแบบฝึกพื้นฐานเสียง [14] รวมถึงศึกษาเกณฑ์และเอกสารทางการของ HSK เพื่อใช้เป็นแหล่งอ้างอิงของเนื้อหาทุกส่วน

1.4.2 ศึกษาเครื่องมือและไลบรารีที่ใช้พัฒนา รวมถึงการเรียกใช้โมเดลภาษาขนาดใหญ่จากฝั่งเซิร์ฟเวอร์

1.4.3 วางกรอบเนื้อหาของระบบตามโครง เนื้อหา × ทักษะ × ระดับ คือกำหนดจำนวนหมวด จำนวนคำต่อหมวด และนิยามของแต่ละทักษะในระดับ 1 กับระดับ 2 ตามเกณฑ์ทางการ (ผลของขั้นนี้แสดงไว้ในภาคผนวก ข)

1.4.4 รวบรวมและจัดเตรียมคลังคำศัพท์ตามระดับการสอบ พร้อมจัดทำคลังความผิดเฉพาะคนไทย (Thai-L1 Error Catalog) และตารางจับคู่ข้อสอบกับทักษะ (Q-matrix) โดยผู้ร่วมพัฒนาที่เชี่ยวชาญภาษาจีนตรวจสอบความถูกต้องทุกรายการ รวมถึงตรวจพินอินที่แปลงด้วยเครื่องมืออัตโนมัติ เนื่องจากอักษรพ้องรูปหลายเสียงอาจแปลงผิด

1.4.5 ออกแบบฐานข้อมูลและโครงสร้างของระบบ โดยแยกส่วนแบบจำลองผู้เรียนออกจากส่วนติดต่อผู้ใช้เพื่อให้นำกลับมาใช้ซ้ำได้ และออกแบบให้ทุกการตอบของผู้เรียนถูกบันทึกเป็นข้อมูลหนึ่งรายการ (ใคร ข้อไหน ทักษะอะไร ถูกหรือผิด ใช้เวลาเท่าไร มาจากโหมดใด) เพื่อใช้ต่อทั้งการวินิจฉัย การทบทวน และการวิจัย

1.4.6 พัฒนาแบบจำลองผู้เรียน ได้แก่ การประเมินความแม่นยำรายทักษะ การวินิจฉัยจุดที่ผิดด้วยคลังความผิดของคนไทย และการจัดตารางทบทวนแบบเว้นช่วง

1.4.7 ศึกษาอัตราการเรียนรู้คำศัพท์ภาษาจีนจากเอกสารและงานวิจัยที่อ้างอิงได้ แล้วพัฒนาการประมาณการเวลาเรียนที่เหลือรายบุคคล โดยคำนวณจากจำนวนคำและทักษะที่ยังไม่ผ่าน เทียบกับอัตราการเรียนจริงของผู้เรียนคนนั้น

1.4.8 พัฒนาเว็บแอปพลิเคชัน ได้แก่ บทเรียนพื้นฐานเสียงและวรรณยุกต์ บัตรคำรายหมวด แบบฝึกทักษะฟัง-อ่าน-ประกอบภาษา ควิซท้ายหมวด ข้อสอบจำลอง หน้าสรุปผลการเรียน ระบบสมาชิกกับผู้ดูแลระบบ และการแคชข้อมูลลงเครื่องเพื่อใช้งานต่อเมื่อสัญญาณไม่เสถียร พร้อมสร้างคลังข้อสอบที่ผ่านการตรวจโดยผู้ร่วมพัฒนาที่เชี่ยวชาญภาษาจีน

1.4.9 ทดลองใช้งานกับผู้เรียนจริงประมาณ 5–10 คน ซึ่งคัดจากผู้ที่ยังไม่มีพื้นฐานหรือมีพื้นฐานเพียงเล็กน้อย โดยให้ทำข้อสอบจำลองก่อนเรียนแบบไม่เฉลยรายข้อ ใช้แอปต่อเนื่องประมาณ 10 วัน แล้วทำข้อสอบชุดเดิมอีกครั้งหลังเรียน พร้อมเก็บบันทึกการตอบทั้งหมดและบันทึกว่าผู้เข้าร่วมเรียนภาษาจีนจากแหล่งอื่นควบคู่ไปด้วยหรือไม่

1.4.10 ประเมินผลด้วยการทดลอง โดยด้านผู้เรียนเทียบคะแนนก่อนเรียนกับหลังเรียนของผู้ทดลองแต่ละคน ส่วนด้านแบบจำลองดำเนินเป็นสองขั้น คือพิสูจน์ว่ากระบวนการวัดทำงานถูกต้องด้วยชุดข้อมูลการตอบของผู้เรียนภาษาที่เผยแพร่สาธารณะก่อน [4] แล้วจึงวัดซ้ำบนข้อมูลผู้เรียนไทยที่เก็บได้จริง พร้อมทดลองปิดส่วนประกอบเพื่อดูว่าคลังความผิดเฉพาะคนไทยมีผลต่อความแม่นเพียงใด จากนั้นปรับปรุงระบบและจัดทำรายงาน ทั้งนี้เนื่องจากกลุ่มผู้ทดลองมีขนาดเล็ก ไม่มีกลุ่มควบคุม และช่วงทดลองสั้นกว่าแผนการเรียนเต็มรูปแบบของระดับ 1 ซึ่งใช้เวลาประมาณ 8 สัปดาห์ ผลด้านผู้เรียนจึงรายงานเป็นแนวโน้มการเปลี่ยนแปลงของคะแนน ไม่ใช่ข้อสรุปว่าผู้เรียนสอบผ่านได้ภายในระยะเวลาที่ทดลอง

## 1.5 ขอบเขตของโครงงานที่พัฒนาและคำจำกัดความ

### 1.5.1 ขอบเขตของโครงงาน

โครงงานนี้พัฒนาเป็นเว็บแอปพลิเคชันที่ติดตั้งลงหน้าจอมือถือได้และใช้ทบทวนต่อได้แม้ไม่มีอินเทอร์เน็ต สำหรับผู้เรียนชาวไทยที่ยังไม่มีพื้นฐานภาษาจีนหรือมีพื้นฐานเพียงเล็กน้อย ทั้งกรณีเรียนด้วยตนเองและกรณีที่ครูผู้สอนใช้เป็นสื่อเสริม ครอบคลุมการเตรียมสอบ HSK ระดับ 1–2 ตามระบบ HSK 3.0 มีผู้จัดทำ 2 คน ใช้เวลาประมาณ 4 เดือน โดยแบ่งการทำงานเป็นโมดูลดังนี้

1. **โมดูลพื้นฐานเสียง:** สอนพินอินโดยเทียบกับเสียงภาษาไทย (เช่น b–ปอ p–ผอ m–มอ) และวรรณยุกต์ 4 เสียง พร้อมแบบฝึกแยกคู่เสียงต่างกันจุดเดียว (Minimal Pair) ที่ผู้เรียนชาวไทยมักสับสน
2. **คลังคำศัพท์และบัตรคำ:** จัดเก็บคำศัพท์ HSK พร้อมพินอิน ความหมายภาษาไทย เสียงอ่าน และประโยคตัวอย่าง แบ่งเป็น 5 หมวดตามบริบทการใช้งาน (ภาคผนวก ข)
3. **แบบฝึกรายทักษะ:** แบบฝึกการฟังและการอ่านตามรูปแบบข้อสอบ พร้อมแบบฝึกเรียงคำและเติมคำเพื่อดักไวยากรณ์ที่ถ่ายโอนจากภาษาไทย
4. **แบบจำลองผู้เรียน:** ประเมินความแม่นยำรายทักษะ ทั้งตัวคำ วรรณยุกต์ พยัญชนะ และไวยากรณ์ ด้วยวิธีติดตามความรู้ของผู้เรียน โดยเชื่อมข้อสอบกับทักษะผ่านตารางจับคู่ข้อสอบกับทักษะ (Q-matrix)
5. **การวินิจฉัยจุดอ่อนเฉพาะคนไทย:** เทียบข้อที่ตอบผิดกับคลังความผิดเฉพาะคนไทย (Thai-L1 Error Catalog) เพื่อระบุสาเหตุ แล้วสอนและฝึกซ้ำเฉพาะจุดที่ยังพลาด
6. **การจัดตารางทบทวนและประมาณการเวลาเรียน:** ใช้หลักทบทวนแบบเว้นช่วงกำหนดว่าควรทบทวนคำหรือทักษะใดเมื่อใด และประมาณการว่าเหลืออีกกี่วันจึงจะเรียนครบตามเป้าหมาย
7. **การวัดผลและข้อสอบจำลอง:** ควิซท้ายหมวดสำหรับเก็บคะแนนระหว่างเรียน และข้อสอบจำลองแบบจับเวลาที่ให้คะแนนตามเกณฑ์จริง โดยตรวจด้วยกติกาเทียบเฉลย ไม่ใช้ปัญญาประดิษฐ์ตัดสินคำตอบ
8. **หน้าสรุปความคืบหน้า:** แสดงทักษะที่แม่นแล้ว ทักษะที่ต้องทบทวน จุดอ่อนแบบคนไทยที่ตรวจพบ และความพร้อมสอบโดยประมาณ
9. **ระบบสมาชิกและผู้ดูแลระบบ:** สมัครสมาชิกเพื่อเก็บความก้าวหน้ารายบุคคล และส่วนผู้ดูแลสำหรับจัดการคำศัพท์ บทเรียน และแบบทดสอบ
10. **การใช้งานบนมือถือและการแคชข้อมูล:** ติดตั้งลงหน้าจอมือถือได้ และเปิดบทเรียน บัตรคำ กับคิวทบทวนได้แม้ไม่มีอินเทอร์เน็ต โดยซิงก์ผลการตอบเมื่อกลับมาออนไลน์

ส่วนที่จัดเป็นงานในอนาคต ได้แก่ การประเมินการออกเสียงจากเสียงพูดจริงและการแสดงเส้นเสียง แบบฝึกแต่งประโยคปลายเปิดที่ตรวจด้วยปัญญาประดิษฐ์ คู่สนทนาภาษาจีนที่ขับเคลื่อนด้วยปัญญาประดิษฐ์ การขยายไป HSK ระดับ 3 ขึ้นไป และการสแกนอักษรจีนจากกล้อง

### 1.5.2 คำจำกัดความ

1. **Learner Model (แบบจำลองผู้เรียน)** แบบจำลองที่เก็บสถานะความรู้ของผู้เรียนรายบุคคล ประกอบด้วยความแม่นยำรายทักษะ จุดอ่อน และประวัติการตอบ
2. **Knowledge Tracing (การติดตามความรู้ของผู้เรียน)** เทคนิคที่ประเมินและทำนายว่าผู้เรียนจะตอบทักษะถัดไปถูกหรือไม่ จากประวัติการตอบที่ผ่านมา
3. **Mastery (ความแม่นยำรายทักษะ)** ระดับความเชี่ยวชาญของผู้เรียนต่อทักษะย่อยหนึ่ง ๆ เช่น การแยกวรรณยุกต์เสียง 2 กับเสียง 3 คำนวณด้วยวิธี Bayesian Knowledge Tracing (pyBKT)
4. **Q-matrix (ตารางจับคู่ข้อสอบกับทักษะ)** ตารางที่ระบุว่าข้อสอบแต่ละข้อวัดทักษะย่อยใดบ้าง ใช้เชื่อมผลการตอบเข้ากับแบบจำลองผู้เรียน
5. **Spaced Repetition (การทบทวนแบบเว้นช่วง)** วิธีจัดตารางทบทวนตามเส้นโค้งการลืม เพื่อให้ทบทวนก่อนจะลืมพอดี โดยใช้อัลกอริทึม FSRS
6. **Thai-L1 / L1 Transfer (การถ่ายโอนจากภาษาแม่)** อิทธิพลของภาษาแม่ (ภาษาไทย) ที่ส่งผลต่อรูปแบบความผิดพลาดในการเรียนภาษาจีน
7. **Thai-L1 Error Catalog (คลังความผิดเฉพาะคนไทย)** ชุดข้อมูลรูปแบบความผิดที่ผู้เรียนชาวไทยมักทำในภาษาจีน พร้อมสาเหตุ วิธีตรวจจับ และวิธีสอนซ้ำ
8. **Minimal Pair (คู่เสียงต่างกันจุดเดียว)** คู่คำที่ต่างกันเพียงเสียงเดียวหรือวรรณยุกต์เดียว ใช้เป็นแบบฝึกและเครื่องมือวินิจฉัยว่าผู้เรียนแยกเสียงคู่ใดไม่ออก โดยไม่ต้องใช้ระบบรู้จำเสียงพูด
9. **HSK** การสอบวัดระดับความรู้ภาษาจีนกลางมาตรฐานสากล โครงงานนี้ยึดระบบ HSK 3.0 โดยใช้มาตรฐาน 《国际中文教育中文水平等级标准》(GF0025-2021) [15] เป็นกรอบระดับความสามารถ และใช้บัญชีคำศัพท์กับโครงสร้างข้อสอบตามหลักสูตรการสอบ (考试大纲) ฉบับเดือนพฤศจิกายน ค.ศ. 2025 [16] ซึ่งเริ่มทดลองจัดสอบทั่วโลกเมื่อวันที่ 31 มกราคม ค.ศ. 2026 เป็นตัวกำหนดจำนวนคำที่นำมาสอนและออกข้อสอบ คือระดับ 1 จำนวน 300 คำ (ไวยากรณ์ 48 จุด) และระดับ 2 สะสม 500 คำ (ไวยากรณ์ 129 จุด) ทั้งนี้บัญชีคำของเอกสารทั้งสองฉบับเป็นคนละชุดกัน (ตัวมาตรฐานกำหนดระดับ 1 ไว้ 500 คำ) โครงงานนี้จึงยึดตัวเลขจากหลักสูตรการสอบ ซึ่งเป็นบัญชีที่ข้อสอบใช้จริง
10. **Mock Exam (ข้อสอบจำลอง)** ชุดข้อสอบที่จำลองโครงสร้าง เวลา และเกณฑ์คะแนนของข้อสอบ HSK จริง (ระดับ 1 มี 40 ข้อ คะแนนเต็ม 200 ผ่านที่ 120) ใช้ทั้งวัดความพร้อมของผู้เรียนและเก็บข้อมูลป้อนแบบจำลองผู้เรียน
11. **AUC (Area Under the ROC Curve)** ตัวชี้วัดความแม่นยำเชิงทำนายของแบบจำลอง มีค่าระหว่าง 0 ถึง 1 ยิ่งเข้าใกล้ 1 ยิ่งทำนายถูก-ผิดของผู้เรียนได้แม่นยำ

## 1.6 ประโยชน์ที่คาดว่าจะได้รับ

1.6.1 ผู้เรียนชาวไทยที่ยังไม่มีพื้นฐานมีเส้นทางเตรียมสอบที่ต่อเนื่องตั้งแต่การอ่านพินอินจนถึงการทำข้อสอบจำลองตามเกณฑ์จริง และตอบได้ด้วยคะแนนของตนเองว่าพร้อมเข้าสอบหรือยัง โดยไม่มีค่าใช้จ่าย

1.6.2 ผู้เรียนใช้เวลาทบทวนได้คุ้มค่าขึ้น เพราะได้ฝึกเฉพาะทักษะที่ยังไม่ผ่านและคำที่กำลังจะลืม แทนการไล่ทบทวนทุกคำและทุกบทเท่ากันหมด และทราบล่วงหน้าว่าเหลือเวลาอีกประมาณเท่าใดจึงจะเรียนครบตามเป้าหมาย

1.6.3 ผู้เรียนทราบสาเหตุของความผิดพลาดของตนเอง เช่น การสับสนวรรณยุกต์เสียงที่ 2 กับเสียงที่ 3 หรือการเรียงคำตามโครงสร้างประโยคภาษาไทย จึงแก้ไขได้ตรงจุดกว่าการทราบเพียงจำนวนข้อที่ตอบผิด ซึ่งจากการสำรวจแอปพลิเคชันและเว็บไซต์ที่ผู้เรียนชาวไทยเข้าถึงได้ ณ ปี พ.ศ. 2569 ยังไม่พบเจ้าใดที่ให้ข้อมูลระดับนี้ (ภาคผนวก ก)

1.6.4 ครูผู้สอนภาษาจีนมีสื่อเสริมที่มอบหมายให้ผู้เรียนฝึกนอกเวลาเรียนได้โดยไม่มีค่าใช้จ่าย และผู้เรียนใช้ทบทวนต่อได้แม้สัญญาณอินเทอร์เน็ตไม่เสถียร

1.6.5 นักวิจัยและผู้พัฒนารายอื่นได้ฐานความรู้ชุดใหม่ที่เผยแพร่เป็นชุดข้อมูลเปิด ได้แก่ คลังความผิดเฉพาะคนไทย (Thai-L1 Error Catalog) และตารางจับคู่ข้อสอบกับทักษะ (Q-matrix) พร้อมคำตอบเชิงประจักษ์จากการทดลองปิดส่วนประกอบว่าการวินิจฉัยตามภาษาแม่ช่วยให้แบบจำลองทำนายผู้เรียนได้แม่นขึ้นเพียงใด

1.6.6 คณะผู้จัดทำได้สถาปัตยกรรมและต้นแบบของแบบจำลองผู้เรียนที่แยกเป็นบริการต่างหากจากหน้าจอแสดงผล จึงนำกลับมาใช้ซ้ำกับระดับที่สูงขึ้นหรือภาษาอื่นได้ พร้อมประสบการณ์บูรณาการการประมวลผลภาษาจีน การเรียนรู้ของเครื่อง การพัฒนาเว็บแอปพลิเคชัน และการออกแบบฐานข้อมูลเข้าด้วยกัน
