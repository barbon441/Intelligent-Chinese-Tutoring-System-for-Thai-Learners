| หน้า | เนื้อหา |

| **Dashboard** | การ์ดสรุป (ระดับ HSK 0/1/2, XP, หน่วย x/5, ศัพท์ x/30, streak) + **กราฟคะแนนรายทักษะ (Chart.js)** + การ์ด 5 บทเรียน |

| **บทเรียน** (5 หน่วยธีม: รู้จักภาษาจีน/ครอบครัว/อาหาร/เวลา/เดินทาง) | ศัพท์ 6 คำ/หน่วย (ฮั่นจื้อ+พินอิน+ไทย+TTS) + แบบฝึกฟัง/พูด/ไวยากรณ์ + **เรียงลำดับคำ** |

## ✅ ตรงกับทิศทางเรา (สัญญาณดี — อาจารย์คิดใกล้เรา)
- เป้าหมาย HSK 1–2 สำหรับคนไทยเริ่มจากศูนย์ + UI ไทยทั้งหมด
- **ตรวจคำตอบด้วย rule เทียบเฉลยทั้งหมด ไม่มี LLM ตรวจ** (ตรงหลักการเราเป๊ะ)
- มี placement/pre-test + **วัดผลแยกรายทักษะ + กราฟ** (= สิ่งที่อาจารย์อยากเห็น!)
- เก็บ state ฝั่ง client (แนว offline)

## ⚠️ ขัดกับทิศทางเรา (ต้องคุย/ไม่เอาตาม)
1. **มีข้อสอบพูด 10/25 (40%) + ASR** — ขัดข้อตกลง (HSK 1–2 ไม่มีสอบพูด, เราตัด ASR เป็น future work) และ ASR เทียบ string ตรงตัว = ไม่ rigorous + ต้องออนไลน์
2. **ข้อฟังเฉลยตัวเอง** — โจทย์โชว์พินอิน/ฮั่นจื้อ ไม่ต้องฟังก็ตอบได้ (ของเราต้อง audio-only + minimal pair)
3. **เกณฑ์ 12/25, 18/25 เป็นเลขสมมติ** (ของเราใช้เกณฑ์จริง 120/200) + ไม่มีจับเวลา
4. **tag ระดับศัพท์ผิด** (吃/喝/水/茶 ถูก tag HSK2 ทั้งที่เป็น HSK1) และไม่อิงมาตรฐาน 3.0
5. **ไม่มีแกนวิชาการของเรา** — ไม่มี BKT / FSRS / Thai-L1 / Q-matrix (เป็นแอปฝึกทั่วไป ไม่ใช่ติวเตอร์วินิจฉัย)

## 🐛 บั๊กที่เจอ (เผื่ออาจารย์ถาม/เผื่อโดนใช้ต่อ)
- แบบฝึก**เรียงลำดับคำไม่ถูกตรวจเลย** (checkUnitExercises วนไม่ถึง index ของมัน)
- อ้าง "25 ข้อ/หน่วย" แต่จริงมี 17 · ไวยากรณ์ template เดิมซ้ำทุกหน่วย · streak ไม่เคยนับ (0 ตลอด)
- เปิดหน่วยใหม่แล้วคำตอบเก่าถูกล้างหมด · distractor ข้อฟังซ้ำหน้าเดิม · พึ่ง CDN + ASR ออนไลน์ (ขัด PWA offline)

## 💡 ไอเดียที่ควรเอามาใช้ในแอปจริง
1. **กราฟรายทักษะบน Dashboard** (คะแนนคุณ vs เต็ม) → ต่อยอดเป็นกราฟ mastery จาก pyBKT
2. **UX ข้อสอบทีละข้อ** + progress bar + ย้อนแก้ + คำตอบ persist → ใช้กับ Mock Exam (เพิ่มจับเวลา)
3. **Interaction เรียงลำดับคำ** (คลิก pool↔บรรทัด) → ใช้กับข้อ 排列顺序 (แต่ตรวจให้จริง)
4. หน่วยเรียนจัดตามธีมชีวิตประจำวัน → แนวจัดกลุ่มคำ HSK 3.0
5. Gamification เบา ๆ (XP/streak/feedback ✅❌ รายข้อ) + แสดงเกณฑ์ผ่านบน Dashboard (เปลี่ยนเป็น 120/200)
6. Pattern `safeStorage` (fallback + defensive load) → ใช้กับ Dexie layer
