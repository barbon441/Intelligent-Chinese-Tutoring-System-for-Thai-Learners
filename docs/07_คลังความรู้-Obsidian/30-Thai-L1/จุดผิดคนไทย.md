# จุดผิดคนไทย (Thai-L1 Error Catalog)

## คืออะไร
**Thai-L1** = จุดผิดภาษาจีนที่เกิดจาก "ภาษาแม่" ของผู้เรียน (L1 = first language = ภาษาไทย) ถ่ายโอนมาแทรก — เรียกว่า **language transfer** พูดง่าย ๆ คือ สมองเอานิสัยภาษาไทยไปใช้กับภาษาจีน แล้วพลาดในจุดที่สองภาษาไม่เหมือนกัน
นี่คือ **จุดขายหลักของโปรเจกต์** — แอปใหญ่สอนเหมือนกันทุกชาติ ไม่มีใครวินิจฉัยตามภาษาแม่ไทย (ดู [[เทียบคู่แข่ง-2026]])

## จุดผิดหลัก 3 กลุ่ม (มีงานวิจัยรองรับทั้งหมด)

| กลุ่ม | เกิดอะไร | ทำไมคนไทยพลาด |
|---|---|---|
| 1. วรรณยุกต์ **เสียง 2/3 สับสน** | แยกคู่ใกล้ 2 กับ 3 ไม่ออก | contour (เส้นเสียง) ของจีนไม่ตรงกับวรรณยุกต์ไทยตัวไหนพอดี — Rungruang 2017: เสียง 3 ยากสุด เสียง 2 รองลงมา |
| 2. พยัญชนะม้วนลิ้น **zh/ch/sh/r** | ออก/ฟังเพี้ยนเป็น j/ch/s ธรรมดา | ไทย**ไม่มีเสียง retroflex** เลย → แทนด้วยเสียงไทยที่ใกล้สุด — Suphasa & Chi 2017: ผิดสูงสุด |
| 3. **ไวยากรณ์ถ่ายโอน** | เรียงคำผิด เช่น คำขยาย จีนวาง**หน้า**คำนาม แต่ไทยวาง**หลัง** | เอาลำดับคำไทยไปใช้ตรง ๆ — งานผู้เรียนไทยยืนยันข้อผิดบทเสริม 补语 (Pichaichanlert 2022) ⚠️ ~~ตัวเลข 48% เดิมยืนยันไม่ได้ ตัดทิ้ง~~ ดู [[งานวิจัยอ้างอิง]] |

⚠️ จุดสำคัญตอนตอบกรรมการ: คนไทยมีวรรณยุกต์อยู่แล้วจริง → **perception (การฟัง) ได้เปรียบ** แต่ **production + คู่เสียงใกล้ (2/3) ยังพลาด** เพราะ contour ไม่ตรงกับไทย — อย่าเหมารวมว่า "คนไทยได้วรรณยุกต์อัตโนมัติ"

- 📄 ให้หฤทัยตรวจ: `data/thai-l1/REVIEW-thai-l1-สำหรับหฤทัย.md`
- 🗂️ ข้อมูลดิบ: `data/thai-l1/catalog-v1.json` (= Q-matrix seed 15 KC) · ผลตรวจ citation: `data/thai-l1/citation-audit.md`
- KC 3 กลุ่ม: วรรณยุกต์ (T2/T3 + sandhi), retroflex (zh/ch/sh/r + merge平/翘舌), ไวยากรณ์ (的-order, ลักษณนาม, 补语, 了, 状语)

## คลัง = Error Catalog + Q-matrix
เก็บเป็นรายการที่มีโครงสร้างชัด แต่ละรายการประกอบด้วย:

1. **จุดผิด** — อธิบายว่าอะไรผิด
2. **ตัวอย่าง** — ประโยค/คำจริงที่พลาด
3. **สาเหตุ** — อธิบายด้วย transfer จากภาษาไทย
4. **ทักษะที่ผูก** — โยงเข้า Knowledge Component ของ [[pyBKT]] ผ่าน Q-matrix
5. **วิธีเจาะสอน** — แบบฝึกที่ตรงจุด (เช่น minimal pair สำหรับหู — ดู [[รูปแบบข้อสอบ-HSK-1-2]])
6. **หลักฐาน** — อ้างอิงงานวิจัยจริง (ดู [[งานวิจัยอ้างอิง]] — ห้ามแต่งเอง)

## สร้างจากอะไร
- 📚 งานวิจัยที่ตรวจสอบแล้ว ([[งานวิจัยอ้างอิง]])
- 🗂️ learner corpus ที่มีคนไทย ([[Datasets]])
- 🔍 ทฤษฎี contrastive analysis (เทียบระบบเสียง/ไวยากรณ์ ไทย vs จีน)
- 👥 ข้อมูลผู้ใช้จริงที่แอปเก็บเอง (ยิ่งใช้ยิ่งแม่น)

**กฎเหล็ก:** ทุกรายการต้องผ่านการตรวจโดย**หฤทัย** (สอบ HSK 5 แล้ว — เรื่องความถูกต้องภาษาจีนให้เธอตัดสิน) ก่อนเข้าเล่ม/เข้า item bank เสมอ

## เป็น contribution ได้ด้วย
คลังนี้เผยแพร่เป็น **open dataset** ได้ (GitHub + ขอ DOI ผ่าน Zenodo ฟรี) → กลายเป็นผลงานวิชาการที่คนอื่นอ้างอิงต่อได้ ไม่ใช่แค่ฟีเจอร์ในแอป
