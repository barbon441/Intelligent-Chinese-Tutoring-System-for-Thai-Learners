# NLP-จีน-และเสียง

**คืออะไร:** ชุดเครื่องมือโอเพนซอร์ส (ฟรีทั้งหมด) ที่เราใช้จัดการ "ตัวอักษรจีน → พินอิน → เสียง → ความหมายไทย" ในแอป星航 — ส่วนใหญ่รันฝั่ง [[FastAPI]]

## เครื่องมือหลัก 5 ตัว

| เครื่องมือ | ทำอะไร | ใช้ตรงไหนในโปรเจกต์ |
|---|---|---|
| **jieba** | ตัดคำภาษาจีน (word segmentation) | คุมระดับคำศัพท์ในข้อสอบอ่าน — เช็กว่าประโยคใช้แต่คำในโควตา HSK 1–2 (ดู [[HSK-3.0-ข้อเท็จจริง]]) |
| **pypinyin** | แปลงอักษรจีน → พินอินพร้อมวรรณยุกต์ | ข้อสอบ HSK 1–2 มี pinyin กำกับอยู่แล้ว → ใช้สร้างบัตรคำ/ข้อสอบอัตโนมัติ |
| **CC-CEDICT** | ดิกชันนารีจีน–อังกฤษ (โหลดจาก mdbg.net) | ตัวอ้างอิงความหมายให้ AI แปลไทย "ทีเดียว" — **ไม่แปลทอดต่อทอด** จีน→อังกฤษ→ไทย |
| **hanzi-writer** | แสดง/ฝึกลายเส้นตัวอักษรจีน (JS, ฝั่งเว็บ) | โชว์ stroke order ในบัตรคำ (รันใน [[Next.js-PWA]]) |
| **edge-tts** | สังเคราะห์เสียงอ่านภาษาจีน (TTS) | เสียงอ่านบัตรคำ + ข้อสอบฟัง + minimal pair วรรณยุกต์ 2/3, zh/ch/sh (ดู [[จุดผิดคนไทย]]) |

## ข้อควรระวังสำคัญ

- **CC-CEDICT เป็น CC BY-SA** → ต้องใส่เครดิตในแอป/เล่มเสมอ
- **edge-tts ฟรี ไม่ต้อง API key แต่ต้องต่อเน็ต** → ห้ามเรียกสด ๆ ตอนผู้ใช้กดฟัง ให้ **pre-generate ไฟล์เสียงล่วงหน้า + cache** เพื่อให้ทำงานออฟไลน์ได้ (proposal มี MeloTTS เป็นตัวสำรอง)
- **การแปลไทย:** เก็บ จีน + ความหมายอังกฤษ (จาก CC-CEDICT) เป็นตัวอ้างอิง แล้วให้ AI แปลไทยครั้งเดียวโดยเห็นทั้งคู่ — แปลตรงจากจีนโดยมีอังกฤษกันเพี้ยน ไม่ใช่แปลต่อกันเป็นทอด ๆ แล้วความหมายเพี้ยนสะสม
- คำแปลที่ AI สร้างต้องผ่านการตรวจโดยหฤทัย (HSK 5) ก่อนเข้า item bank — เป็นกติกาทีม

## แล้ว parselmouth / วิเคราะห์ pitch ล่ะ?

แผนเดิม (ยุคก่อนปรับขอบเขต) เคยคิดจะวิเคราะห์เส้นเสียง/pitch ของผู้เรียน แต่ **ตัดเป็น future work แล้ว** เพราะ:
- HSK 1–2 **ไม่มีสอบพูด** (HSKK บังคับตั้งแต่ระดับ 3)
- อาจารย์เตือนอย่าเน้นดัดสำเนียง — เป้าคือ "สื่อสาร/ฟังเข้าใจ"
- เราวินิจฉัยวรรณยุกต์ 2/3 และ zh/ch/sh ทาง "หู" ด้วย **minimal pair** แทน — ไม่ต้องใช้ ASR/วิเคราะห์เสียงพูดเลย (ดูเหตุผลเต็มใน [[ปรับขอบเขต-โฟกัสHSK]])
