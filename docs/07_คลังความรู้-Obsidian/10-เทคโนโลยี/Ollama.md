# Ollama — ทดลองจริงแล้วบนเครื่องบอล (การบ้านอาจารย์ ✅)

> อาจารย์ถาม 3 รอบว่า "ลอง Ollama หรือยัง" — ลองแล้ว 6 ส.ค. 2026 บนโน้ตบุ๊กบอล ผลสรุปอยู่ท้ายโน้ต

## Ollama คืออะไร
โปรแกรมรัน LLM บนเครื่องตัวเอง (ออฟไลน์ ฟรี ไม่มี API key ไม่ส่งข้อมูลออกนอกเครื่อง) — ติดตั้งแล้วดึงโมเดลโอเพนซอร์สมารันผ่าน GPU ได้เลย

## สิ่งที่ทดลอง (6 ส.ค. 2026)
- **เครื่อง:** โน้ตบุ๊กบอล — RAM 16GB · NVIDIA RTX 4060 Laptop (VRAM 8GB) · Windows 11
- **เวอร์ชัน:** Ollama 0.32.6 (ติดตั้งผ่าน winget) · **โมเดล:** Qwen3 4B (~2.6GB — เลือกเพราะตระกูล Qwen เก่งจีนสุดในโมเดลเปิด)
- **โจทย์ทดสอบ = งานจริงของโปรเจกต์ 2 ข้อ:** (1) ร่างข้อสอบฟัง HSK 1 พร้อมเหตุผลตัวลวงแบบ Thai-L1 (2) อธิบายจุดสับสนวรรณยุกต์ 2/3 เป็นภาษาไทย

## ผลที่วัดได้

| ตัววัด | ผล |
|---|---|
| ความเร็ว generate | **60-68 token/วินาที** (GPU ทำงานเต็ม — เร็วพอใช้จริง) |
| เวลาตอบจริงต่อข้อ | **1-2.3 นาที/ข้อ** เพราะโหมด "คิดก่อนตอบ" ของ Qwen3 เผาไป 4,200-5,800 token ต่อคำตอบ (ปิดด้วย `--think=false` และ `/no_think` แล้วไม่เชื่อ) |
| คุณภาพภาษาไทย/ความรู้จีน | **ต่ำกว่าเกณฑ์ใช้งาน** — ดูตัวอย่างข้างล่าง |
| เสถียรภาพ | เจอ crash 1 ครั้งตอนโหลดโมเดลรอบแรก (`EOF`) — เซิร์ฟเวอร์รีสตาร์ทเองแล้วหาย |

## ตัวอย่างข้อผิดที่เจอ (โมเดล 4B)
- ทับศัพท์พินอินเป็นไทยเพี้ยน: "ชูอิ/ถิ้ว" สำหรับ shuǐ
- ใช้คำนอกลิสต์ HSK 1 ในข้อสอบ (无 wú — HSK 1 มีแต่ 没有)
- เหตุผลตัวลวงแต่งเอง ไม่มีฐาน Thai-L1 จริง (อ้างว่า shì เสียงคล้าย shuǐ)
- อธิบายวรรณยุกต์ผิดข้อเท็จจริง: บอก "ภาษาไทยไม่มีระบบเสียงแยกระดับแบบจีน" — ไทยมี 5 เสียง ประเด็นจริงคือเส้นเสียง T2/T3 จีนคล้ายเสียงจัตวาไทย (ดู [[จุดผิดคนไทย]])

## ข้อสรุป (ไว้ตอบอาจารย์)
1. **ลองแล้วจริง รันได้จริง** — ฮาร์ดแวร์ทีมรองรับสบาย ความเร็วไม่ใช่ปัญหา
2. **แต่ไม่เอามาใช้ในระบบ เพราะ 3 เหตุผล:**
   - คุณภาพโมเดลเปิดขนาดเล็ก (ที่เครื่องฟรี ๆ รันไหว) ต่ำกว่า Gemini Flash ชัดเจนกับงานภาษาจีน-ไทย — ทุกชิ้นต้องให้หฤทัยรื้อใหม่ ช้ากว่าเขียนเอง
   - เซิร์ฟเวอร์จริงของเรา (Render free tier) **ไม่มี GPU** — รัน Ollama บน production ไม่ได้อยู่แล้ว มันเป็นเครื่องมือฝั่งเครื่องทีมเท่านั้น
   - สถาปัตยกรรมเราไม่ได้พึ่ง LLM ตอนรันจริงอยู่แล้ว: ตรวจคำตอบ = rule เทียบเฉลย 100% (กฎเหล็ก) · LLM ใช้แค่ช่วยทีม "ร่าง" เนื้อหาก่อนหฤทัยตรวจ ซึ่ง Gemini Flash (ฟรี tier) ทำได้ดีกว่าและไม่กินเครื่อง
3. **ช่องที่ Ollama อาจกลับมามีประโยชน์ (future work):** ถ้าต้องประมวลผลข้อมูลผู้เรียนแบบ privacy-sensitive ในเครื่องทีม หรือถ้าได้เครื่อง GPU server ฟรีในอนาคต — จดไว้เฉย ๆ ไม่ใช่แผนตอนนี้
