# CrewAI — ทดลอง multi-agent จริงแล้ว (การบ้านอาจารย์ครึ่งหลัง ✅)

> คู่กับ [[Ollama]] (ครึ่งแรก) — อาจารย์ให้ไกด์มา 2 ไฟล์ใน `docs/09_Ollama_CrewAI/` ทำครบทั้งสองแล้ว 6 ส.ค. 2026

## CrewAI คืออะไร
Framework สร้าง "ทีม AI หลายตัว" (multi-agent): นิยาม **Agent** (ผู้เชี่ยวชาญแต่ละด้าน) + **Task** (งานที่มอบ) + **Crew** (จับมาต่อแถวทำงานส่งไม้กันได้) — เลือก LLM เบื้องหลังได้ทั้ง Ollama local และ Gemini API

## สิ่งที่ทำตามไกด์อาจารย์ (6 ส.ค. 2026)
- ติดตั้ง `uv` 0.12.2 + CrewAI CLI (ผ่าน `uv tool install crewai`)
- สร้างโปรเจกต์ **career_plan_agents** แบบ classic ตาม Part C ของไกด์เป๊ะ: agents.yaml (4 เอเจนต์) + tasks.yaml (4 งานต่อแถว) + crew.py + main.py
  - 📁 โปรเจกต์อยู่นอก repo ที่ `D:\crewai\career_plan_agents`
- รันกับ **Ollama local (llama3 8B)** บน RTX 4060 — ไม่แตะ cloud เลย
- **สำเร็จ end-to-end:** 4 เอเจนต์ส่งงานต่อกัน (วิเคราะห์โปรไฟล์ → หา gap → ออกแบบแผน → เขียนรายงาน) ได้ไฟล์รายงาน ~9.4KB
  - หลักฐานผลรันจริง: `docs/09_Ollama_CrewAI/career_plan_report-ผลรันจริง-2026-08-06.md`

## ข้อสังเกตจากการรันจริง
- llama3 8B ตอบภาษาอังกฤษคุณภาพดีกว่า qwen3:4b ตอบไทยมาก (ตาราง gap, ระดับคะแนน, แผนพัฒนา — โครงครบ ใช้ได้จริง)
- ทั้ง 4 เอเจนต์รันจบในไม่กี่นาทีบนเครื่องบอล — multi-agent บน local LLM ทำได้จริงถ้างานเป็นภาษาอังกฤษ
- CrewAI จะถามเรื่อง tracing/telemetry ตอนจบ — ตอบ N / ปิดถาวรแล้วด้วย `crewai traces` preference

## เกี่ยวอะไรกับโปรเจกต์เรา (ไว้ตอบอาจารย์)
- แนวคิด multi-agent นี้**เราใช้อยู่แล้วในกระบวนการทำงานทีม** เช่น ตอนแบ่ง 300 คำเป็น 5 หมวด (AI 3 ร่างอิสระ + judge ตัดสิน แล้วหฤทัยยืนยัน) และตอนรีวิว UX/โค้ด (หลายมุมมอง + ด่านหักล้าง)
- ช่องใช้ต่อในอนาคต: ท่อร่างข้อสอบเข้า item bank แบบ "ตัวร่าง + ตัวตรวจเบื้องต้น" ก่อนส่งหฤทัยอนุมัติ (คนยังเป็นด่านสุดท้ายตามกติกา [[กรอบระบบ-จากอาจารย์]])
- **ไม่ใช้ในระบบ production** ด้วยเหตุผลเดียวกับ [[Ollama]]: เซิร์ฟเวอร์ฟรีไม่มี GPU + ระบบเราไม่พึ่ง LLM ตอนรัน (ตรวจคำตอบ = rule 100%)
