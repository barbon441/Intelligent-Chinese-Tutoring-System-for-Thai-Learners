# pyBKT

## คืออะไร
pyBKT คือไลบรารี Python สำหรับทำ **BKT — Bayesian Knowledge Tracing** (อ่านว่า "เบย์เซียน โนว์เลดจ์ เทรซซิง" = การติดตามความรู้แบบเบย์เซียน) — เป็นสมองของโมดูล "แบบจำลองผู้เรียน" ที่คอยตอบคำถามว่า *"ผู้เรียนคนนี้แม่นทักษะไหนแค่ไหนแล้ว"* จากประวัติตอบถูก/ผิด (ไลบรารีโดย Badrinath, Wang & Pardos 2021 — ดู [[งานวิจัยอ้างอิง]])

## หลักการ: พารามิเตอร์ 4 ตัวต่อ 1 ทักษะ
BKT มองว่าแต่ละทักษะมีสถานะซ่อนอยู่ 2 แบบ: "รู้" หรือ "ยังไม่รู้" แล้วอัปเดตความน่าจะเป็นทุกครั้งที่ตอบ

| พารามิเตอร์ | ชื่อ | ความหมายแบบเพื่อนเล่าให้ฟัง |
|---|---|---|
| **P(L0)** | prior | โอกาสที่ "รู้ทักษะนี้อยู่แล้ว" ตั้งแต่ก่อนเริ่มฝึก |
| **P(T)** | transition/learn | โอกาส "เรียนรู้เพิ่ม" (จากไม่รู้ → รู้) หลังฝึกแต่ละครั้ง |
| **P(S)** | slip | รู้อยู่แล้วแต่ "พลาด" ตอบผิด |
| **P(G)** | guess | ไม่รู้แต่ "เดาถูก" |

ตอบถูกไม่ได้แปลว่ารู้เสมอ (อาจเดา) ตอบผิดก็ไม่ได้แปลว่าไม่รู้ (อาจพลาด) — BKT ชั่งน้ำหนักเรื่องพวกนี้ให้อัตโนมัติ

## ใช้ในโปรเจกต์ยังไง
- **เทรนด้วยข้อมูลผู้เรียนไทยที่แอปเราเก็บเอง** (ทุกการตอบ = 1 log) — *ไม่ใช่ข้อมูล global* · Duolingo SLAM 2018 ใช้แค่พิสูจน์ pipeline/benchmark เท่านั้น คนละการทดลองกัน (ดู [[Datasets]])
- **Pre-train offline → runtime คิดแค่ posterior**: เทรนพารามิเตอร์ล่วงหน้านอกระบบ ตอนใช้งานจริง FastAPI แค่คำนวณอัปเดตความน่าจะเป็นต่อการตอบ (เบา เร็ว) — ดู [[FastAPI]]
- **Cold start**: ผู้ใช้ใหม่ยังไม่มีข้อมูล → ใช้ค่าตั้งต้นจากงานวิจัยไปก่อน
- **ต้องมี Q-matrix**: ตารางจับคู่ "ข้อสอบข้อไหน → วัดทักษะอะไร" (คำศัพท์/วรรณยุกต์/พยัญชนะ/ไวยากรณ์ + จุดผิด Thai-L1 เป็น knowledge component) — ไม่มี Q-matrix = BKT ไม่รู้จะเอาคำตอบไปอัปเดตทักษะไหน (ดู [[รูปแบบข้อสอบ-HSK-1-2]] และ [[จุดผิดคนไทย]])

## ทำไม BKT ไม่ใช่ DKT (Deep Knowledge Tracing)
- DKT ใช้ neural network → **กินข้อมูลมหาศาล** ผู้ใช้เราน้อย (โปรเจกต์นักศึกษา 4 เดือน) เทรนไม่ไหว
- BKT **เบาและโปร่งใส** — อธิบายกรรมการได้ว่าตัวเลขแต่ละตัวหมายถึงอะไร
- DKT/AKT เก็บไว้เป็น future work / เทียบผลตอน evaluation ได้

## วัดผลยังไง
วัดด้วย **AUC** (Area Under the ROC Curve, ใช้ scikit-learn) — ทำนายว่าข้อถัดไปจะตอบถูกไหม ยิ่งใกล้ 1 ยิ่งแม่น + ทำ **ablation** (มี/ไม่มี Thai-L1) — ดู [[การวัดผลโครงงาน]]

⚠️ อย่าสับสนกับ [[FSRS]]: pyBKT ตอบ "แม่นแค่ไหน" (mastery) ส่วน FSRS ตอบ "ควรทวนเมื่อไหร่" — คนละหน้าที่กัน
