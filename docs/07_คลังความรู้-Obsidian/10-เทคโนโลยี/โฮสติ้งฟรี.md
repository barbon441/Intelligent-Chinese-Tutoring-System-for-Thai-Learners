# โฮสติ้งฟรี

**คืออะไร:** ชุดบริการโฮสต์ฟรี (ยืนยันเงื่อนไขปี 2026 แล้ว) ที่ทำให้星航รันได้จริงด้วย **งบ 0 บาท** — deploy อัตโนมัติผ่าน `git push` ทั้งชุด

> ⚠️ **อัปเดต 12 ก.ค. 2026:** Hugging Face เปลี่ยน **Docker Space เป็นของเสียเงิน (ต้อง PRO)** — เดิมวางไว้ให้รัน backend → **เปลี่ยนมาใช้ Render free web service แทน** (บทเรียน: เงื่อนไขฟรีเปลี่ยนเร็วมาก ต้องเช็กสดตอนจะใช้จริง)

## สถาปัตยกรรม

```
Next.js PWA (Vercel/CF Pages) → FastAPI (Render) → Supabase
   ออฟไลน์: Dexie/IndexedDB       pyBKT·FSRS·jieba      Postgres+Auth
```

## ชุดที่เลือก (3 ชิ้น)

| ชั้น | บริการ | เงื่อนไขฟรีที่ต้องรู้ |
|---|---|---|
| เว็บ (frontend) | **Vercel** หรือ **Cloudflare Pages** | โฮสต์ [[Next.js-PWA]] · push ขึ้น GitHub แล้ว deploy เอง |
| Backend | **Render free web service** | รัน [[FastAPI]] · 512MB · ไม่ต้องบัตรเครดิต · connect GitHub → auto-deploy ตอน push · หลับหลัง 15 นาที ปลุก ~30-50 วิ |
| ฐานข้อมูล | **Supabase** | PostgreSQL ฟรี 500MB + Auth 50k MAU (ดู [[Supabase]]) |

**ทำไม 512MB ของ Render พอ:** API เราเบา — [[pyBKT]] **เทรน offline** ใน `ml/`/`scripts/` (ไม่ใช่บน server) · ตอน runtime API แค่คำนวณ posterior + query DB ซึ่งกินแรมน้อย

## เรื่อง "หลับ" — จุดที่ต้องระวังก่อนเดโม

- **Render free:** ไม่มีคนเรียก **15 นาที → หลับ** · request แรกหลังตื่นช้า ~30-50 วิ (boot) แต่**ข้อมูล/แอปไม่หาย** → ตั้ง **keep-alive ping ก่อนวันเดโม** (มี `.github/workflows/keepalive.yml`)
- **Supabase:** ไม่มี query **7 วัน → โปรเจกต์ pause** → ping ไว้เช่นกัน

## ❌ ห้ามใช้ (เช็กแล้วปี 2026)

| บริการ | ทำไมไม่เอา |
|---|---|
| **Hugging Face Docker Space** | ⚠️ กลายเป็นของเสียเงินแล้ว (ก.ค. 2026) — มีแต่ Static ที่ฟรี ซึ่งรัน Python ไม่ได้ |
| Fly.io / Railway / Koyeb | เลิกให้ tier ฟรีแล้ว |

บทเรียน: บทความ "โฮสต์ฟรี" เก่า ๆ เชื่อไม่ได้ — เงื่อนไขฟรีเปลี่ยนเร็วมาก (แม้แต่ HF ที่เราวางไว้ก็เพิ่งเปลี่ยน) ต้องเช็กปีปัจจุบัน/ตอนจะใช้จริงเสมอ (กติกาทีม: อย่าเดา ตรวจก่อนอ้าง)

## วิธี deploy

1. push โค้ดขึ้น GitHub repo ของทีม
2. Vercel/CF Pages (เว็บ) + Render (API) ผูกกับ repo → build อัตโนมัติทุกครั้งที่ push (ตั้ง Root Directory ให้ตรงส่วน: เว็บ=`apps/web`, API=`apps/api`)
3. API key / secret ทั้งหมดใส่ env ของแต่ละบริการ — **ห้าม commit `.env`** (มี `.gitignore` กันแล้ว)

## เกี่ยวข้องกับ
