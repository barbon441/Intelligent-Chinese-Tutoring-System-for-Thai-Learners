# การวัดผลโครงงาน (3 ระดับ)

## คืออะไร
แผนประเมินผลของ "จีนรู้ใจ" — ตอบโจทย์อาจารย์ที่ให้บอกชัดว่า "จากเท่าไหร่เป็นเท่าไหร่" โดยวัด 3 ระดับ: **ผู้เรียน / โมเดล / การตรวจ**

## ระดับ 1: ผู้เรียน — pre/post Mock Exam (gain score)
- **เป้าหมายของระบบ:** พาคนไทย**ไม่มีพื้นฐาน (จาก 0)** → ระดับที่**สอบ HSK 1 ผ่าน**ได้ ตามแผนการเรียนเต็มประมาณ 8 สัปดาห์
- **สิ่งที่โครงงานพิสูจน์ได้:** gain score ของผู้ทดลอง 5–10 คน ที่ใช้แอปประมาณ **10 วัน** ซึ่งสั้นกว่าแผนเต็มมาก → จึงรายงานเป็น**แนวโน้มการเปลี่ยนแปลงของคะแนน ไม่ใช่ข้อสรุปว่าสอบผ่าน** (แยก 2 เรื่องนี้ให้ขาดเสมอ ทั้งในเล่มและตอนตอบกรรมการ)
- วิธี: ทำ Mock Exam ก่อนเริ่มเรียน (pre) และหลังใช้แอป (post) → ดู **gain score** (คะแนนที่เพิ่มขึ้น)
- ใช้ข้อสอบรูปแบบ HSK จริง เกณฑ์จริง สเกล 200 ผ่าน 120 (ดู [[รูปแบบข้อสอบ-HSK-1-2]] และ [[HSK-3.0-ข้อเท็จจริง]])

## ระดับ 2: โมเดล — AUC บนข้อมูลคนไทย + ablation

### AUC คืออะไร
**AUC (Area Under the ROC Curve)** = ตัวชี้วัดว่าโมเดลทำนาย "ข้อต่อไปผู้เรียนจะตอบถูกหรือผิด" ได้แม่นแค่ไหน ค่าอยู่ระหว่าง 0–1:
- **0.5 = เดามั่ว** (ไม่ต่างจากโยนเหรียญ)
- **~0.7–0.85 = ช่วงปกติของงาน Knowledge Tracing** → ถ้าเราได้แถวนี้ถือว่าโมเดลใช้ได้จริง

### วิธีวัด (ทำตามนี้)
1. แบ่งข้อมูล log การตอบของผู้เรียนไทยเป็น **train / test**
2. `fit` โมเดล [[pyBKT]] ด้วยชุด train
3. `predict` ความน่าจะเป็นตอบถูกบนชุด test
4. คำนวณ `roc_auc_score` (scikit-learn) เทียบกับผลตอบจริง

### Ablation study
เทรน 2 เวอร์ชันแล้วเทียบ AUC: **มี vs ไม่มี knowledge component จุดผิด Thai-L1** — ถ้าเวอร์ชันมี Thai-L1 ทำนายแม่นกว่า = พิสูจน์ว่าจุดขายของเรา (ดู [[จุดผิดคนไทย]]) มีผลจริง ไม่ใช่แค่ฟีเจอร์ประดับ

## ระดับ 3: การตรวจข้อสอบ — rule 100%
- ทุกข้อมีเฉลยตายตัว → ตรวจด้วย rule เทียบเฉลย **ถูกต้อง 100%** (ไม่ใช้ LLM ตรวจไวยากรณ์อิสระ — คำตอบตรงต่อข้อห่วงใหญ่สุดของอาจารย์)

## Duolingo SLAM = benchmark พิสูจน์วิธี (อย่าสับสน!)
- **Duolingo SLAM 2018** (Harvard Dataverse) ใช้เพื่อ **พิสูจน์ว่า pipeline ของเราทำงานถูก** — รัน pyBKT บนข้อมูลใหญ่ที่มีคนอื่นทำไว้แล้ว เทียบว่า AUC เราสมเหตุสมผล
- เป็น **คนละการทดลอง** กับโมเดลจริงที่เทรนด้วยข้อมูลคนไทยที่แอปเก็บเอง — **ไม่ใช่เอามาเทรนต่อกัน** เพราะทักษะเป็นคนละภาษา (SLAM ไม่มีจีน/ไทย) โอนกันไม่ได้
- ท่าตอบกรรมการ: "BKT ใช้ข้อมูล global เหรอ?" → ไม่ใช่ — เทรนด้วยข้อมูลคนไทยที่เก็บเอง (ต้องขอ consent ตาม PDPA) SLAM เป็นแค่ benchmark วิธี (ดู [[Datasets]])

## สรุปสั้น

| ระดับ | วัดอะไร | ตัวชี้วัด |
|---|---|---|
| ผู้เรียน | เรียนแล้วเก่งขึ้นจริงไหม | gain score จาก pre/post Mock Exam |
| โมเดล | ทำนายแม่นไหม + Thai-L1 ช่วยจริงไหม | AUC บนข้อมูลไทย + ablation |
| การตรวจ | เชื่อผลตรวจได้ไหม | rule เทียบเฉลย 100% |
