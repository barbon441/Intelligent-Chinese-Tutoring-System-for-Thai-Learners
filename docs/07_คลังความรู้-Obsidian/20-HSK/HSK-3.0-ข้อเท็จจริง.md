# HSK 3.0 — ข้อเท็จจริงที่ต้องจำ

## คืออะไร
มาตรฐานภาษาจีนฉบับใหม่ **《国际中文教育中文水平等级标准》(GF0025-2021)** ที่มาแทน HSK 2.0 เดิม — โครงสร้างเป็น **3 ระดับใหญ่ 9 ขั้น** (Elementary 1–3, Intermediate 4–6, Advanced 7–9) และเป็นมาตรฐานที่โปรเจกต์เรายึดทั้งหมด

## ไทม์ไลน์สำคัญ
- ข้อสอบ HSK 1–6 **เปลี่ยนเป็นระบบ 3.0 ตั้งแต่ ~18 ก.ค. 2026** (ก่อนหน้านั้นยังเป็น 2.0)
- ตอนนี้ (ก.ค. 2026) = **ช่วงเปลี่ยนผ่านพอดี** → รายละเอียดบาง section อาจยังไม่นิ่ง ให้อ้างอิง chinesetest.cn และ version-stamp เนื้อหาทุกครั้ง

## ตัวเลขจริง HSK 1–2 (สะสม — ใช้เลข "ข้อสอบจริง" ไม่ใช่เลข draft 500/1272)

| | คำศัพท์ | ไวยากรณ์ | อักษร | โครงสร้างข้อสอบ |
|---|---|---|---|---|
| **HSK 1** | 300 คำ | 48 จุด | 300 ตัว | ฟัง + อ่าน (มี pinyin กำกับ) |
| **HSK 2** | 500 คำ | 129 จุด | 600 ตัว | ฟัง + อ่าน (มี pinyin กำกับ) |

- เกณฑ์ผ่าน: **สเกล 200 คะแนน ผ่านที่ 120**
- **HSK 1–2 ไม่มีสอบพูด** — HSKK (สอบพูด) บังคับตั้งแต่ระดับ 3 ขึ้นไป → เราตัดเรื่องออกเสียง/ASR ออกจากแกนได้อย่างถูกต้อง

## ⚠️ กับดักที่ห้ามพลาด
1. **HSK 1 ใหม่ (300 คำ) ≈ HSK 2 เก่า** — ระดับใหม่ยากขึ้นเกือบเท่าตัว → **ห้ามใช้ลิสต์คำ/สื่อ HSK 2.0 เก่าเป็นเนื้อหาหลักเด็ดขาด** ต้องใช้ HSK 3.0 word list เท่านั้น
2. ระวังสับสนเลข "draft มาตรฐาน" (500/1272) กับเลข "ข้อสอบจริง" (300/500) — เราใช้เลขข้อสอบจริง
3. ถ้าต่อยอด HSK 3 (phase 2): คำศัพท์ +500 (รวม 1,000), ไวยากรณ์ +81 (รวม 210), **ตัด pinyin ออก** และเพิ่ม section เขียน (เรียงคำ + เติมอักษร)

## ทำไมสำคัญกับโปรเจกต์
- ตัวเลข 300/500 คำ = ขนาดคลังคำศัพท์และบัตรคำที่ต้องนำเข้า (ดู [[Datasets]])
- ไวยากรณ์ 48/129 จุด = รายการ skill ตั้งต้นสำหรับ Q-matrix ของ [[pyBKT]]
- "มี pinyin ในข้อสอบ 1–2" = ผู้เรียนไม่ต้องอ่านฮั่นจื้อล้วนได้ตั้งแต่แรก → ลดภาระเนื้อหา แต่**ข้อฟังห้ามโชว์พินอิน** (ดู [[รูปแบบข้อสอบ-HSK-1-2]])
- เกณฑ์ 120/200 = เกณฑ์จริงที่ Mock Exam ต้องใช้ (ไม่ใช่เลขสมมติแบบ mockup อาจารย์ — ดู [[วิเคราะห์-mockup-อาจารย์]])
