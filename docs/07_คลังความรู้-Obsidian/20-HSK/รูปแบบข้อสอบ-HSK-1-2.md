# รูปแบบข้อสอบ HSK 1–2 (ที่เราจำลองในแอป)

## คืออะไร
สรุปโครงสร้างข้อสอบ HSK 1–2 และประเภทข้อที่เราใช้สร้าง item bank — จุดสำคัญคือ **ทุกข้อมีเฉลยตายตัว ตรวจอัตโนมัติด้วย rule ได้ 100%** (ไม่ใช้ LLM ตรวจ)

## โครงสร้างใหญ่
- HSK 1–2 สอบแค่ **2 ทักษะ: การฟัง + การอ่าน** (ไม่มีพูด ไม่มีเขียน — ดู [[HSK-3.0-ข้อเท็จจริง]])
- ข้อสอบมี **pinyin กำกับ** ในส่วนอ่าน
- เกณฑ์จริง: สเกล 200 คะแนน ผ่าน 120

## ประเภทข้อที่ตรวจด้วย rule ได้ (ใช้ใน item bank)

| ประเภทข้อ | ทักษะ | ตรวจยังไง |
|---|---|---|
| เลือกความหมาย (multiple choice) | อ่าน/ศัพท์ | เทียบเฉลยตรงตัว |
| เลือกพินอินของคำ | ศัพท์/เสียง | เทียบเฉลยตรงตัว |
| ฟังแล้วเลือกภาพ | ฟัง | เทียบเฉลยตรงตัว |
| จับคู่ (ประโยค↔ภาพ, คำถาม↔คำตอบ) | อ่าน | เทียบเฉลยตรงตัว |
| ถูก-ผิด (ฟัง/อ่านแล้วตัดสิน) | ฟัง/อ่าน | เทียบเฉลยตรงตัว |
| เรียงคำเป็นประโยค | ไวยากรณ์ | เทียบกับชุดคำตอบที่ยอมรับ (accepted answers) |

หมายเหตุ: ข้อเรียงคำเป็น section จริงของ HSK 3 (phase 2) แต่เราใช้เป็นแบบฝึกได้เลย เพราะมันวัด **จุดผิดลำดับคำของคนไทย** (จีนวางคำขยายหน้า ไทยวางหลัง) ได้ตรงที่สุด — ดู [[จุดผิดคนไทย]]

## หลักการออกข้อ (กฎของเรา)
1. **เฉลยตายตัว → auto-grade ด้วย rule** — นี่คือเหตุผลหลักที่โฟกัส HSK (แก้ข้อห่วง "ไวยากรณ์จีนหลวม" ของอาจารย์)
2. **Distractor (ตัวลวง) ต้องสะท้อนจุดผิดคนไทย** — เช่น ลวงด้วยคู่วรรณยุกต์ 2/3, คู่ zh/ch/sh, ลำดับคำแบบไทย → ตอบผิดข้อไหนบอกได้ว่าพลาดเพราะอะไร (ป้อน [[pyBKT]] + Q-matrix)
3. **ข้อฟังต้อง audio-only** — ห้ามโชว์พินอิน/ฮั่นจื้อของสิ่งที่ให้ฟังบนโจทย์ ไม่งั้น "ข้อฟังเฉลยตัวเอง" ไม่ต้องฟังก็ตอบได้ (บทเรียนตรงจาก [[วิเคราะห์-mockup-อาจารย์]])
4. ข้อฟังใช้ **minimal pair** (เช่น วรรณยุกต์ 2 vs 3) วินิจฉัย "หู" ได้โดยไม่ต้องทำ ASR — เสียงอ่านมาจาก edge-tts แบบ pre-generate + cache (ดู [[NLP-จีน-และเสียง]])
5. คุมระดับคำศัพท์ในโจทย์อ่านด้วย jieba ให้อยู่ในลิสต์ HSK 3.0 ระดับนั้นจริง (อย่าซ้ำรอย mockup ที่ tag ระดับศัพท์ผิด)
6. ข้อสอบที่ AI สร้าง (skill `/hsk-item`) **ต้องผ่านการตรวจโดยหฤทัยก่อนเข้า item bank เสมอ**

## Mock Exam (โมดูล 7 — เสาหลักของแอปติว)
- ประกอบข้อสอบฟัง+อ่านเต็มรูปแบบ **จับเวลาเหมือนสอบจริง**
- ให้คะแนนตาม**เกณฑ์จริง สเกล 200 ผ่าน 120** (ไม่ใช่เกณฑ์สมมติแบบ 12/25)
- ทุกการตอบ = 1 log ป้อนเข้า [[pyBKT]] และใช้เป็น pre/post วัดผลผู้เรียน (ดู [[การวัดผลโครงงาน]])
