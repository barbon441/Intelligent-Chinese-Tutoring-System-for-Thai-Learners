# แนวการสอนภาษาจีนมือใหม่ — หลักฐานวิจัยจริง (ตรวจ citation แล้วทุกแหล่ง)

> ที่มา: รีเสิร์ช 4 สาย (วิธีสอนสากล / อัตราเรียนคำศัพท์ / spaced repetition / บริบทไทย) — **ทุกแหล่งถูกเปิดอ่านจริงก่อนใส่ + ตรวจซ้ำอีกชั้น 14 แหล่งสำคัญ ผ่านหมด** · ใช้อ้างใน one-pager, เล่มโครงงาน, และตอบกรรมการ
> คำตอบคำถามบอล "เขาสอนกันยังไง เราขาดอะไรไหม": **โครงเราตรงกับมาตรฐานโลก ไม่มีช่องโหว่ใหญ่ — มีจุดปรับเล็ก 2 จุด** (ดูท้ายไฟล์)

## 1. ตารางเทียบ: โลกสอนแบบนี้ → เราทำแบบนี้

| หลักที่โลกใช้ | หลักฐาน | ของเรา |
|---|---|---|
| **สอนเสียงล้วน ๆ ก่อนเริ่มเนื้อหา** — ตำรา HSK Standard Course เล่ม 1 อุทิศบท 1-2 ให้พินอิน/วรรณยุกต์ล้วน แล้วค่อยเริ่มบทสนทนา (คำใหม่ 10-15 คำ/บท) | [คู่มือตำรา (Purple Culture)](https://www.purpleculture.net/a-guide-to-the-use-of-hsk-standard-course-level-1-article-5/) | ✅ โมดูล 0 พื้นฐานเสียง = บท 1-2 ของเราเอง |
| **เลื่อนตัวอักษรออกไปก่อน ผลการเรียนดีกว่า** — ทดลองจริง: กลุ่มเรียนเสียงล้วน 3 สัปดาห์ก่อนเจออักษร แยกเสียง/ถอดเสียงแม่นกว่า | [Packard 1990, Modern Language Journal (ERIC)](https://eric.ed.gov/?id=EJ411855) | ✅ ลำดับ เสียง → พินอิน → อักษร |
| **ฝึกหูวรรณยุกต์แบบมี feedback ได้ผลจริงและคงทน** — ฝึกแค่ 8 ครั้ง/2 สัปดาห์ แม่นขึ้น +21% อยู่ยาว 6 เดือน ถ่ายโอนไปคำ/ผู้พูดใหม่ | [Wang et al. 1999, JASA (PDF จริง)](https://kuppl.ku.edu/sites/kuppl/files/documents/publications/Wang_Spence_Jongman_Sereno_training_JASA_1999.pdf) | ✅ เกมฝึกหู m0-4 · ⚠️ จุดปรับ #1 ข้างล่าง |
| **ฝึกฟังอย่างเดียว → การออกเสียงก็ดีขึ้น 18%** (ไม่ต้องฝึกพูดเลย) | [Wang et al. 2003, JASA (PubMed)](https://pubmed.ncbi.nlm.nih.gov/12597196/) | ✅ ตอบข้อจำกัด "ไม่สอนพูด" ได้สวย: ฝึกหูของเราให้ผลพลอยได้ด้านออกเสียง |
| **คนไทยได้เปรียบ T1/T4 แต่พลาดหนักสุดที่คู่ T2-T3** — เทียบคนอังกฤษแล้วไทยชนะเฉพาะบางเสียง | [Li 2016, English Language Teaching (ERIC)](https://eric.ed.gov/?id=EJ1087096) | ✅ ตรงคลัง Thai-L1 เป๊ะ — minimal pair 2/3 ต้องน้ำหนักสูงสุด |
| **ทฤษฎี input + i+1** — เรียนรู้เมื่อเข้าใจ input ที่ยากกว่านิดเดียว | [Krashen 1982 (PDF ทางการ)](http://www.sdkrashen.com/content/books/principles_and_practice.pdf) | ✅ ฐานทฤษฎีของ "หูมาก่อนตา" + pacing |
| **พินอินโชว์เร็วไปมีโทษ** — ตัวโรมันหลอก (x, q) ทำให้จำเสียงคำผิด | [Hayes-Harb & Cheng 2016 (PMC เต็ม)](https://pmc.ncbi.nlm.nih.gov/articles/PMC4891949/) | ⚠️ จุดปรับ #2 ข้างล่าง |
| **ทวนเว้นช่วงชนะอัดรวด** — meta-analysis 317 การทดลอง | [Cepeda et al. 2006 (หน้า publication ผู้เขียน)](https://www.yorku.ca/ncepeda/publications/CPVWR2006.html) | ✅ FSRS โมดูล 4 |
| **ควิซช่วยจำมากกว่าอ่านซ้ำ** (testing effect — พิสูจน์กับศัพท์ภาษาต่างประเทศโดยตรงใน Science 2008) | [Roediger & Karpicke 2006](https://journals.sagepub.com/doi/10.1111/j.1467-9280.2006.01693.x) · [Karpicke & Roediger 2008 (PubMed)](https://pubmed.ncbi.nlm.nih.gov/18276894/) | ✅ ควิซท้ายหมวด + โหมดฝึกเฉลยทันที |
| **FSRS ชนะ SM-2 ใน ~99.6% ของผู้ใช้** (benchmark ~350 ล้านรีวิว — ระบุ: เป็น benchmark เชิงทำนาย ไม่ใช่ RCT) | [srs-benchmark (GitHub)](https://github.com/open-spaced-repetition/srs-benchmark) | ✅ เลือก ts-fsrs ถูกแล้ว |
| **งานไทยยืนยันครบ**: คนไทยพลาด ch/sh (มรภ.เชียงใหม่ 2017) · เกม/แบบฝึกพินอินได้ผลกับนักเรียนไทย (สิกขา 2018, BUU 2018) · การสอนอักษรต้องไล่ง่าย→ยาก แยกส่วนประกอบ (Silpakorn 2021) | [ตัวอย่าง: ปัญหาออกเสียง มรภ.ชม.](https://so02.tci-thaijo.org/index.php/banditvijai/article/view/95811) · [กลวิธีสอนอักษรจีน](https://so05.tci-thaijo.org/index.php/sujthai/article/view/253256) | ✅ Thai-L1 + บันไดอักษร + การ์ดอักษรภาพ m1-7 |

## 2. ตัวเลขสำหรับฟีเจอร์ "เหลืออีก ~X วันจำครบ" (m6-5) — การบ้านอาจารย์ ✅

| แหล่ง | ตัวเลข |
|---|---|
| **คู่มือผู้สอบ HSK ทางการ (Hanban 2010)** — [PDF chinesetest.cn](https://www.chinesetest.cn/userfiles/file/zhongying2010.pdf) | ระดับ 1 = เรียน 2-3 คาบ/สัปดาห์ นาน 1 เทอม รู้ 150 คำ · ระดับ 2 = 1 ปี 300 คำ ≈ **8-10 คำ/สัปดาห์** (เพซห้องเรียนปกติ — หมายเหตุ: อิงลิสต์ 2.0 ใช้เป็น "อัตรา" ไม่ใช่จำนวนรวม) |
| **Paul Nation** — [PDF ทางการ ม.Victoria Wellington](https://www.wgtn.ac.nz/lals/resources/paul-nations-resources/paul-nations-publications) | เรียนแบบตั้งใจด้วยบัตรคำ ≈ **50 คำ/สัปดาห์** (~2 ชม./สัปดาห์) — เร็วกว่าห้องเรียนยุโรป ~2 เท่า |
| **Fitzpatrick et al. 2008** — [Language Learning Journal](https://www.tandfonline.com/doi/abs/10.1080/09571730802390759) | อัด 15 คำ/วันทำได้จริง แต่**ลืมเร็วถ้าไม่มีทวนเว้นช่วง** → ต้องนับเฉพาะคำที่เข้ารอบทวนแล้ว |
| **FSI (กต.สหรัฐฯ)** — [state.gov](https://www.state.gov/foreign-language-training/) | จีน = ภาษา "ยากพิเศษ" (2,200 ชม.สำหรับคนอังกฤษ) — ใช้เล่าบริบทว่าทำไมแอปช่วยจัดจังหวะจึงสำคัญ |

**สูตร m6-5 ที่เสนอ (มีหลักฐานรองรับ):** คำที่เหลือ ÷ เพซจริงของผู้ใช้ (คำ/วันที่เข้ารอบ FSRS จากข้อมูลแอปเอง) · cold start ใช้ 10 คำ/วัน → HSK1 300 คำ ≈ 30 วัน (โหมดเร่ง 20 คำ/วัน ≈ 15-25 วัน) · แสดงเป็นช่วง ไม่ฟันธง + ถ่วงคำยาก/ง่ายภายหลังจากข้อมูลจริง

## 3. จุดปรับที่ได้จากวิจัย (เล็ก ทำได้เลย ไม่รื้ออะไร)

1. **เกมฝึกหูควรใช้เสียงหลายผู้พูด** (high-variability คือเหตุที่ผล Wang 1999 ถ่ายโอน/คงทน) → m0-4 และข้อฟัง ใช้ TTS หลาย voice ไม่ใช่เสียงเดียว — เรามีแผน 2 voice (m2-7) อยู่แล้ว แค่ขยายให้ครอบเกมฝึกหูด้วย
2. **เพิ่มจุดเน้น "พินอินหลอก"** (x, q, zh/ch/sh ที่ตาคนไทย/อังกฤษอ่านผิด — Hayes-Harb 2016) → เสริมในตารางเทียบเสียงไทย (m0-2) ให้ตัวหลอกมีป้ายเตือนพิเศษ
3. ยืนยันของที่ทำอยู่ 2 เรื่องแบบมีหลักฐาน: เพดานคำ/วัน + FSRS (Fitzpatrick — อัดแล้วลืมถ้าไม่ทวน) · กติกา "ประโยคใช้เฉพาะคำที่เรียนแล้ว" (Waring & Takaki 2003 — เจอคำน้อยกว่า 8 ครั้ง = แทบไม่เหลือหลัง 3 เดือน)
