# เทียบคู่แข่ง 2026 (ผลตรวจสอบจริง — อย่าเคลมเกิน)

## คืออะไร
ผลการตรวจสอบฟีเจอร์แอปคู่แข่งจากแหล่งทางการ (App Store / เว็บผู้พัฒนา / รีวิว ณ ปี 2026) ก่อนทำตารางเปรียบเทียบ — เพราะเวอร์ชันแรกเราเคลมผิดหลายจุด ต้องแก้ให้ตรงความจริงก่อนขึ้นสไลด์

## ผลตรวจรายแอป
| แอป | ที่เขา "มีจริง" | ที่เขา "ไม่มี" |
|---|---|---|
| **Duolingo** | **มีคอร์สจีนสำหรับผู้ใช้ภาษาไทยแล้ว!** (ขยายเป็น 148 คอร์ส เม.ย. 2025) · ทบทวนอัจฉริยะด้วย HLR (Half-Life Regression) · ฟรี (มีโฆษณา) | ฟีดแบ็กวรรณยุกต์ละเอียด ✗ · ออฟไลน์เต็มรูปแบบ ✗ (บางส่วน) |
| **HelloChinese** | รองรับไทย ✓ · ฟรี (คอร์สหลัก) ✓ · ออฟไลน์ ✓ · **ฟีดแบ็กการออกเสียง/วรรณยุกต์ ✓** · adaptive บางส่วน | วินิจฉัยตามภาษาแม่ผู้เรียน ✗ |
| **Pleco** | พจนานุกรมเทพ + บัตรคำ SRS (+OCR) | ไม่ใช่ติวเตอร์ · ไม่รองรับไทย · adaptive ✗ |

## จุดต่างจริงของเรา เหลือ 2 ข้อเท่านั้น (ทุกเจ้า ✗)
1. **วินิจฉัยจุดผิดตามภาษาแม่ไทย (Thai-L1)** — ไม่มีแอปไหนรู้ว่า "คนไทย" พลาดตรงไหนเพราะภาษาไทย (ดู [[จุดผิดคนไทย]])
2. **Knowledge Tracing วัดความแม่นรายทักษะ + เจาะแก้** — [[pyBKT]] เทรนด้วยข้อมูลผู้เรียนไทยของเราเอง

ท่าตอบกรรมการ: *"เราไม่ได้เคลมว่าดีกว่าแอปใหญ่ — เราขาย 'วินิจฉัยจุดผิดคนไทย' ที่เขาไม่ทำ"* (ตรงกับคอมเมนต์อาจารย์ข้อ 5 ใน [[ปรับขอบเขต-โฟกัสHSK]])

## 📛 บทเรียนราคาแพง: เคยเคลมผิด 4 จุด
ตารางเทียบเวอร์ชันแรกเราเขียนเหมือน "คู่แข่งไม่มี" ทั้งที่ตรวจแล้ว**เขามี**:
1. **รองรับภาษาไทย** — Duolingo/HelloChinese มีทั้งคู่ (Duolingo เพิ่งขยายคอร์ส เม.ย. 2025)
2. **ทบทวนอัจฉริยะ** — Duolingo ใช้ HLR, HelloChinese/Pleco มี SRS
3. **ฟรี + ออฟไลน์** — HelloChinese ทำได้ครบ
4. **ฟีดแบ็กการออกเสียง** — HelloChinese มี (เราต่างหากที่ตัดเรื่องเสียงเป็น future work)

**กฎที่ได้จากบทเรียนนี้ (อยู่ใน `กติกาทีม.md` แล้ว):** ก่อนอ้างข้อเท็จจริงคู่แข่ง/งานวิจัย/ตัวเลข HSK → **ตรวจสอบก่อน ห้ามเดา** และอ้างอิงต้องมีแหล่งจริง
