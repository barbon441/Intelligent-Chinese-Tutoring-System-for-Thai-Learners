# กรอบระบบ — จาก feedback อาจารย์ (นัดจันทร์ 13 ก.ค. 2026)

> สรุปเต็ม + action items: `docs/03_บันทึก-แผนงาน/สรุปพบอาจารย์-2026-07-13.md`

## ประเด็นหลัก: "ยังไม่มีกรอบ" — ต้องนิยามโครงสร้างก่อนเพิ่มฟีเจอร์

โครงสร้างที่อาจารย์ต้องการ = **Content × ทักษะ × ระดับ**

| แกน | ต้องกำหนด |
|---|---|
| Content | มีกี่หมวด (ครอบครัว อาหาร เวลา ฯลฯ) · HSK1/HSK2 แยกหรือรวม · แต่ละหมวดกี่คำ |
| ทักษะ | ฟัง อ่าน เขียน (3 อันนี้ก่อน) · แต่ละทักษะไล่ เสียง/วรรณยุกต์ → คำ → ประโยค |
| ระดับ | HSK1 vs HSK2 ต่างกันยังไง ตามเกณฑ์ทางการ (ดู [[รูปแบบข้อสอบ-HSK-1-2]] · [[HSK-3.0-ข้อเท็จจริง]]) |

## Requirement ใหม่ที่ชัดจากรอบนี้
- **Member + Admin** — admin จัดการศัพท์/บทเรียน/แบบทดสอบ · member เก็บ progress รายคน
- **การวัดผล 2 ชั้น** — % ความพร้อมจากคะแนนเรียนต่อ content + ข้อสอบ mock (สอดคล้อง [[การวัดผลโครงงาน]])
- **ทุกอย่างต้องมี reference** — เวอร์ชัน HSK, จำนวนคำ, แนวการสอน (อิงหนังสือ/แหล่งทางการ)
- **checklist + timeline** เอาให้อาจารย์ดูทุกนัด · สิ้น ก.ค. = กรอบชัด · ส.ค. = พร้อมสอบ 50%

## ทิศทาง AI (การบ้าน)
- อาจารย์ให้ศึกษา **Ollama** (มี GPU ในเครื่อง) + **Multi-agent** แล้วนัดคุยเลือก AI 1 ประเด็นเป็นจุดขาย
- ของเรามีแกน AI อยู่แล้ว (pyBKT + Thai-L1 + FSRS — ดู [[ปรับขอบเขต-โฟกัสHSK]]) → รอบหน้านำเสนอให้อาจารย์เห็นชัด ๆ

## ✅ ตัดสินใจแล้ว (22 ก.ค. 2026 — บอลและหฤทัยเคาะตรงกันโดยอิสระวันเดียวกัน)
- **ยึด HSK 3.0 เป็น reference หลัก · ขอบเขตเฉพาะระดับ 1–2** (ลิสต์ข้อสอบจริง: HSK1 = 300 / HSK2 = 500 สะสม — ดู [[HSK-3.0-ข้อเท็จจริง]]) ตรงกับคลัง 300 คำใน DB และ PRD ที่สร้างไว้แล้ว → โน้ตหลักของการตัดสินใจนี้: [[เลือกเวอร์ชันHSK-3.0]]
- เหตุผลตอบอาจารย์: (1) เป็นมาตรฐานที่หลักสูตรทางการบังคับใช้แล้ว (大纲 พ.ย. 2025 มีผล ก.ค. 2026) มี reference ชัด (2) ครอบคลุมลิสต์ 2.0 (150 คำ) เกือบทั้งหมด → คนสอบปีนี้ (สนามยัง 2.0) ใช้ได้เลย (3) พอ 3.0 เปิดสอบจริง ระบบเราพร้อมก่อน
- งานต่อของหฤทัย: เตรียมเอกสาร reference (ลิงก์大纲/CLEC) ประกอบคำตอบ

## ✅ ตัดสินใจเพิ่ม (22 ก.ค. — บอลเคาะ · รอเสนออาจารย์นัดจันทร์)
- **Positioning: ไม่เลือกข้าง — รับทุกระดับพื้น** · เขียนว่า "ผู้เริ่มเรียน (0 หรือใกล้ 0) เตรียม HSK 1–2 — เรียนเองจาก 0 ได้ผ่านโมดูลพื้นฐานเสียง หรือครูใช้เป็นสื่อเสริมก็ได้ · pre-test + BKT ปรับเส้นทางรายคนอัตโนมัติ" — ครอบทั้งแผนเดิมและมุมอาจารย์ โดยมีกลไกจริงรองรับ (ไม่ใช่คำโฆษณา)
- **Pre-test 2 ชั้น**: ในแอปถาม "เคยเรียนจีนไหม" ก่อน — ไม่เคย = ข้ามสอบ เข้าโมดูล 0 ทันที (ไม่บังคับคนพื้นศูนย์ทำข้อสอบที่อ่านไม่ออก) · เคยบ้าง = placement สั้น 10-15 ข้อ · ส่วน pre-test เต็มรูป (mock 200 คะแนน) ใช้กับ**กลุ่มทดลองวิจัย**เพื่อวัด gain score
- **Onboarding 4 คำถาม** (ไอเดียบอล): ระดับสอบ / เหลือกี่วัน / นาทีต่อวัน / มีพื้นไหม → สร้างแผนเรียนส่วนตัว + เตือนถ้า pace เกิน ~20 คำ/วัน (เพดานที่อาจารย์แนะ) + นับถอยหลังวันสอบ · ทุกข้อข้ามได้
- **ยืนยันซ้ำ (บอล stress-test เองแล้วคงเดิม): เริ่มจาก 0 ได้จริง เพราะข้อจำกัดของแอป (สอนพูด/รูปปาก) = สิ่งที่ HSK 1–2 ไม่ได้สอบ** — ทักษะที่สอบ (หูแยกเสียง/อ่าน/ศัพท์) แอปสอนจาก 0 ได้ครบ และฝึกหูซ้ำ ๆ พร้อมวัดผลรายครั้ง แอปทำได้ดีกว่าห้องเรียน · **ข้อจำกัดเขียนตรง ๆ ในเล่ม+ใน onboarding**: "ไม่ครอบคลุมการฝึกพูด/สำเนียง — แนะนำเรียนกับครูควบคู่ · วิดีโอรูปปาก = future work"
- **เส้นทางคน 0 (สรุปดีไซน์):** โมดูล 0 สี่ด่าน (กติกาภาษา 1 หน้า → พินอินเทียบเสียงไทย → วรรณยุกต์ 4 เสียง → minimal pair จนแยกได้ ~80%) → หมวด 1 แบบ "หูมาก่อนตา" (เสียง → พินอินสี → อักษร+รูป+แปล) → เกราะ 5 ชั้น (ไทยทุกจุด/แผนคุม pace/เฉลย Thai-L1/FSRS/BKT เด้ง drill) · เวลารวม ~2 เดือนกว่า @15 นาที/วัน
