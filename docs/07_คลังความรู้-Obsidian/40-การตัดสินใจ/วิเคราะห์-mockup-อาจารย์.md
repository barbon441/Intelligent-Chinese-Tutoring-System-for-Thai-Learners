# วิเคราะห์ Mockup จากอาจารย์ (DeepSeek, Duolingo-style)

## คืออะไร
อาจารย์ส่ง mockup HTML มา 2 ไฟล์ (สร้างด้วย DeepSeek, 3 ก.ค. 2026) ชื่อแอป "เรียนจีน - Duolingo Style" — เราอ่านโค้ดทั้งไฟล์ + รันจริงด้วย Playwright แล้วสรุปว่าอะไรเอามาใช้ อะไรต้องคุยกับอาจารย์ (source เต็ม: `docs/02_ดีไซน์-Mockup/วิเคราะห์-mockup-อาจารย์.md`)

**ข้อสรุปไฟล์:** ไฟล์ 8 กับ 9 คือแอปเดียวกัน 2 รอบแก้ (diff แค่ 47 บรรทัด) — **ไฟล์ 9 ใหม่กว่า (แก้บั๊กกราฟ Dashboard) → ใช้ไฟล์ 9 เป็นตัวอ้างอิงหลัก** ไฟล์ 8 = draft

ในแอปมี 4 หน้า: Dashboard (การ์ดสรุป + กราฟรายทักษะ Chart.js) · ทดสอบระดับ 25 ข้อ (ฟัง 10, พูด 10, ไวยากรณ์ 5) · บทเรียน 5 หน่วยธีมชีวิตประจำวัน · โปรไฟล์

## ✅ ตรงกับทิศทางเรา (สัญญาณดี — อาจารย์คิดใกล้เรา)
- เป้า HSK 1–2 สำหรับคนไทยเริ่มจากศูนย์ + UI ไทยทั้งหมด
- **ตรวจทุกข้อด้วย rule เทียบเฉลย ไม่มี LLM ตรวจ** — ตรงหลักการเราเป๊ะ
- มี placement test + **วัดผลแยกรายทักษะ + กราฟ** (= สิ่งที่อาจารย์อยากเห็น)
- เก็บ state ฝั่ง client (แนว offline)

## ⚠️ ขัดกับทิศทางเรา (ไม่เอาตาม)
1. **มีข้อสอบพูด 10/25 ข้อ (40%) + ASR** — HSK 1–2 ไม่มีสอบพูด และ ASR เทียบ string ตรงตัวไม่ rigorous + ต้องออนไลน์
2. **ข้อฟังเฉลยตัวเอง** — โจทย์โชว์พินอิน/ฮั่นจื้อ ไม่ต้องฟังก็ตอบได้ (ของเราต้อง audio-only + minimal pair)
3. เกณฑ์ตัดระดับ 12/25, 18/25 เป็น**เลขสมมติ** + ไม่จับเวลา (ของเราใช้เกณฑ์จริง 120/200)
4. **tag ระดับศัพท์ผิด** (吃/喝/水/茶 โดน tag HSK2 ทั้งที่เป็น HSK1) — ไม่อิงมาตรฐาน 3.0 (ดู [[HSK-3.0-ข้อเท็จจริง]])
5. **ไม่มีแกนวิชาการของเรา** — ไม่มี BKT / FSRS / Thai-L1 / Q-matrix (เป็นแอปฝึกทั่วไป ไม่ใช่ติวเตอร์วินิจฉัย)

## 🐛 บั๊กที่เจอ (เผื่ออาจารย์ถาม)
- แบบฝึก**เรียงลำดับคำไม่ถูกตรวจเลย** (loop ใน checkUnitExercises วนไม่ถึง index ของมัน)
- อ้าง "25 ข้อ/หน่วย" แต่มีจริง 17 · streak นับไม่เคยขึ้น (0 ตลอด) · ไวยากรณ์ template ซ้ำทุกหน่วย
- เปิดหน่วยใหม่แล้วคำตอบเก่าถูกล้าง · พึ่ง CDN + ASR ออนไลน์ (ขัด PWA offline)

## 💡 ไอเดียที่เอามาใช้ในแอปจริง
1. **กราฟรายทักษะบน Dashboard** → ต่อยอดเป็นกราฟ mastery จาก [[pyBKT]]
2. **UX ข้อสอบทีละข้อ** (progress bar + ย้อนแก้ + คำตอบ persist) → ใช้กับ Mock Exam (เพิ่มจับเวลา)
3. **Interaction เรียงลำดับคำ** (คลิก pool↔บรรทัด) → ใช้กับข้อ 排列顺序 ใน [[รูปแบบข้อสอบ-HSK-1-2]] — แต่ตรวจให้จริง
4. หน่วยเรียนตามธีมชีวิตประจำวัน · Gamification เบา ๆ (XP/feedback รายข้อ) + โชว์เกณฑ์ผ่าน 120/200
5. Pattern `safeStorage` (fallback + defensive load) → ใช้กับ Dexie layer ใน [[Next.js-PWA]]

## 🎤 ท่าคุยกับอาจารย์เรื่องตัดข้อสอบพูด
ชมก่อน-ค่อยเสนอ: *"ชอบกราฟรายทักษะ + placement test UX ซึ่งตรงกับ Dashboard/Mock Exam ที่วางไว้ — ส่วนข้อสอบพูด (ASR) เนื่องจาก HSK 1–2 ไม่มีสอบพูด และการตรวจด้วย ASR ยังไม่ rigorous ขอเก็บเป็น future work ตามที่ตกลงกัน แล้วแทนด้วยแบบฝึกฟังแยกคู่เสียง (minimal pair) เสียง 2/3 และ zh/ch/sh ซึ่งวินิจฉัยจุดอ่อนคนไทยได้โดยไม่ต้องใช้ speech recognition"* — สอดคล้อง [[ปรับขอบเขต-โฟกัสHSK]]
