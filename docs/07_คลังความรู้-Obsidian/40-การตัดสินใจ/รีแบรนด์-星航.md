# รีแบรนด์: จีนรู้ใจ (中文知心) → 星航 (Xing Hang)

## มติ (14 ส.ค. 2026)
- **ชื่อแอปใหม่: 星航 (Xing Hang — "เดินเรือตามดวงดาว")** · ตะวันออกแบบและลงมือรีแบรนด์ทั้งแอป (commit `cc210f5`) · **บอลอนุมัติทั้งชื่อและธีม 14 ส.ค.**
- **ธีมทางการ: Ocean + Night Sky + Star** — น้ำเงินทะเล/ท้องฟ้ากลางคืน + ดาวทอง + มาสคอตดาว · แทนธีม Warm Ink (แดงชาด-หมึก) เดิม และแทนชุดสีจิบลิใน mockup (ตะวันเปลี่ยนทางเองตอนลงมือจริง)
- คอนเซ็ปต์: การเรียน = การเดินทาง — "ดาวนำทาง" บอกก้าวถัดไป · คำรอทวน = "ดาวที่กำลังจาง" · ปุ่มหลัก = "ออกเดินทาง" · แท็บใหม่ วันนี้/เส้นทาง/บัตรคำ/ฉัน

## ขอบเขตของชื่อ
- **ชื่อแอป/แบรนด์** = 星航 — ใช้ในเว็บ, เอกสารทีมที่ยังมีชีวิต, สไลด์นำเสนอ
- **ชื่อโครงงานทางการ** = "ระบบติวเตอร์ภาษาจีนอัจฉริยะสำหรับคนไทย" — **ไม่เปลี่ยน** (ตามเล่มที่ส่งเซ็น)
- บันทึกย้อนหลัง (บันทึกงาน/คลิปเสียง/เอกสารที่ล้อฉบับเซ็น) **ตั้งใจไม่แก้** — เป็นประวัติศาสตร์ว่าตอนนั้นเรียกชื่ออะไร
