# บันทึกงาน 14 ก.ย. 2026

## 🎤 อาจารย์ขอเพิ่ม "ทักษะพูด" — วิเคราะห์ทางเลือกเสร็จ (รอบอล+ตะวันเคาะ)

- **ที่มา:** LINE อาจารย์สมนึก *"ลองเพิ่มส่วนที่พูดด้วยได้ไหมครับ..รู้สึกเสียดาย...จะได้ครบทุกทักษะ"* + คลิปนัดรอบ 5 ถามซ้ำ 3 ครั้ง
- **ค้นพบสำคัญ:** "ซาวด์ที่ผมให้ไป" ที่แกพูดในคลิป = **mockup HTML ที่แกส่งให้ 3 ก.ค.** (`docs/02_ดีไซน์-Mockup/9-…html` และไฟล์ 8) — มีข้อสอบพูด 10 ข้อ "กดไมค์แล้วพูดตาม" ตรวจด้วย `webkitSpeechRecognition` zh-CN อยู่แล้ว (ยืนยันในไฟล์จริง: บรรทัด 324/443/552-573) · ทีมตัดทิ้งตอนปรับสโคป ก.ค. → แกเลย "เสียดาย"
- **วิเคราะห์ (ค้น 3 ทาง 11 เอเจนต์ + ตรวจย้อน):** ทางที่แนะนำ = **Web Speech API zh-CN ในเบราว์เซอร์** (ฟรี ไม่ผูกบัตร 3–5 วัน) → เทียบพินอินแบบ rule-based → ป้าย Thai-L1 (วรรณยุกต์เพี้ยน / ไม่ม้วนลิ้น) · ตำแหน่ง = "ฝึกพูดตามรูปแบบ HSKK ระดับต้น + ตัวช่วยเช็กเบื้องต้น" **ไม่ใช่ประเมินการออกเสียง** (บทคัดย่อ CSTI ที่ส่งแล้วประกาศไว้ว่าการประเมินอยู่นอกขอบเขต — ถ้อยคำนี้ยังจริง) · ผลพูดจดลง attempts เป็น `asr_hint` ไม่ป้อน BKT รอบแรก
- ทางอื่นที่ตัด: Azure PA (ต้องบัตร/ไม่มี tone score zh) · Whisper บน Render (OOM) · Google STT (ต้องบัตร) · SpeechSuper (ไม่ฟรี) · wav2vec2 MDD = future work ในเล่ม · สำรอง: Vosk grammar / Groq Whisper fallback · เฟส 2: เส้นเสียง F0 ในเบราว์เซอร์
- **งานวิจัยรองรับที่ตรวจแล้ว 8 ชิ้น** (Wu 2025 · Chun 2015 · Godfroid 2017 · Rungruang & Mu 2017 · สุภาษา&ฉี 2017 ThaiJO · Inceoglu 2023 · McCrocklin 2026 · Graham & Roll 2024) + HSKK 初级 ทางการ · Cheng 2025 ต้องเปิดยืนยันก่อนใส่เล่ม
- **ผลกระทบ:** จุดยืน "พูด = นอกขอบเขต" ถูกเขียนไว้ 40 จุด (CLAUDE.md, กติกาทีม, ARCHITECTURE หลักเหล็ก, PRD, ME-05, CHECKLIST, proposal, บทคัดย่อ, บทพูด, roadmap m0-5) → ถ้าเคาะเพิ่ม ต้องไล่แก้ให้แยกคำ "ฝึกพูดตาม (ใน MVP)" กับ "ประเมินสำเนียง (future work)"
- เอกสารเต็ม + ร่างข้อความตอบอาจารย์: [[ทักษะพูด-วิเคราะห์ทางเลือก]] (`docs/08_สเปค-พัฒนา/`)
- **รอเคาะ:** ทาง A (แนะนำ) / B / C · บอลเช็ค LINE ว่าแกส่งอะไรอื่นอีกไหม · ทดสอบ Web Speech บนมือถือจริงของทีม 30 นาที
