## 📼 อาจารย์รอบ 6 พูดถึง "ตารางโมเดล" ว่าอะไรบ้าง (บอลถาม 28 ก.ย.)

คลิป 14 ก.ย. บรรทัด ~301–405 · อาจารย์ชี้ **2 ตาราง** ไม่ใช่ทั้งโซน BKT:
1. **ตารางผลโมเดลรายคน (mastery_snapshots)** — *"คุณเก็บเขาใหม่ หรือประเมินจากที่เก็บอยู่ในฐานข้อมูล?"* → *"เก็บซ้ำซ้อนกับข้อมูลหลักที่มีอยู่"* → *"เขียนโค้ดดึง query จากข้อมูลมา summary ไม่ได้หรอ ทำไมต้องหลายตาราง"* → *"ไม่ต้องมีตารางซ้ำแบบนี้อีก มันก็จะเป็น summary ของตารางนี้เลย"* · ⚠️ บอลตอบในคลิปว่า *"มันเหมือนจะเป็นรวมทุกคน ไม่ได้แยก"* (นั่นคือค่าพารามิเตอร์ใน bkt_training_runs/skills ไม่ใช่ mastery_snapshots) — อาจารย์อาจเข้าใจว่าตารางนี้เป็นสรุปรวม
2. **recommendations** — *"คำอธิบายพวกนี้มาจากไหน แต่ละคนจะเขียนคอมเมนต์ครบเหรอ"* → *"ตั้งเกณฑ์จุดแข็ง/จุดอ่อน ทำ dashboard แล้วให้ Gemini เขียนคำแนะนำ input คือคะแนนแต่ละสกิล"* → *"ถ้าตัดไปได้ก็ตัด… ก็จะได้ลดตารางไป"* (ตัดแล้ว 23 ก.ย.)
- **ไม่ได้ติ**: bkt_training_runs · skills · thai_l1_catalog (อาจารย์ถาม "คำอธิบายมาจากไหน" = thai_l1_catalog ตอบได้)
- **🔍 ที่มาจริงของคำติ "ซ้ำซ้อน" (บอลทวนคลิป 28 ก.ย.):** อาจารย์ถามคำถามสำคัญ *"คุณเก็บเขาใหม่ หรือประเมินจากที่เก็บอยู่ในฐานข้อมูลแล้ว?"* — คำตอบที่ถูกคือ "ประเมินจาก attempts ด้วยโมเดล แล้วเก็บ*ผลประเมิน* 1 แถว/คน/ทักษะ" แต่บอลตอบ "เก็บ" + บรรยายว่า "บันทึกการตอบของผู้เรียน… รวมทุกคน ไม่ได้แยก" → อาจารย์เข้าใจว่า mastery_snapshots = ตารางสรุปจำนวน (ผ่านกี่คำ) ที่ก๊อปจาก attempts → จึงติว่า query ได้ · **บอลสรุปเองได้ถูกแล้ว:** attempts = บันทึกการตอบรายคนรายข้อจริง · mastery_snapshots = ตารางกลาง คน×ทักษะ บอกว่ารู้ทักษะนี้กี่ % · **รอบ 7 ต้องเปิดด้วยการแก้ความเข้าใจนี้ก่อน** ไม่ใช่เถียงเรื่องเก็บประวัติ · "ลดรูป" (ค่าล่าสุดอย่างเดียว) เป็นข้อเสนอฝั่งเรา ไม่ใช่คำอาจารย์ — ถ้าใช้ต้องพูดว่า "ปรับตามที่อาจารย์ติ" ไม่ใช่ "ตามที่แนะนำ"

**วันแรก:** ① PDPA → สมัคร *(users)* ② ตอบ 3 คำถาม *(users.target_level / exam_date / self_level)* ③ ทำ pre = ข้อสอบจำลอง HSK1 ชุดเดียว "ไม่รู้ให้เดา ไม่มีผ่าน-ตก" *(sessions kind=pretest · attempts)* ④ พาไปเริ่ม: ตอบ "ยังอ่านไม่ออก" → โมดูล 0 *(foundation_progress)* · นอกนั้นดูคะแนน pre พาร์ตฟัง ต่ำ → แนะนำโมดูล 0 (ข้ามได้) · สูง → หมวด 1

**ทุกวัน (~10 วัน):** ⑤ เปิดแอป ปุ่มใหญ่ "เรียนต่อ" + วันนี้ทวนกี่คำ ⑥ ทวนคำเก่าที่ถึงกำหนด เพดาน 40 คำ/วัน *(review_states · attempts)* ⑦ เรียนคำใหม่ 10 คำ บัตรคำ+ฟัง/อ่าน/จับคู่ *(review_states แถวใหม่ · category_progress.words_learned)* ⑧ เรียงประโยคที่ใช้เฉพาะคำที่รู้ (เช็กส่วนผสมจาก sentence_words) *(sentence_states)* ⑨ ครบคำในหมวด → ควิซ 10 ข้อ สุ่มสด ≥7/10 ปลดล็อกหมวดถัดไป ตกทำใหม่ได้ *(sessions kind=quiz · category_progress)* ⑩ เบื้องหลัง BKT อ่าน attempts → ใครแม่น/อ่อนทักษะไหน *(mastery_snapshots)* ⑪ หน้าจุดแข็ง/จุดอ่อน: % รายทักษะ + คำอธิบายจุดผิดคนไทย *(thai_l1_catalog)* + Gemini แต่งคำแนะนำสด → กดฝึกเจาะ

**วันที่ 10:** ⑫ post = ชุดเดิม สับลำดับ ครั้งเดียว *(sessions kind=posttest · attempts)* ⑬ เห็นผลเทียบ pre→post รายหมวด/ฟัง-อ่าน = พัฒนาการของตัวเอง

ยังไม่เคาะ: เกณฑ์คะแนน pre (PL-05) · จำนวนข้อ 40/ย่อ · เวลา post (พร้อมกัน/ทยอย · หลัง D12) · ทักษะพูดแทรกที่ ⑦ ถ้าเคาะวิธี A
