## 📄 บทที่ 1: เขียน 1.1 ใหม่รอบสุดท้าย แล้วไล่ 1.2 ให้ตามทัน

- **1.1 บีบเหลือ 3 ย่อหน้า** เฟรมรอบ **"หน้าที่ของติวเตอร์ 4 อย่าง"** = (1) จำว่าพลาดอะไรซ้ำ (2) อธิบายว่าผิดเพราะอะไร (3) สั่งทบทวนก่อนลืม (4) บอกว่าก้าวหน้าถึงไหน — สี่ข้อนี้แมปกับ 4 โมดูลแกน (BKT / Thai-L1 / FSRS / ความก้าวหน้า+ประมาณเวลา) ทำให้ชื่อโครงงาน "ระบบติวเตอร์อัจฉริยะ" ถูกอธิบายในเนื้อความ ไม่ใช่แค่ตั้งชื่อไว้เฉย ๆ
- **ตัดตัวอย่าง `b–ปอ p–ผอ m–มอ` ออกจาก 1.1 → ย้ายลง 1.5.1 โมดูล 1** — เหตุผล: 1.1 คือที่มาและความสำคัญ ไม่ใช่ที่อยู่ของรายละเอียดระดับเนื้อหาบทเรียน · **ก่อนตัดต้องเช็กก่อนว่าตัวอย่างนี้มีอยู่ที่เดียวในโปรเจกต์** (grep ทั้ง repo) ถ้าลบเฉย ๆ จะหายจากเอกสารทุกฉบับ
- **1.2 วัตถุประสงค์ปรับ 2 ข้อ** ให้รับกับ 1.1 ใหม่
  - 1.2.1 เติม "เสมือนติวเตอร์ส่วนตัว" + ผู้เรียนไม่มีพื้นฐาน + บทเรียนพื้นฐานเสียง (เดิม 1.2 ไม่มีข้อไหนรับผิดชอบโมดูล 0 เลย ทั้งที่ 1.1 เปิดเรื่องด้วยจุดผิดที่เป็นเรื่องเสียงล้วน ๆ)
  - 1.2.4 เติม "แสดงความก้าวหน้ารายทักษะ" (เดิมมีแต่ครึ่งหลัง = ประมาณเวลาที่เหลือ หน้าที่ติวเตอร์ข้อ 4 จึงขาดไปครึ่งหนึ่ง)

### อ้างอิงใน 1.1 ที่ยืดเกินหลักฐาน (ตรวจซ้ำกับ `data/thai-l1/citation-audit.md` แล้วจริง)

- **[12] [13] ไม่ใช่งานเรื่อง "ตำแหน่งของคำขยาย"** — ทั้งคู่เป็นงาน**หน่วยคำเสริมกริยา/บทเสริมผล (补语)** → ต้องแก้ตัวอย่างเป็น "การใช้และการวางคำเสริมกริยา" ไม่งั้นกรรมการที่รู้จีนเปิดบรรณานุกรมจับได้ทันที
- **[9] Cai & Lee (2015) ใช้เกินขอบเขต 2 จุด** — audit ของเราเองระบุว่างานนี้ **ไม่พูดถึงวรรณยุกต์เลย** (tone/tonal/pitch = 0 ครั้ง) ขอบเขตแค่พยัญชนะ+สระ กลุ่มตัวอย่างคนไทย 5 คน และ**บทสรุปของงานเองบอกว่าอำนาจทำนายของ CA ต่ำกว่าที่เคยเคลมกัน** → ใช้เป็น "กรอบทฤษฎีการถ่ายโอน L1" ได้ (แบบที่ย่อหน้า 3 ใช้ = ถูกต้องแล้ว) แต่**ห้ามใช้ค้ำประโยคเหมารวม "ต่างภาษาแม่ผิดคนละจุด"**
- **[9] [10] [11] เป็นหลักฐานด้านการออกเสียง (production) แต่ประโยคเคลมเรื่องการฟัง (perception)** → เปลี่ยนเป็น "มักถูกแทนด้วยเสียงไทยที่ใกล้เคียง"
- **[8] Rungruang & Mu เป็น perception test + สัมภาษณ์ ไม่ใช่งานอะคูสติก** → รองรับได้ว่า "T2/T3 เป็นคู่ที่แม่นน้อยที่สุด" แต่ไม่รองรับคำอธิบาย "เส้นเสียงไม่ตรงกับวรรณยุกต์ไทยตัวใดพอดี"
- ประโยคเปิดเล่ม ("คนไทยเรียนจีนเพิ่มขึ้นต่อเนื่อง + HSK ใช้เป็นเกณฑ์") ยังไม่มีอ้างอิงรองรับ
