# 🎓 ออกแบบการสอนรายทักษะ: ฟัง · อ่าน · เขียน (HSK1 vs HSK2)

> ตอบการบ้านอาจารย์: "แต่ละทักษะจะสอนยังไง มีอะไรบ้าง HSK1 กับ 2 ต่างกันยังไง" — ยึดมาตรฐาน 3.0 (มติทีม 22 ก.ค.)
> คู่กับ: `กรอบระบบ-CHECKLIST.md` (โครงระบบ) · `TODO-ออกแบบเนื้อหา.md` (งานเนื้อหาหฤทัย — เอกสารนี้คือร่างของ "ขั้น 2" ให้เธอเคาะ+แปะ reference)

## 1. ตั้งต้นจากข้อสอบจริง: HSK1/HSK2 สอบอะไร (ตาม大纲 3.0 — verify แล้ว)

| | **HSK 1** | **HSK 2** |
|---|---|---|
| ทักษะที่สอบ | ฟัง 20 ข้อ + อ่าน 20 ข้อ = 40 ข้อ | ฟัง + อ่าน + **เขียน (书写) 10 ข้อ** = 60 ข้อ |
| เขียน | ❌ ไม่มี | ✅ มี: ให้พินอิน → เขียนอักษร (จากลิสต์ 100 ตัว) |
| พินอิน | มีกำกับในข้อสอบ | มีกำกับ |
| คำศัพท์ | 300 คำ | 500 คำ (สะสม) |
| เกณฑ์ | สเกล 200 ผ่าน 120 | สเกล 200 ผ่าน 120 |
| หน่วยภาษาหลัก | เสียง/คำ/ประโยคสั้น/บทสนทนา 1 คู่ | ประโยค/บทสนทนาหลายคู่/ข้อความสั้น |

> ⬜ รอเช็ก: สัดส่วนข้อ ฟัง/อ่าน ของ HSK2 (3.0) จาก PDF 大纲 — งานหฤทัยขั้น 2 (อย่าเดาตัวเลข)

**หลักการใหญ่:** เราสอนเพื่อ "สอบผ่าน" → **ทุกกิจกรรมฝึกต้อง map กลับไปหาประเภทข้อสอบจริงได้** และทุกข้อตรวจด้วย rule เฉลยตายตัว

## 2. โครงการสอนร่วม (ใช้เหมือนกันทุกทักษะ ทุกหมวด)

**บันได 3 ขั้นตามที่อาจารย์วาง: เสียง/วรรณยุกต์ → คำ → ประโยค**

```
ขั้น 0 พื้นฐานเสียง (ครั้งเดียว ก่อนหมวดแรก)   ขั้น 1 คำ (ในแต่ละหมวด)     ขั้น 2 ประโยค (ท้ายหมวด → ข้ามหมวด)
พินอิน + วรรณยุกต์ 4 เสียง + minimal pair  →  บัตรคำ+เสียง+รูป → ฝึกคำ  →  ประโยคตัวอย่าง → ฝึกประโยค → ควิซ
```

**Loop ในทุกหมวด: เรียน → ฝึก → วัด → ทวน** (ทวน = FSRS ทำงานข้ามหมวดอัตโนมัติ)
- **โหมดเรียน/ฝึก**: ใจดี — ฟังซ้ำได้ ปรับความเร็วได้ เฉลยทันที + คำอธิบาย Thai-L1
- **โหมดสอบ (ควิซ/mock)**: กติกาสนามจริง — เสียงเล่น 2 รอบ ห้าม pause ไม่โชว์คำถามเป็นข้อความ

---

## 3. 🎧 ทักษะฟัง — สอนยังไง มีฟังก์ชันอะไร

**เป้า:** หูแยกเสียงได้ (จุดตายคนไทย: วรรณยุกต์ 2/3, zh/ch/sh) → ฟังคำรู้ความหมาย → ฟังประโยค/บทสนทนาจับใจความ

| ขั้น | สอน (input) | ฝึก (ฟังก์ชัน) | ข้อสอบจริงที่ map |
|---|---|---|---|
| เสียง | หน้าเรียนวรรณยุกต์ 4 เสียง (กราฟเส้นเสียง + พินอินสี + ปุ่มฟังเทียบ) | **minimal pair drill**: ฟัง 1 เสียง → เลือกพินอิน (ลวงด้วยคู่ 2/3, zh/ch/sh ตาม Thai-L1 catalog) | (พื้นฐานของทุกข้อฟัง) |
| คำ | บัตรคำมีเสียง (เล่นอัตโนมัติ) + ปุ่มปรับความเร็ว 0.75x/1x + เสียง ช/ญ | ฟังคำ → เลือกรูป · ฟังคำ → เลือกฮั่นจื้อ/พินอิน · ฟัง → จริง/เท็จกับรูป | HSK1 พาร์ตต้น (ฟังเลือกรูป/จริงเท็จ) |
| ประโยค | ประโยคตัวอย่างในหมวด + เสียงอ่าน (ช้า→ปกติ) | ฟังประโยค → เลือกรูป/จริงเท็จ · **ฟังบทสนทนา → ตอบ MCQ** (เช่น "B กินข้าวหรือยัง") | HSK1-2 พาร์ตบทสนทนา |

**HSK1 vs HSK2 (ฝั่งฟัง):** HSK1 = คำ/ประโยคสั้น/บทสนทนา 1 คู่ถาม-ตอบ, มีรูปช่วยเยอะ, เสียงช้ากว่า · HSK2 = บทสนทนายาวขึ้นหลายคู่, ตัวเลือกเป็นข้อความมากขึ้น, ความเร็วปกติ → **ฟังก์ชันเดียวกัน แต่ต่างที่ "วัตถุดิบ" (ความยาว/ความเร็ว/มีรูปไหม)** ปรับด้วยข้อมูล ไม่ต้องเขียนโค้ดใหม่

**กฎเหล็ก:** ข้อฟังห้ามโชว์ข้อความของสิ่งที่ให้ฟัง (กันข้อสอบเฉลยตัวเอง) · โหมดสอบ = เสียง 2 รอบ + auto-advance

## 4. 📖 ทักษะอ่าน — สอนยังไง มีฟังก์ชันอะไร

**เป้า:** เห็นฮั่นจื้อ (มีพินอินช่วย) → รู้ความหมาย → อ่านประโยค/ข้อความสั้นจับใจความ → ค่อย ๆ "หย่าพินอิน"

| ขั้น | สอน | ฝึก (ฟังก์ชัน) | ข้อสอบจริงที่ map |
|---|---|---|---|
| คำ | บัตรคำ: ฮั่นจื้อใหญ่ + พินอินสีวรรณยุกต์ + รูป + คำแปล | เห็นคำ → เลือกคำแปล · จับคู่คำ ↔ รูป · จริง/เท็จ (คำกับรูปตรงไหม) | HSK1 พาร์ตจับคู่รูป |
| ประโยค | ประโยคตัวอย่าง 5-10 ประโยค/หมวด + **ปุ่มซ่อน/โชว์พินอิน** | เติมคำในช่องว่าง (เลือกจาก word bank) · จับคู่คำถาม ↔ คำตอบ · จริง/เท็จ | HSK1-2 พาร์ตเติมคำ/จับคู่/จริงเท็จ |
| ไวยากรณ์ | จุดไวยากรณ์แทรกในหมวด (的/吗/个/了 ตามหมวดที่ใช้จริง) | **เรียงคำเป็นประโยค** (ลาก/แตะ — มีแล้ว!) ลวงด้วยลำดับคำแบบไทย | (แบบฝึกเสริม — เป็นข้อจริงของ HSK3 แต่ดัก Thai-L1 ได้ดีสุด) |

**HSK1 vs HSK2 (ฝั่งอ่าน):** HSK1 = ระดับคำ+ประโยคเดี่ยว · HSK2 = ประโยคเชื่อมกัน/ข้อความสั้น + เติมคำในบริบทยาวขึ้น → เพิ่ม "ข้อความสั้น 2-3 ประโยค → ตอบคำถาม" เป็นฟังก์ชันใหม่ตอนขยาย HSK2

## 5. ✍️ ทักษะเขียน — นิยาม + สอนยังไง

**นิยาม "เขียน" ของเรา (อาจารย์รับแล้ว):** การ**ประกอบภาษา** = เลือกคำ/เรียงคำเป็นประโยคที่ถูกไวยากรณ์ — ไม่ใช่คัดลายมือ

| ระดับ | ฝึก (ฟังก์ชัน) | หมายเหตุ |
|---|---|---|
| HSK1 | เรียงคำเป็นประโยค (มีแล้ว) · เติมคำที่หายไป | HSK1 **ไม่มีพาร์ตเขียนในข้อสอบจริง** → เขียนของ HSK1 = แบบฝึกเสริมไวยากรณ์ ไม่ใช่พาร์ตสอบ |
| HSK2 | เพิ่ม: **พินอิน → เลือก/พิมพ์อักษรที่ถูก** (จำลอง 书写 บนเว็บ) | ข้อสอบจริงมี 书写 10 ข้อจากลิสต์ 100 ตัว — จำกัดมาก ทำไหว |
| optional (challenge อาจารย์) | ฝึกเขียนตามลำดับขีด (ไลบรารี Hanzi Writer — ฟรี, โหลดเฉพาะตอนกด) เฉพาะ 100 ตัวของลิสต์ 书写 | ตัดได้ถ้าเวลาไม่พอ (อาจารย์อนุญาตแล้ว) — ตัดสินใจตอนขยาย HSK2 |

## 6. ตารางรวมฟังก์ชัน (map ทักษะ × สถานะ)

| ฟังก์ชัน | ทักษะ | ระดับ | สถานะ |
|---|---|---|---|
| บัตรคำ + พินอินสี + เสียง | อ่าน+ฟัง | 1,2 | ✅ มีแล้ว |
| ทบทวน FSRS | ทุกทักษะ | 1,2 | ✅ มีแล้ว |
| ฝึกอ่าน MCQ (คำ→แปล) / ฝึกฟัง MCQ (เสียง→คำ) | อ่าน/ฟัง | 1 | ✅ มีแล้ว (จะ refactor เข้าระบบหมวด) |
| เรียงคำเป็นประโยค (ลาก/แตะ) | เขียน/ไวยากรณ์ | 1,2 | ✅ มีแล้ว |
| หน้าเรียนวรรณยุกต์ + minimal pair drill | ฟัง | 0 (พื้นฐาน) | ⬜ ก.ค.–ส.ค. |
| หน้าเลือกหมวด (5 หมวด) + loop เรียน-ฝึก-วัด | โครง | 1 | ⬜ ส.ค. |
| ปุ่มปรับความเร็วเสียง + เสียง ช/ญ | ฟัง | 1,2 | ⬜ ส.ค. (ง่าย — playbackRate) |
| รูปประกอบคำ + ข้อฟัง/อ่านแบบเลือกรูป | ฟัง/อ่าน | 1 | ⬜ ส.ค. (ต้องหาคลังรูปฟรี) |
| เติมคำจาก word bank · จับคู่ถาม-ตอบ | อ่าน | 1,2 | ⬜ ส.ค. |
| ปุ่มซ่อน/โชว์พินอิน (หย่าพินอิน) | อ่าน | 1,2 | ⬜ ส.ค. (ง่าย) |
| ควิซท้ายหมวด + log รายทักษะ | วัดผล | 1 | ⬜ ส.ค. |
| Mock Exam โหมดสนามสอบ (เสียง 2 รอบ, จับเวลา, 200/120) | วัดผล | 1 | ⬜ ส.ค.–ก.ย. |
| วินิจฉัย Thai-L1 ตอนตอบผิด + เจาะฝึกซ้ำ | ทุกทักษะ | 1,2 | ⬜ ก.ย. (catalog พร้อมแล้ว) |
| ข้อความสั้น→ตอบคำถาม · จำลอง 书写 | อ่าน/เขียน | 2 | ⬜ เฟส HSK2 |
| ฝึกลำดับขีด (Hanzi Writer, 100 ตัว) | เขียน | 2 | 🟡 optional/challenge |

## 7. คำตอบสั้นไว้ตอบอาจารย์ "HSK1 กับ 2 สอนต่างกันยังไง"

> "โครงการสอนเหมือนกันครับ — ไล่จากเสียง → คำ → ประโยค ในทุกหมวด แต่**ต่างกันที่วัตถุดิบและน้ำหนัก**: HSK1 หน่วยหลักคือคำและประโยคสั้น มีรูปภาพช่วยเยอะ เสียงช้ากว่า และไม่มีพาร์ตเขียน · HSK2 ขยับเป็นบทสนทนายาวขึ้นและข้อความสั้น ความเร็วเสียงปกติ และเพิ่มพาร์ตเขียนตามข้อสอบจริง (พินอิน→อักษร จากลิสต์ 100 ตัว) — ฟังก์ชันในแอปจึงใช้ชุดเดียวกัน แต่ป้อนเนื้อหาคนละระดับครับ"

## 8. ขอบเขต HSK2 — เขียนไว้ล่วงหน้า (คำสั่งอาจารย์ 23 ก.ค.: "สอบ 50% จะถามว่า HSK2 ทำอะไรเพิ่ม")

- **เนื้อหา:** +200 คำ (รวม 500 สะสม ตามลิสต์ 3.0) ใช้โครงหมวดเดิม · ไวยากรณ์สะสม 129 จุด
- **ข้อสอบจริง HSK2 (3.0):** ฟัง + อ่าน + 书写 10 ข้อ รวม 60 ข้อ · สเกล 200 ผ่าน 120 เท่าเดิม (สัดส่วนข้อฟัง/อ่านต้องเช็คจาก PDF 大纲 จริง — งาน 1.3.2 ห้ามเดา)
- **ฟังก์ชันที่ "เพิ่มใหม่" มีแค่ 2 ตัว:** ① จำลอง 书写 — เห็นพินอิน → เลือก/พิมพ์อักษร จากลิสต์ 100 ตัว (รูปแบบบนเว็บรอเคาะกับอาจารย์) ② อ่านข้อความสั้น 2-3 ประโยค → ตอบคำถาม
- **ที่เหลือใช้ฟังก์ชันเดิม ป้อนเนื้อหายากขึ้น:** บทสนทนาหลายคู่ · เสียงความเร็วปกติ · ตัวเลือกเป็นข้อความมากขึ้น — ห้ามเขียนโค้ดแยกชุด (กฎ: ความต่างระดับทำผ่านข้อมูล)
- **Mock HSK2:** 60 ข้อฟอร์แมตจริง — อยู่ roadmap กล่อง "เฟสถัดไป" (m11-1 ถึง m11-5)
- **เงื่อนไขเริ่มทำ:** โครง HSK1 นิ่ง + ผ่าน midterm · ตัดออกได้ทั้งก้อนถ้าเวลาไม่พอ (กฎเหล็กคุมสโคป — ตัดจากท้าย ห้ามตัดแกน)
