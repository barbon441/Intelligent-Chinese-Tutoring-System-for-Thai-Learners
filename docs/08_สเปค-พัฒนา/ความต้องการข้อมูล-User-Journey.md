## ระยะที่ 4 · บทปูพื้นฐานเสียง (วันที่ 1-4)

**เธอทำ:** 4 ด่าน — กติกาภาษาจีน → พินอินเทียบเสียงไทย → วรรณยุกต์ → เกมฟังแยกเสียง

**เธอคิด:** *"เสียง 2 กับ 3 ฟังเหมือนกันหมดเลย"* ← จุดที่งานวิจัยบอกว่าคนไทยพลาดหนักที่สุด และเป็นจุดที่แอปอื่นไม่รู้ว่าต้องดัก

**ระบบทำ:** PA-01 ประตูหมวด 1 เปิดเมื่อแยกเสียงได้ ~80% · ใช้เสียงหลายผู้พูดเพื่อให้ทักษะถ่ายโอนได้จริง (m0-4) · ทุกครั้งที่ตอบเก็บเป็น KC (`TL-TONE-*` / `TL-RETRO-*`)

**เก็บลง:** `foundation_progress(stage, tries, best_accuracy)` + `attempts(generator='ear_game', skill_id)`

> **⚠️ กติกาที่ยังไม่เคาะ (PA-08)** ถ้าเธอติดด่านนี้ 5 วันแล้วยังไม่ถึง 80% จะเกิดอะไรขึ้น — ยังไม่มีคำตอบ · persona "กัน" ในสมุดกฎชนกำแพงนี้พอดี

## ระยะที่ 5-6 · หมวดแรก (วันที่ 5-12)

**วงจรรายวัน ~30 นาที:**

```
เปิดแอป → ปุ่มเดียว "เรียนต่อ" (MO-01)
   │
   ├─ มีคำถึงกำหนดทวน → ทวนก่อน       → attempts(context=review) + review_states
   ├─ ไม่มี            → บัตรคำ 10 คำ  → attempts(generator=flashcard)
   └─ เรียนครบชุดแล้ว  → ฝึก 4 โหมด    → sessions(kind=practice, mode=…)
                             │
                             └─ ควิซท้ายหมวด 10 ข้อ → sessions(kind=quiz, attempt_no, score)
```

**เธอคิด:** *"วันนี้ทำอะไรต่อดี"* → ระบบตอบด้วยปุ่มเดียว ไม่ให้เธอต้องตัดสินใจ

**ตอนทำควิซ:** ผ่าน ≥7/10 → ปลดล็อกควิซหมวดถัดไป (QZ-12) · ตก → ปุ่ม "ฝึกข้อที่พลาด" + สอบใหม่ได้ทันทีไม่จำกัด สุ่มข้อชุดใหม่ (QZ-05) · ตกซ้ำ 2 ครั้ง → ชวนกลับไปเรียนบัตรคำ **แนะนำ ไม่บังคับ**

**สำคัญ:** ทุกครั้งที่ทำซ้ำยัง log ครบ ไม่ใช่แค่ครั้งที่ดีที่สุด (QZ-09) — คะแนนที่โชว์ใช้ครั้งดีสุด แต่ BKT กินทุกครั้ง

## ระยะที่ 7 · หายไป แล้วกลับมา (สัปดาห์ที่ 3)

**เธอทำ:** สอบกลางภาค หายไป 2 สัปดาห์ กลับมาเปิดแอป

**เธอคิด:** 🔴 *"คงตามไม่ทันแล้วมั้ง"* — persona "นัท" ในสมุดกฎชี้ว่านี่คือจุดเลิกใช้แอปสูงสุด

**ระบบต้องทำ:** FS-06 **ห้ามโชว์ "180 คำรอทวน"** แสดงเฉพาะยอดของวันนี้ · MO-03 ข้อความต้อนรับโทนเพื่อนติว **ห้ามตำหนิ** · FS-04 cap คิวรายวัน คำที่เกินทยอยวันถัดไป ไม่หายไปไหน

> **🔴 จุดหลุดที่ 2 + กฎที่พังอยู่** FS-04 คำนวณ cap จาก *"นาทีต่อวันที่ผู้ใช้ตั้งไว้"* แต่คำถามนั้นถูกตัดออกจาก onboarding ไปแล้ว 6 ส.ค. (ON-02) → **สูตรนี้ไม่มีอินพุตแล้ว ต้องเคาะใหม่**

## ระยะที่ 8 · ระบบเริ่มรู้จักเธอ ⭐

**เธอเห็น:** การ์ดบนหน้าแรก — *"จุดที่ควรฝึกเพิ่ม: แยกเสียง 2 กับ 3"* พร้อมปุ่มฝึกเจาะ

**เธอคิด:** *"มันรู้ได้ยังไงว่าฉันพลาดตรงนี้"* ← **โมเมนต์ที่แอปเลิกเป็นบัตรคำ แล้วกลายเป็นติวเตอร์**

**เก็บลง — ทั้งเส้น:**

```
attempts (สะสม)  →  pyBKT  →  mastery_snapshots (p_mastery ต่ำ)
                                      │
                                      ▼
                            recommendations (reason='low_mastery')
                                      │  เธอกดทำ
                                      ▼
                        recommendations.followed_session_id
```

> ระยะนี้คือ**ทั้งจุดขายและทั้งบทที่ 4 ของเล่ม** — ถ้า `recommendations` ไม่ถูกบันทึก จะพิสูจน์ได้แค่ว่า "โมเดลทำนายแม่น" แต่พิสูจน์ไม่ได้ว่า "การวินิจฉัยทำให้ผู้เรียนเปลี่ยนพฤติกรรม"

# ส่วนที่ 3 · 8 รายการที่ยังไม่มีที่เก็บ

เรียงตามความเสียหายถ้าไม่มี:

| อันดับ | ขาดอะไร | ถ้าไม่มีแล้วพังยังไง |
|---|---|---|
| 1 | **เวอร์ชันแอปในแถวการตอบ** | แก้บั๊กระหว่างทดลอง → ข้อมูลก่อน/หลังแก้ปนกันถาวร แยกไม่ออก **ย้อนหลังเติมไม่ได้** |
| 2 | **เวอร์ชันพารามิเตอร์ BKT** | ตัวเลข AUC ในเล่มอ้างไม่ได้ว่ามาจากการเทรนรอบไหน — กรรมการถามแล้วตอบไม่ได้ |
| 3 | **เวอร์ชันข้อความ consent** | แก้ข้อความแล้วไม่รู้ว่าใครยอมรับฉบับไหน = ปัญหา PDPA จริง ไม่ใช่แค่เรื่องเทคนิค |
| 4 | **บทบาท (role)** | RO-03 "หฤทัยกดอนุมัติได้คนเดียว" บังคับในระดับข้อมูลไม่ได้ |
| 5 | **ตารางหมวด** | แก้ชื่อ/ลำดับหมวดต้องแก้โค้ดแล้ว deploy |
| 6 | **คู่ minimal pair + เนื้อหาบทปูพื้นฐานเสียง** | หฤทัยแก้เนื้อหาเองไม่ได้ ต้องผ่านบอลทุกครั้ง |
| 7 | ค่าตั้งซ่อนพินอิน | เปลี่ยนเครื่องแล้วค่าหาย (เล็ก) |
| 8 | บันทึกการโอนสิทธิ์อนุมัติ | กติกาที่ทีมเขียนเองแต่ไม่มีที่บันทึก (เล็ก) |

**3 อันดับแรกมีลักษณะเดียวกันคือย้อนหลังเติมไม่ได้ และทั้งสามเกี่ยวกับความน่าเชื่อถือของตัวเลขในเล่มโดยตรง**

# ส่วนที่ 4 · คำถามที่ฐานข้อมูลต้องตอบได้

ใช้เป็นเช็กลิสต์ตอน **ขั้น 5 (Validate)** — เขียน query จริงแล้วต้องได้คำตอบทุกข้อ ถ้าข้อไหนตอบไม่ได้แปลว่าออกแบบตกอะไรไป

1. ผู้เรียนคนนี้ผ่านหมวดไหนแล้ว ได้กี่คะแนน จากการทำครั้งที่เท่าไหร่
2. ทักษะนี้ของคนนี้ ตอบถูกกี่ครั้งจากกี่ครั้ง **เรียงตามเวลา** *(อินพุตตรงของ pyBKT)*
3. คะแนน pre กับ post ของคนนี้ต่างกันเท่าไหร่ แยกรายทักษะ *(gain score ของเล่ม)*
4. KC ไหนมีโอกาสตอบน้อยกว่า 5 ครั้ง *(เตือนก่อนที่ AUC จะไม่มีความหมาย)*
5. ข้อนี้อยู่ชุดข้อสอบไหน และชุดนั้นเปิดให้ทำได้หรือยัง
6. วันนี้คนนี้ต้องทวนกี่คำ
7. ข้อสอบในหมวดนี้ที่สถานะ "อนุมัติ" เหลือกี่ข้อ *(เตือนแอดมินเมื่อต่ำกว่าขั้นต่ำสุ่มควิซ)*
8. ระบบเคยแนะนำอะไรให้คนนี้ และเขาทำตามกี่ครั้ง
9. ผู้เข้าร่วมทดลองใช้แอปมากี่วันแล้ว
10. คนที่ถอนความยินยอมไปแล้ว ข้อมูลเขาถูกทำให้นิรนามครบหรือยัง
