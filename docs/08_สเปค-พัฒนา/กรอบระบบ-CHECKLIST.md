# 🏗️ กรอบซอฟต์แวร์ "จีนรู้ใจ" + Checklist ความคืบหน้า

> เอกสารตอบการบ้านอาจารย์ (ประชุมขอบเขต ก.ค. 2026): โครงสร้างระบบ · content × ทักษะ · ตารางติ๊กความคืบหน้า + timeline
> ยึดโมเดลที่อาจารย์วาง: **หน้าแรกเลือก Content (หมวด) → ข้างในฝึกรายทักษะ (ฟัง/อ่าน/เขียน) → มีทั้ง "เรียน" และ "สอบ"**

## 1. โครงสร้างระบบ (System Structure)

```
จีนรู้ใจ (Web App / PWA — ใช้บนมือถือได้)
│
├── 👤 ผู้เรียน (Member: สมัคร/ล็อกอิน)
│   │
│   ├── 📚 ส่วนเรียน (Learn)
│   │   ├── โมดูลพื้นฐานเสียง (ก่อนเข้าหมวด) ← อาจารย์: "วรรณยุกต์สำคัญ"
│   │   │   ├── รู้จักพินอิน + วรรณยุกต์ 4 เสียง (พินอินสีวรรณยุกต์)
│   │   │   └── ฝึกหูแยกเสียง minimal pair (เสียง 2/3 · zh/ch/sh) ← จุดเด่น Thai-L1
│   │   ├── Content หมวดคำศัพท์ HSK1 (8 หมวด × ~30-50 คำ ครบ 300 คำ)
│   │   │   ├── ① คน/ครอบครัว ② ตัวเลข/เวลา/วันที่ ③ อาหาร/เครื่องดื่ม
│   │   │   ├── ④ ชีวิตประจำวัน/กริยาพื้นฐาน ⑤ สถานที่/การเดินทาง
│   │   │   ├── ⑥ โรงเรียน/การเรียน ⑦ ของใช้/สิ่งของ ⑧ คำถาม/คำช่วย/ไวยากรณ์
│   │   │   └── ในแต่ละหมวด: บัตรคำ(+เสียง+รูป) → ฝึกฟัง → ฝึกอ่าน → ฝึกเขียน(เรียงคำ)
│   │   └── ทบทวนอัจฉริยะ FSRS (ข้ามหมวด — คิว "ทวนวันนี้" 10-20 คำ/วัน ตาม pacing ที่อาจารย์แนะ)
│   │
│   ├── 📝 ส่วนสอบ (Test) ← อาจารย์: "อ้างระดับ HSK ต้องวัดจากข้อสอบเท่านั้น"
│   │   ├── Pre-test (placement ก่อนเริ่ม = baseline)
│   │   ├── ควิซท้ายหมวด (ผ่านหมวด → เก็บ % รายหมวด)
│   │   └── Mock Exam HSK1 เต็มรูป (ฟอร์แมตจริง จับเวลา สเกล 200 ผ่าน 120)
│   │
│   └── 📊 ผลการเรียน (Report)
│       ├── % ความสำเร็จราย content + รายทักษะ ← คำนวณด้วย Knowledge Tracing (pyBKT)
│       ├── "ความพร้อมสอบ HSK1 โดยประมาณ" (คะแนนเรียน + คะแนน mock)
│       └── จุดอ่อนเฉพาะคนไทย (Thai-L1) ที่วินิจฉัยได้ + แบบฝึกเจาะ
│
├── 🔧 ผู้ดูแล (Admin: ทีม 2 คน)
│   ├── จัดการบทเรียน: เพิ่ม/ลบ/แก้ คำศัพท์ · หมวด · ประโยค
│   └── จัดการแบบทดสอบ: item bank (เพิ่ม/แก้/อนุมัติข้อสอบ — ทุกข้อผ่านผู้ตรวจภาษาจีนก่อนเผยแพร่)
│
└── 🗄️ โครงเนื้อหา: HSK1 กับ HSK2 แยกชุดกัน (HSK2 = เฟสถัดไป +200 คำ)
```

**ทักษะที่ครอบคลุม (ตามที่ตกลง: เอา 3 ทักษะก่อน):** ฟัง · อ่าน · เขียน(ระดับเลือก/เรียงคำ) — พูด = future work (HSK 1–2 ไม่สอบพูด) · เขียนตัวอักษร (stroke order) = optional/challenge เป้า HSK2 (ระบบ 3.0 สอบเขียน 100 ตัว)

## 2. ตาราง Content × ทักษะ (แต่ละหมวดมีอะไร)

| ในหมวด 1 หมวด | ฟัง 🎧 | อ่าน 📖 | เขียน ✍️ |
|---|---|---|---|
| **เรียน** | ฟังเสียงคำ/ประโยค (ปรับความเร็วได้, เสียง ช/ญ) | บัตรคำ: ฮั่นจื้อ+พินอินสี+คำแปล+รูป | ดูโครงประโยค + ตัวอย่าง |
| **ฝึก** | ฟัง→เลือกคำ/รูป · ฟัง→ถูก/ผิด · minimal pair | เห็นคำ→เลือกแปล · จับคู่ · ถูก/ผิด | เรียงคำเป็นประโยค (ลาก/แตะ) · เติมคำ |
| **วัด (ควิซท้ายหมวด)** | ข้อฟังฟอร์แมต HSK (เสียง 2 รอบ) | ข้ออ่านฟอร์แมต HSK | ข้อเรียงประโยค |
| **หน่วยเนื้อหาไล่ระดับ** | วรรณยุกต์ → คำ → ประโยคสั้น | คำ → วลี → ประโยคสั้น | คำ → ประโยค |

ทุกข้อฝึก/ข้อสอบ: **ตรวจด้วย rule เทียบเฉลย (ไม่ใช้ AI เดา)** + ผูกทักษะผ่าน Q-matrix → ป้อน BKT

## 3. การวัดผล (ตอบคำถาม "วัดยังไง" ของอาจารย์)

| ชั้น | วัดอะไร | วิธี |
|---|---|---|
| ระหว่างเรียน | % ความสำเร็จราย content/ทักษะ | คะแนนควิซ + **BKT mastery** (ไม่ต้องรอสอบ — ตาม solution 1 ของอาจารย์) |
| สอบ | ระดับเทียบ HSK1 | **Mock Exam ฟอร์แมตจริง** คะแนนสเกล 200 ผ่าน 120 (ตาม solution 2 — เป็นตัวชี้ขาด) |
| โครงงาน | ผู้เรียนเก่งขึ้นจริงไหม | pre-test vs post-test (gain score) กับผู้ใช้จริงผ่านครูสอนจีน (~5 โมดูล/10 วัน) |

## 4. Tech Stack (ท่องให้คล่อง — โดนถามแน่)

> 💬 **บทท่องตอบ "เขียนภาษาอะไร":** "เขียนด้วย TypeScript ครับ ซึ่งคือ JavaScript ที่เพิ่มระบบตรวจชนิดข้อมูล ช่วยกันบั๊กตอนเขียน — ตอน build ถูกแปลงเป็น JavaScript รันในเบราว์เซอร์ ใช้ผ่านเฟรมเวิร์ก Next.js ซึ่งสร้างบน React ครับ"
> (TS = JS + type checker · สิ่งที่รันจริงคือ JS — อาจารย์เข้าใจแบบนั้นถูกแล้ว แค่เราต้องอธิบายความสัมพันธ์ให้ได้)

- **Frontend:** Next.js (React) + TypeScript + Tailwind CSS · PWA (ติดตั้งบนมือถือได้ ใช้ผ่านเบราว์เซอร์ได้)
- **Backend:** FastAPI (Python) — คำนวณ BKT posterior, endpoint จัดการข้อมูล
- **Database:** Supabase (PostgreSQL + Auth + Storage เก็บไฟล์เสียง)
- **ML/อัลกอริทึม:** pyBKT (Knowledge Tracing) · FSRS (ทบทวนเว้นช่วง) · ตรวจข้อสอบ rule-based
- **Deploy (ฟรีทั้งหมด):** Vercel (เว็บ) + Render (API) + Supabase — push แล้ว auto-deploy
- **เสียง:** edge-tts สร้างล่วงหน้า (กำลังเปลี่ยน voice ให้ชัดขึ้น)
- **Reference เนื้อหา:** HSK 3.0 (ลิสต์ทางการ CLEC พ.ย. 2025: HSK1=300 คำ, HSK2=500 สะสม) + ฟอร์แมตข้อสอบจาก sample ทางการ chinesetest.cn
