# ออกแบบ: แผนเรียน "ให้การวินิจฉัยนำทาง" (Diagnosis-Led) — ข้อเสนอเพื่อทีมตัดสิน

> ที่มา: คำถามหฤทัย 26 ก.ค. — "จุดขายคือติวเตอร์ส่วนตัวจับจุดรายคน แต่แผนตอนนี้ (บัตรคำ→ฝึก→ควิซ) มันเหมือนแอปทั่วไป" · เอกสารนี้เสนอว่าจะทำให้ "รู้สึกเป็นติวเตอร์" จริงได้ยังไง **โดยไม่แหกกรอบอาจารย์ (PA-12: ทุกคนเรียนเส้นเดียวกัน)**
> สถานะ: 🔧 ข้อเสนอ ยังไม่เคาะ — เอาไว้ทีมเลือกว่าจะดันแค่ไหน (ดูระดับ 1-2-3 ท้ายไฟล์)

---

## 1) แก่นของปัญหา และทางออก

**ทำไมแผนปัจจุบันดูเหมือนแอปทั่วไป:** เพราะเล่าเป็นเส้น "บัตรคำ → ฝึก → ควิซ → ทวน" ซึ่งเป็นลูปมาตรฐานที่ทุกแอปมี · ส่วนที่ต่าง (วินิจฉัย Thai-L1) เป็นแค่ชั้นบาง ๆ ที่แทรกตอนเฉลย ไม่ได้ขับเคลื่อนอะไร

**กุญแจ:** กฎอาจารย์ PA-12 ห้ามแค่ **"เส้นทางเนื้อหา"** (คำไหน/หมวดไหน เรียงยังไง — ต้องเหมือนกันทุกคน) · **แต่ไม่ได้ห้าม:**
- ผู้เรียนจะ**ฝึกเสริม**อะไรเพิ่ม (drill)
- คิวทวน**เน้น**อะไรก่อน
- ระบบ**โชว์**อะไรว่า "รู้จักคุณ"
- **จ่ายแบบฝึกเจาะ**ตรงจุดไหน

→ **ทางออก: เก็บ "เส้นทางเนื้อหา" ให้เหมือนกันทุกคน (ตามอาจารย์) แต่วาง "ชั้นวินิจฉัยส่วนตัว" ทับบนนั้น แล้วทำให้ชั้นนี้มองเห็นได้ + ขับเคลื่อนสิ่งที่ผู้เรียนเจอต่อ**

**ข่าวดี: นี่ไม่ใช่งานใหม่** — ชิ้นส่วนมีอยู่ใน roadmap แล้วเกือบหมด (m8-1 คลัง Thai-L1 · m8-4 วินิจฉัย+จ่าย drill · m6-4 การ์ดจุดอ่อน · m3-3 เฉลยวินิจฉัย · BK-03) แค่ตอนนี้มันเป็น "หลังบ้าน/ของแถมท้ายควิซ" · เอกสารนี้เสนอให้**ยกมันขึ้นมาเป็นสันหลังที่ผู้เรียนเห็นตลอด**

## 2) "โปรไฟล์ผู้เรียน" ที่ขับเคลื่อนทุกอย่าง

ระบบสะสม 1 สิ่งต่อผู้เรียน = **แผนที่จุดอ่อนรายคน** (ไม่ใช่แค่คะแนนรวม):

| ข้อมูล | มาจาก | ใช้ทำอะไร |
|---|---|---|
| ความแม่นราย KC Thai-L1 (วรรณยุกต์ 2/3, zh/ch/sh, ลำดับคำ ฯลฯ 15 จุด) | ทุกการตอบผิด + เกมหูโมดูล 0 (m0-4) | จัดอันดับ "จุดอ่อนของคุณ" + trigger drill |
| ความแม่นรายทักษะ (ฟัง/อ่าน/เขียน) | pyBKT (ก.ย.) · ก่อนนั้นใช้ % ควิซตรง ๆ (BK-06) | โชว์ readiness + เน้นทักษะที่อ่อน |

**เริ่มมีข้อมูลตั้งแต่โมดูล 0** — เกมฝึกหูบอกได้เลยว่าคุณสับสนคู่เสียงไหน → พอเข้าหมวด 1 ระบบ "จับตา" จุดนั้นอยู่แล้ว

## 3) เทียบทีละจุดสัมผัส: ปัจจุบัน vs วินิจฉัยนำทาง

| จุดสัมผัส | ปัจจุบัน (เหมือนทุกแอป) | **วินิจฉัยนำทาง (รู้สึกเป็นติวเตอร์)** |
|---|---|---|
| **จบโมดูล 0** | ผ่าน ~80% → เข้าหมวด 1 | + "คุณยังสับสน 十/是 (เสียง sh) — จะช่วยจับตาให้" → **เริ่มโปรไฟล์จุดอ่อนตั้งแต่วันแรก** |
| **เรียนคำใหม่ (บัตรคำ)** | เหมือนกันทุกคน | เนื้อหาเดิม แต่คำที่มีเสียงที่*คุณ*พลาด ติดป้าย "⚠️ เสียงนี้คุณมักพลาด ฟังให้ดี" |
| **ตอบผิด (หัวใจ!)** | "✗ คำตอบคือ X" | "คุณเลือก 是 แทน 十 = เสียง sh ที่คนไทยพลาด (**จุดอ่อน #3 ของคุณ**)" + ปุ่ม **"ฝึกเสียงนี้ 5 ข้อเลย"** → drill ทันที + อัปเดตโปรไฟล์ |
| **กด "เรียนต่อ" วันถัดไป** | ทวน + คำใหม่ + ควิซ (ลอจิกเดียวทุกคน) | เพิ่ม **"ซ่อมจุดอ่อน"** แทรกเมื่อ KC ตกเกณฑ์ → **2 คนหมวดเดียวกัน วันเดียวกัน เจอ drill คนละชุดตามที่ตัวเองพลาด** ← จุดที่ "รู้สึกว่ามันปรับตามเรา" |
| **ก่อนเข้าควิซ** | เข้าสอบเลย | "ก่อนสอบหมวดนี้ — จุดที่*คุณ*ยังเสี่ยง: วรรณยุกต์ 3 (แม่น 45%)" + วอร์มอัพสั้น (เลือกได้) |
| **หน้าผล / หน้าแรก** | % รวม, streak | **การ์ด "จุดอ่อนของคุณ"** เรียงอันดับ Top 3 KC + ปุ่มเจาะ → 2 คนเห็นการ์ดคนละแบบ (m6-4) |
| **ก่อนสอบจริง** | คะแนน mock | "คนไทยพลาด 15 จุด — *คุณ*เคลียร์แล้ว 13 เหลือ 2 จุดที่ยังไม่แน่น: [x][y] เจาะก่อนสอบ" (ต่อยอด MK-05) |

**สังเกต:** ทุกช่องขวา "เส้นทางเนื้อหา" ยังเหมือนกันเป๊ะ (คำ/หมวด/ลำดับเดียวกัน) — ที่ต่างคือ *สิ่งที่ระบบพูดกับคุณ* + *แบบฝึกเสริมที่จ่ายให้* + *สิ่งที่โชว์ว่ารู้จักคุณ* → **ไม่แหก PA-12**

## 4) จะดันไปแค่ไหน — เลือก 1 ใน 3 ระดับ

| ระดับ | ทำอะไร | ต้องมีอะไรก่อน | ต้นทุน | แหก PA-12 ไหม |
|---|---|---|---|---|
| **1 · โชว์เฉย ๆ** | วินิจฉัยตอนตอบผิด + การ์ด "จุดอ่อนของคุณ" + ปุ่ม "ฝึกจุดนี้" (กดเอง) · เส้นทางไม่เปลี่ยน | คลัง Thai-L1 (m8-1) + Q-matrix ผูกตัวลวง | ต่ำ — เกือบเป็น UI ทับของที่มีแล้ว | ไม่ |
| **2 · จ่าย drill อัตโนมัติ** ⭐ | + แทรก drill จุดอ่อนเข้าคิวเองเมื่อ KC ตกเกณฑ์ (BK-03) + วอร์มอัพก่อนควิซ + "จุดที่เหลือ" ก่อนสอบ | + เกณฑ์ mastery (BK-04) · ใช้ % ควิซไปก่อนได้ (BK-06) ยังไม่ต้องรอ BKT | กลาง | **ไม่** (อาจารย์อนุญาต "drill เสริมรายจุดอ่อน" ตรง ๆ ใน PA-12) |
| **3 · เปลี่ยนเส้นทางรายคน** | จัดลำดับ/ข้ามเนื้อหาต่างกันรายคน, ปรับความยากอัตโนมัติ, เส้นทาง dynamic เต็ม | เอนจินปรับเส้นทาง + ข้อมูลเยอะ | สูงมาก | **ใช่ — อาจารย์บอกชัดว่า "ยากไป เอาง่ายก่อน"** |

### ข้อเสนอ: **เล็งระดับ 2 · ส่งระดับ 1 ก่อน**
- **ระดับ 2 คือจุดหวานพอดี** — รู้สึกเป็นติวเตอร์จริง (จ่าย drill ตามที่*คุณ*พลาด) แต่ยังอยู่ในกล่อง "เส้นเดียวกัน + เสริม drill" ที่อาจารย์วาดไว้เป๊ะ (PA-12 เขียนว่า adaptive = "drill เสริมรายจุดอ่อน" — ระดับ 2 คือสิ่งนี้ตรงตัว)
- **ระดับ 3 = future work** (วิทยานิพนธ์ / เฟสถัดไป) — ตรงกับที่อาจารย์บอกว่า multi-agent/dynamic เป็นอนาคต
- **ส่งระดับ 1 ก่อน** เพราะเกือบทั้งหมดเป็น UI ทับ roadmap ที่มีอยู่ ทำได้เร็ว เห็นจุดขายทันที แล้วค่อยต่อยอดเป็น 2 เมื่อเกณฑ์ mastery/BKT พร้อม

## 5) สรุปสิ่งที่เปลี่ยน (เทียบของเดิม)

- **ไม่ใช่งานใหม่** — เป็นการ **จัดลำดับความสำคัญใหม่**: ยกชั้นวินิจฉัย (m8-1/m8-4/m6-4/m3-3) จาก "ของแถมหลังบ้าน" → "พระเอกที่เห็นทุกจุดสัมผัส"
- **แผนการเรียนเดิม (`แผนการเรียน-HSK1.md`) ยังถูกทั้งหมด** — เอกสารนี้แค่บอกว่า "ชั้นที่ทำให้เป็นติวเตอร์" ต้องแทรกตรงไหนบ้างในลูปเดิม
- **จุดขายที่ตอบกรรมการได้:** "เราไม่ได้ต่างที่กิจกรรม (บัตรคำ/ควิซ ใครก็มี) — เราต่างที่**ตอนคุณตอบผิด ระบบรู้ว่าคุณพลาดเพราะเป็นคนไทย แล้วเจาะให้ตรงจุด**"

## 6) ต้องเคาะก่อนลงมือ

1. เลือกระดับ (เสนอ 2, ส่ง 1 ก่อน) — ทีม + ปรึกษาอาจารย์
2. เกณฑ์ mastery ที่ถือว่า "จุดอ่อน" trigger drill (BK-04 — เสนอ <0.5) · ก่อน BKT ใช้ % ควิซไปก่อน (BK-06)
3. ตอนตกควิซ (QZ-05) เชื่อมกับกลไกนี้ตรง ๆ — "ฝึกข้อที่พลาด" = จ่าย drill ตาม KC ที่ผิด
4. คลัง Thai-L1 (m8-1) ต้องผ่านหฤทัยตรวจก่อน — เป็นวัตถุดิบของทุกข้อความวินิจฉัย
