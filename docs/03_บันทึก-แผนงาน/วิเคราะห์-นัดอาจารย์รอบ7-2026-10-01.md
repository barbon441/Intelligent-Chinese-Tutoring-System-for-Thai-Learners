## 0) สรุป 6 บรรทัด

1. **นัดนี้อาจารย์เลิกไล่ "ตามตาราง" แล้วไล่ "ตามหมวด → 4 ทักษะ → เนื้อหา → ข้อสอบ → ผลรายคน"** — โมเดลในหัวแกคือสายพาน 6 ชั้นที่คิดจากหน่วย "คำ" ล้วน ๆ ไม่มี BKT/FSRS อยู่ในนั้นเลย
2. **ขั้น ①–③ ดีขึ้นชัด** (users → ชุด → สารบัญ → ข้อ → sessions → attempts และแยก "ดิบ vs สรุป" ได้ดีที่สุดในคลิป) **แต่ขั้น ④ ตกที่เดิมและหนักกว่าเดิม**: ตอบว่า categories "ไว้บันทึกว่าผู้เรียนเรียนถึงหมวดไหน" (= category_progress ที่เป็นการบ้านรอบ 6 แต่ไม่ถูกเอ่ยชื่อเลยทั้งคลิป) และรับกรอบ "แต่ละหมวดมี 4 สกิล ฟัง พูด อ่าน เขียน" ด้วย "ครับ" ทั้งที่ซ้อมไว้ว่าต้องแก้
3. **คำว่า "ทักษะ" คนละชั้น**: ของอาจารย์ = ช่องทาง 4 ด้าน (ฟัง/พูด/อ่าน/เขียน) · ของเรา = หน่วยความรู้ 23 ตัวที่โมเดลติดตาม · สองชั้นไม่ขัดกัน แต่ผังเราไม่มีคอลัมน์ที่ถือชั้นของอาจารย์ชัด ๆ → แกจึงไม่เห็น และเราก็ไม่ได้อธิบาย
4. **การบ้านใหม่ 3 ชิ้นที่แกสั่งตรง ๆ**: (ก) ส่ง GitHub + ดีไซน์ DB ให้แก แกจะช่วยไล่ ("ช่วงนี้ผมว่าง") (ข) "เขียนอย่างนี้มาให้ผมดู" = ตารางหมวด 1 × 4 ทักษะ × เนื้อหา × ข้อสอบ × ผล (ค) ให้ AI เจน DB เป็น **โค้ด** (ไม่ใช่รูป) แล้วเอาโค้ดไปสร้างตารางใน Supabase เป็น migration — ข้อ (ค) เรามีแล้วครึ่งทาง (er-drawio.sql) แต่ไม่มีใครบอกแก
5. **สัญญาณเตือน**: แกพูดว่า "แกเองก็งง ฉันดูก็งง ไล่ให้แกไม่ถูก" และ "ตอนนี้มันเป็นโปรแกรมแล้ว คุณกำลังไล่หลังมัน" + "ผมไม่ได้เป็นกรรมการโปรเจกต์นี้" + อาสาช่วยทำ = แกไม่มั่นใจว่าทีมจะทันเอง จึงเปลี่ยนจากผู้ตรวจเป็นผู้ร่วมทำ — เป็นทั้งโอกาสและคำเตือน
6. **เวลา**: วันตัดสิน MVP วัดผล 5 ต.ค. ผ่านไปแล้วโดยไม่มีการตัดสิน · Supabase ยังมี 2 ตาราง · ไม่มี commit หลัง 28 ก.ย. · ตะวันถูกงานประจำอัด 12 ชม./วัน → ต้องวางฐานเวลาใหม่ตรง ๆ ไม่ปล่อยเงียบ

**แบบแผนที่เห็นทั้งคลิป ("ครับ-reflex"):** อาจารย์ถาม "งงมั้ย" 4 ครั้ง (157, 237, 243, 279) บอลไม่ขอให้ทวนสักครั้ง · รับคำถามนำที่ไม่ตรง schema ด้วย "ครับ" อย่างน้อย 5 จุด (9–17, 35–37, 61–63, 167–169, 195) · ตอบคนละคำถามแล้วถูกปัด 2 ครั้ง (41, 217) · **ไม่มีใครบอกแกเลยว่า HSK1 สอบแค่ฟัง+อ่าน** → กรอบ 4 ทักษะ + ตารางทดสอบ 4 อัน ถูกวางทั้งรอบโดยไม่มีใครแย้ง

**สิ่งที่ดีขึ้นจริง:** ขั้น ①–③ เดินเองได้ครบ · แยก "คำตอบดิบ (attempts) กับสรุป (sessions)" ชัดที่สุดในคลิป (3) · ตอบเรื่อง fix ชุด pre/post ถูกพร้อมเหตุผล (287) · ตอบสถานะพูดตรงไปตรงมา (289) · ยอมรับตรง ๆ ตอนท้ายว่าตอบไม่ได้ (395) — แต่วินิจฉัยตัวเองคลาด: ช่องว่างไม่ใช่ "เนื้อหาที่สอน" (words/sentences มีแล้ว) แต่คือ **"แบบฝึกแต่ละแบบดึงโจทย์/ตัวเลือก/เฉลยจากคอลัมน์ไหน แล้วลง attempts ช่องไหน"** ซึ่งไม่เคยซ้อม (28 ก.ย. ซ้อมแต่คีย์กับโฟลว์)

## 5) ช่องว่างใน schema ที่นัดนี้เปิดให้เห็น (ข้อเสนอ — **ยังไม่แก้ SQL** รอบอลเคาะ)

1. **ชั้น "ทักษะ 4 ด้าน" ไม่มีคอลัมน์ถือ** — ฟัง/พูด/อ่าน/เขียน กระจายใน items.module (listening/reading/vocab/grammar) · sessions.mode (listen/read/order/match) · attempts.generator (listen_mc4/read_mc4/order/speak_along) คนละชุดคำ → ถาม "คนนี้ได้กี่คำในทักษะฟัง" ต้องแปลงเองทุก query · **เสนอ:** คอลัมน์ `modality` (listen|read|write|speak) ใน items และ attempts (เติมอัตโนมัติจาก generator) + เลิกเรียก skills ว่า "ทักษะ" กับอาจารย์ (เรียก "หน่วยความรู้")
2. **pre/post นับ "ได้กี่คำ" ไม่ได้** — items ไม่ผูก words (เคาะ 28 ก.ย. ไม่ทำ item_words) แต่โมเดลแก "1 ข้อ = 1 คำ" · **เสนอ:** (ก) `items.word_id` nullable (FK เดียว ถูกกว่า M:N) หรือ (ข) ยืนตามเดิมแล้วเขียนชัดว่า pre/post รายงานรายทักษะ×หมวด ส่วน "ได้กี่คำ" มาจากช่วงเรียน — ผมแนะนำ (ข) ก่อน
3. **ข้อปั้นสดไม่เก็บตัวเลือก** — ย้อนดู "ข้อนั้นหน้าตายังไง ตัวลวงไหนล่อคนไทย" ไม่ได้ · **เสนอ:** กำหนดรูป attempts.answer = {choices:[word_id×4], picked, correct} ไม่ต้องเพิ่มตาราง
4. **พูด** ไม่มีตารางสถานะ (ค้างรอบ 6)
5. **นิยาม "อ่าน"** ยังไม่เป็นกฎ (PR-06 ข้างบน)
6. **ลำดับคำในหมวด** — words.teach_order
7. **attempts/sessions ยังไม่ live และไม่เป็น migration** — ช่องว่างใหญ่สุด = การบ้านข้อ 3 ของอาจารย์พอดี

## 7) โครงไฟล์ "ตารางแบบอาจารย์ — หมวด 1" (การบ้านข้อ 2) — ให้ตรงรูปที่แกวาดเป๊ะ

```
① หมวด C1 ทักทาย        ← categories แถวจริง: id 1 · name_th · difficulty_order 1 · word_count
② 4 ทักษะของหมวดนี้      ← ฟัง · อ่าน · เขียน(เรียงประโยค) · พูด(ถ้า go)  + บรรทัดเดียว: HSK1 สอบแค่ฟัง+อ่าน
③ ตารางเนื้อหาต่อทักษะ   ← words แถวจริง 10 คำ: hanzi | pinyin | meaning_th | audio_path | category
   + ตาราง "ทักษะ × โจทย์ × ตัวเลือก × ตัวลวงจากไหน × มีเสียงไหม × เฉลยเช็กจาก × ลง attempts ช่องไหน"
     ฟัง  : audio_path → เลือก meaning_th/hanzi 4 · ลวง = คำหมวดเดียวกัน · มีเสียง · generator=listen_mc4
     อ่าน : hanzi(+pinyin) → เลือก meaning_th 4 · ไม่มีเสียง (PR-06) · generator=read_mc4
     เขียน: sentences.tokens สับ → เรียง · เฉลย sentence_words.position · generator=order
     พูด  : audio_path+hanzi+pinyin → พูดตาม → ASR เทียบพินอิน · generator=speak_along (asr_hint ไม่ป้อนโมเดล)
④ ตารางข้อสอบ            ← items แถวจริง 3 ข้อ (ฟัง/อ่าน): stem | choices | answer_key(ตัวล็อก) | module | category
   + 3 แถว "ชุด": pre/post = 1 ชุดล็อก (exam_forms+form_items) · ควิซ = สุ่มสดจากคลังหมวด · ฝึก = ปั้นสดจากคำ
⑤ ตารางผลรายคน           ← attempts แถวจริง: user U1 | session(kind=pretest / kind=quiz,category=1) | item/word | skill_id | is_correct 1/0
   + 2 แถวตัวอย่างในตารางเดียวกัน (pre กับควิซ) ให้เห็นว่าต่างกันที่ kind กับ category
⑥ นับยังไง               ← 3 query: "100 คำได้กี่คำ" (attempts/category_progress.words_learned) · "ต้องทบทวนคำไหน" (review_states.due) · "% รายทักษะ" (mastery_snapshots)
```
ทำเป็น markdown 1–2 หน้า (เปิดบนมือถือได้) · ตะวันเติม/ตรวจคำจริง 10 คำ + ข้อ 3 ข้อ · ซ้อมเดินตามไฟล์นี้ 1 รอบก่อนนัดรอบ 8 (ไม่ต้องพกผัง 24 ตาราง)

> 1. ส่ง GitHub + ดีไซน์ DB — ขอ username GitHub ของอาจารย์ครับ จะเชิญเข้า repo (private) · ไฟล์หลัก 2 ไฟล์: `er-drawio.sql` (โค้ด CREATE TABLE 24 ตาราง — ผัง ER ทุกแผ่นสร้างจากไฟล์นี้ ไม่ได้วาดมือ) กับผัง ER แผ่นเดียวเป็นรูป · ตอนนี้ใน Supabase สร้างจริงแล้ว 2 ตาราง (words 300 คำ กับ roadmap) ที่เหลือเป็นโค้ดรอรันเป็น migration ซึ่งผมจะทำสัปดาห์นี้ตามที่อาจารย์แนะนำ
> 2. ตารางแบบที่อาจารย์วาด (หมวด 1 → ทักษะ → ตารางคำ+เสียง → ตารางข้อสอบ → ผลรายคน 1/0 → นับยังไง) — จะทำให้ครบหมวด 1 ด้วยข้อมูลจริง ส่งให้อาจารย์ดูก่อน [วันที่] แล้วค่อยนัดมาทำด้วยกันครับ
> 3. เรื่อง "สกิล" ที่ผมตอบว่า 4 ด้าน ขอแก้ให้ชัดครับ: ชั้นบนคือช่องทาง ฟัง/อ่าน (+เรียงประโยค และพูดที่อาจารย์ให้เพิ่ม — HSK1 ไม่สอบเขียน/พูด) ส่วนในฐานข้อมูลมี "หน่วยความรู้" ย่อยกว่านั้น 23 ตัวที่โมเดลใช้วัด เช่น วรรณยุกต์ 2 กับ 3 ผมจะเขียนไว้ในไฟล์ข้อ 2 ให้เห็นทั้งสองชั้นครับ
> ขอถามเพิ่ม 2 ข้อครับ: (ก) ข้อสอบ pre/post ใช้ 40 ข้อเต็มแบบ HSK1 หรือฉบับย่อ 20 ข้อดีครับ (ข) เรื่องผู้ทดสอบ 5–10 คน อาจารย์พอจะแนะนำน้องที่เป็นครูสอนจีนให้ได้ไหมครับ
