- [ ] **3.7.2** Pre-test: **~20 ข้อ** คละหมวด/ทักษะ (ง่าย-กลาง — วัด baseline ไม่ใช่คัดคนตก)
- [ ] **3.7.3** Mock Exam: ฟัง 20 + อ่าน 20 = **40 ข้อ/ชุด × 2 ชุด = 80 ข้อ** (2 ชุดกันจำข้อสอบตอน pre/post)
- [ ] **3.7.4** คำอธิบายเฉลยภาษาไทยทุกข้อ — AI ร่างล่วงหน้า → หฤทัยเกลา (ข้อที่มีตัวลวง Thai-L1 ต้องอธิบายว่า "ลวงยังไง ทำไมคนไทยพลาด")
- [ ] **3.7.5** Q-matrix: ทุกข้อผูกทักษะอย่างน้อย 1 ตัว (คำศัพท์/ไวยากรณ์ 48 จุด/จุดผิด Thai-L1)
- **ขั้นตอนมาตรฐานต่อข้อ:** AI สร้างด้วย skill `/hsk-item` → เข้า item bank สถานะ "รออนุมัติ" → 🧕 ตรวจ/แก้/อนุมัติ → ใช้งานจริง (ไม่มีข้อไหนข้ามขั้นได้)
