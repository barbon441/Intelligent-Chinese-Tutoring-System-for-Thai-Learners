# วิเคราะห์ปรึกษาอาจารย์รอบ 2 — ขอบเขต + การวัดผล (23 ก.ค. 2026)

> ต้นฉบับ: `คลิปเสียง2.txt` (บันทึกประชุมรอบก่อนย้ายไปอยู่ `คลิปเสียง1.txt`) · วิเคราะห์ 3 ชั้น: สกัดคำสั่งจาก transcript จริง + เทียบกับสถานะทีม + ตรวจสอบสรุป NotebookLM

## TL;DR

1. อาจารย์ยืนยันทิศทางเรา **ถูกแล้วเป็นส่วนใหญ่** (ตัวเลข HSK, ลำดับงาน, การบ้านเก่าเราทำล่วงหน้าไปแล้วหลายข้อ)
2. จุดชนใหญ่สุด: **เสนอยุบ 8 หมวด → ~5 หมวด** (พูดย้ำหลายรอบ) — มีทางออกที่ไม่ทิ้งงานตะวัน
3. การวัดผลต้องเป็น **pre-test → เรียน → post-test** และ **pre-test ห้ามเฉลย** (คำสั่งชัด ×2)
4. อาจารย์ชี้ฟีเจอร์ใหม่ที่มองเป็นไฮไลต์: **"แผนประมาณการเวลาเรียนจากคะแนนจริง"** ("จะเป็นคลาสสิคของคุณ")
5. NotebookLM สรุปเพี้ยน 3 จุด — สำคัญสุด: **อาจารย์ไม่ได้สั่งวัดทักษะพูด** (ขอบเขตเรายืนได้)

## ⚠️ จุดชนกับสิ่งที่ทีมทำอยู่ — 7 เรื่อง พร้อมข้อเสนอ

### T1 · 5 หมวด vs 8 หมวด (ชนแรงสุด — กระทบงานตรวจของตะวันที่กำลังเดิน)
- **ข้อเสนอทีม: โครง 2 ชั้น "5 กลุ่มใหญ่ × 8 หมวดย่อย"** — UI หน้าเลือกหมวด + สัดส่วนข้อสอบรายงานที่ระดับ 5 กลุ่ม · เนื้อหา/การตรวจ 42 คำ/ควิซ คงระดับ 8 หมวดย่อยเดิม (แค่เพิ่ม field `group` ในข้อมูล)
- ทำไมท่านี้ชนะ: งานตรวจของตะวัน**ไม่เสียแม้แต่คำเดียว** (การยุบ = จับหมวดควบทั้งก้อน คำไม่ย้ายหมวด) · ตอบโจทย์อาจารย์ทั้ง 2 ข้อ (ผู้เรียนเห็น 5 ไม่ล้า + ข้อสอบแบ่งสัดส่วนจาก 5 กลุ่มลงตัว) · ถ้าอาจารย์ยืนยัน 5 จริง ๆ ก็ยุบสนิทได้ทีหลังโดยไม่รื้อ
- ร่างการจับกลุ่ม (ให้ตะวันเคาะ): ①ทักทาย+ครอบครัว ②ตัวเลข/เวลา ③อาหาร+ซื้อของ ④เรียน/ทำงาน ⑤เดินทาง+ชีวิตประจำวัน

### T2 · Pre-test บังคับทุกคน? (ชนมติ "พื้นศูนย์ข้ามสอบ")
- อาจารย์พูดเหมือนเป็น flow มาตรฐานของทุกคน แต่ไม่ได้เจาะจงว่ารวมคนพื้นศูนย์ — **ต้องถามยืนยันวันจันทร์** (ต้นทุนศูนย์)
- แผนสำรองถ้าท่านเอาทุกคน: **micro pre-test สำหรับพื้นศูนย์** — 5-10 ข้อแบบ "ฟังเสียง+เลือกรูป" ไม่ต้องอ่านตัวจีนเลย → ได้ baseline โดยไม่ฝืนหลัก UX เดิม (PL-01)

### T3 · Pre = Post ข้อสอบชุดเดียวกัน (เราออกแบบ 2 ชุด)
- **ข้อเสนอ: ตามอาจารย์ — ชุดเดียว + กฎห้ามเฉลย** → งานเขียนข้อสอบ mock ของตะวัน**ลดลงครึ่งหนึ่ง** (80 → 40 ข้อ) ซึ่งเป็นก้อนงานเนื้อหาที่ใหญ่ที่สุด · ผู้เรียนไม่เคยเห็นเฉลย = จำข้อได้ยากอยู่แล้ว
- ชุดที่ 2 เลื่อนเป็น optional (ถ้ามีเวลา ค่อยทำเป็น "mock ฝึกซ้อม" แยกจาก pre/post)

### T4 · "ทุกคนเรียนเหมือนกัน ไม่ต้อง adaptive" vs แกน BKT ของเรา
- สิ่งที่อาจารย์ว่า "ยาก" คือ dynamic content (รื้อบทเรียนรายคน) — **ซึ่งเราไม่ได้ทำอยู่แล้ว**
- Adaptive ของเรา = เส้นเรียนหลักเดียวกันทุกคน + **drill เสริมรายจุดอ่อน** (BKT ชี้ KC ต่ำ → แทรกแบบฝึกเจาะ) — เข้ากับกรอบ "ง่าย ๆ" ของอาจารย์พอดี ไม่ต้องตัดอะไร
- **ท่านำเสนอวันจันทร์:** "ทุกคนเรียนเส้นเดียวกันตามที่อาจารย์แนะครับ ระบบแค่*เสริม*แบบฝึกตรงจุดที่แต่ละคนพลาดบ่อย" — รักษาจุดขาย pyBKT+Thai-L1 ไว้เต็ม ๆ

### T5 · อาจารย์รู้สึกว่า "งานยังไม่เริ่ม" (perception gap)
- ความจริง: บัตรคำ+เสียง / FSRS / ฝึก 3 โหมด / deploy 3 ชั้น เสร็จแล้ว — แต่อาจารย์ยังไม่เห็นของจริง
- **แก้:** จันทร์นี้เปิดแอปจริงบนมือถือ + หน้า /roadmap โชว์สด (ปลุก Render ก่อนเข้าห้อง) + พก one-pager "กรอบการสอน-การประเมิน" 1 หน้า

### T6 · Onboarding 4 คำถามถูกตั้งคำถาม
- ไม่ต้องถอด (อาจารย์บอก "ไม่ซีเรียส") แต่เพิ่มชั้นที่อาจารย์อยากเห็น: **แผนประมาณการจากคะแนนจริง** (ดู m6-5 ใหม่) — ระวังอย่านำเสนอ onboarding เป็นจุดขายหลัก ให้เสนอแผนประมาณการแทน

### T7 · ขอบเขต HSK2 ยังไม่มีเป็นลายลักษณ์อักษร
- เพิ่มครึ่งหน้าใน `ออกแบบทักษะ-ฟัง-อ่าน-เขียน.md`: +200 คำ (โครงหมวดเดิม) · เพิ่มพาร์ตเขียน 书写 ~10 ข้อ (ลิสต์ 100 อักษร) · ฟัง/อ่านยาวขึ้น-เร็วขึ้น · ฟังก์ชันใหม่ที่ต้องเพิ่ม 2 ตัว (จำลอง书写 + อ่านข้อความสั้น)

## 🔍 ผลตรวจสรุป NotebookLM (12 ข้อ)

- **ตรง 9 ข้อ** — ใช้ได้
- **เพี้ยน 3 ข้อ:** ① *"เก็บคะแนน (ฟัง พูด อ่าน เขียน)"* — คำว่า "พูด" อยู่ในวลีเหมารวมครั้งเดียว ("...หรืออะไรของคุณอ่ะ") **ไม่ใช่คำสั่งวัดทักษะพูด** และตอนทีมอธิบายว่า HSK1-2 ไม่สอบพูด อาจารย์รับโดยไม่แย้ง → ขอบเขต 3 ทักษะยืนเดิม · ② *"ระบบปรับสัดส่วนตามจุดอ่อนจะน่าสนใจมาก"* — จริง ๆ อาจารย์เปรยแล้วตบเองว่า "ยากไป เอาง่ายก่อน" · ③ *"ระบุเครื่องมือเทคนิคให้คม"* — ไม่มีในไฟล์ ของจริงคือ "ทำ**กรอบ**เนื้อหา-การสอน-การประเมินให้**ชัด**"
