# 🇨🇳 น้องยิน — ติวเตอร์ภาษาจีนที่รู้ใจ (แผนทิศทางใหม่)

> **ไฟล์นี้คืออะไร:** สรุปทุกอย่างที่เราคุยกับอาจารย์เมื่อ **28 มิ.ย. 2026** ตอนที่ตัดสินใจหันโปรเจกต์ "น้องยิน" มาทาง *ผู้ช่วยเรียนภาษาจีน*
> **สำคัญมาก:** ไฟล์นี้ **ไม่ได้ลบหรือเขียนทับ** แผนเดิม (น้องยินผู้ช่วยส่วนตัวบน LINE) — แผนเดิมยังอยู่ครบในโฟลเดอร์นี้ ไฟล์นี้คือ "ทิศทางใหม่" ที่เก็บไว้คู่กัน เผื่อเปิดมาอ่านทีหลังว่า *ทำไม* ถึงเลือกแบบนี้
> **สถานะ:** ยังเป็นขั้น *ออกแบบ/ตัดสินใจ* ยังไม่เริ่มเขียนโค้ด · ยังมีบางข้อต้องเคลียร์กับบอล (ดูข้อ 9)

## 0. สรุปใน 30 วินาที (TL;DR)

**น้องยิน = ติวเตอร์ภาษาจีนที่จำเราได้ รู้ว่าเรายังไม่แม่นตรงไหน แล้วปรับการสอนให้เราโดยเฉพาะ**

เราเอา *หัวใจของน้องยิน* (AI ที่จำเรา + เรียนรู้ตัวตนเรา) มารวมกับ*ความถนัดภาษาจีน*ของเรา
→ เริ่มจากทำให้ช่วย **คนคนเดียวได้จริงก่อน** (บอล — เพื่อนร่วมทีมที่เพิ่งเริ่มเรียนจีน) แล้วค่อยขยายไปคนอื่น
→ จุดที่ทำให้คน *อยากกลับมาใช้ตลอด* คือ "มันรู้จักเรา" ไม่ใช่ "มีฟีเจอร์เยอะ"

---

## 1. เรามาถึงตรงนี้ได้ยังไง (เส้นทางความคิด)

1. เดิมเราทำ **น้องยิน = ผู้ช่วยส่วนตัวบน LINE** (จำเรา + เตือน + File Vault)
2. ไปปรึกษาพี่ ๆ หลายคน → ตกตะกอนว่าอยากใช้ **ความถนัดภาษาจีน** ของตัวเอง
3. คุยกับอาจารย์ → พบว่าไม่ต้องทิ้งน้องยิน เพราะ **"หัวใจ" ของน้องยิน (จำเรา + เรียนรู้เรา) เอามาใช้กับการเรียนภาษาจีนได้พอดีเป๊ะ**
4. ได้ข้อสรุป: **รวม "หัวใจ" ไม่ใช่รวม "หน้าจอ"** — ไม่ใช่เอาของสองอย่างมากองรวมกัน แต่ถักทอเป็นสิ่งเดียว

> 💡 **บทเรียนที่อาจารย์ย้ำ:** ครูสอนภาษาที่เก่งที่สุด ไม่ใช่เพราะมีข้อสอบเยอะที่สุด แต่เพราะ *เขาจำเราได้* — จำว่าเราลืมคำไหนบ่อย ติดตรงไหน วันนี้ควรทวนอะไร นี่คือสิ่งที่ AI ที่ "จำเราได้" ทำได้ แต่กองข้อสอบเปล่า ๆ ทำไม่ได้

## 2. หัวใจของโปรเจกต์ (แกนเดียวที่ให้ทุกอย่าง)

> ### ⭐ "ติวเตอร์ภาษาจีนที่รู้ว่า *เรา* ยังไม่แม่นตรงไหน แล้วปรับให้เราโดยเฉพาะ"

แกนประโยคเดียวนี้ ตอบโจทย์ทุกอย่างที่เราต้องการในคราวเดียว:

| สิ่งที่เราต้องการ | แกนนี้ให้ได้ยังไง |
|---|---|
| 💝 หัวใจของน้องยิน | คือ "ระบบจำ + เรียนรู้ผู้ใช้" เดิม ที่แปลงร่างมาเป็น "ตัวจำว่าผู้เรียนอ่อนคำไหน" |
| 🎓 แก่นวิชาการ (กรรมการอยากเห็น) | ไม่ใช่แค่แอป แต่เป็น *ระบบที่เรียนรู้ตัวผู้เรียนแล้วปรับตัว* (ดูข้อ 7) |
| 🧲 แม่เหล็กดึงคนกลับมา | เพราะมัน "รู้จักเรา" ที่อื่นเปิดมาเริ่มนับหนึ่งใหม่ทุกครั้ง แต่น้องยินจำได้ว่าเราถึงไหน |
| 🇨🇳 ใช้จุดแข็งของเรา | ใช้ความเชี่ยวชาญภาษาจีนของเราเต็มที่ |

## 3. ทำเพื่อใคร (กลุ่มเป้าหมาย)

- **เริ่มจากคนเดียวก่อน → บอล** (เพื่อนร่วมทีม ที่เพิ่งเริ่มเรียนจีนและอยากเก่งขึ้น)
  - บอลคือ "ผู้ใช้จริงคนแรก" ที่นั่งอยู่ข้างเรา → เป็นกระจกสะท้อนว่าอะไรช่วยได้จริง
  - เราเก่งจีนแล้วอาจลืมว่าตอนมือใหม่งงตรงไหน แต่บอลกำลังเจ็บกับมันจริง ๆ
- **ต่อไป → คนที่อยากเรียนภาษาจีน** (โดยเฉพาะคนเตรียมสอบ HSK / มือใหม่ที่กลัวเริ่ม)
- **อนาคตไกล → ภาษาที่ 2, 3 อื่น ๆ** — แต่ **ลึกก่อน แล้วค่อยกว้าง**

> 🎯 **เป้าหมายที่จับต้องได้:** "ทำให้น้องยินช่วยบอลเรียนจีนเก่งขึ้นจริง ๆ ให้ได้ก่อน" — ถ้าช่วยบอลได้ ก็ช่วยคนอีกเป็นพันที่เหมือนบอลได้

## 4. น้องยินทำอะไรได้บ้าง (ห้องต่าง ๆ ในบ้าน)

น้องยินคือ **"เจ้าบ้าน" ที่จำเราได้** แล้วพาเราไปห้องที่ใช่ (ไม่ใช่เมนูเย็น ๆ ที่ต้องเลือกเองทุกอย่าง)
เรียงตามความสำคัญ — ดาว ⭐ = หัวใจที่ควรทำก่อน

| ห้อง / ฟีเจอร์ | ระดับ | ทำอะไร |
|---|---|---|
| 📊 **วัดความคืบหน้าแบบมีหัวใจ** | ⭐ หัวใจ | ดูข้อ 4.1 |
| 🎯 **"จะออกคำไหน" — คำสำคัญที่เรายังไม่แม่น** | ⭐ หัวใจ | ดูข้อ 4.2 |
| 🧠 **คลังคำศัพท์ HSK + ทวนแบบรู้ใจ** | ⭐ MVP | จำว่าเราอ่อนคำไหน เอากลับมาทวน *ก่อน*จะลืมพอดีจังหวะ |
| 🗣️ **ห้องฝึกออกเสียง (วรรณยุกต์)** | 🟡 เฟสถัดไป | ที่ปลอดภัยให้ลองพูด ผิดได้ ไม่มีใครว่า + จำว่าเราติดเสียงไหนบ่อย |
| 🎵 **เรียนจากเพลง / การ์ตูน** | 🟡 เฟสถัดไป | ห่อคำด้วย *อารมณ์ + เรื่องราว* → จำง่ายกว่าท่อง |
| 📝 **มุมจดบันทึกการเรียน (กลิ่น Notion)** | 🔵 ลูกเล่นเสริม | ที่จดคำที่อยากจำของตัวเอง — *แต้มเล็ก ๆ ไม่ใช่สร้างทั้ง Notion* |
| 👥 **เห็นเพื่อนร่วมทาง (กลิ่น Facebook)** | 🔵 ลูกเล่นเสริม | รู้สึกว่ามีคนสู้อยู่ด้วยกัน — *แต้มเล็ก ๆ ไม่ใช่สร้างทั้ง Facebook* |

### 4.1 📊 วัดความคืบหน้าแบบมีหัวใจ (ห้องหัวใจ)

ตัววัดความคืบหน้าธรรมดา = วัด "เหลืออีกไกลแค่ไหนกว่าจะถึงเป้า" → เหนื่อย
ของเรา = วัด **"เรามาไกลแค่ไหนแล้วจากจุดเริ่ม"** → ภูมิใจ

ถักรวมสามมุมเป็น *เสียงเดียว* ของน้องยิน (ไม่ใช่สามกราฟวางเรียงกัน):
- **เจอตัวเราในอดีต** — "คำนี้เมื่อก่อนเธอลืมสามรอบ ตอนนี้ตอบปุ๊บเลย"
- **ผูกกับชีวิตจริง** — "ตอนนี้เธออ่านเมนูร้านจีนรู้เรื่องแล้วนะ / เพลงนี้ฟังออกครึ่งเพลงแล้ว"
- **ชัยชนะเล็ก ๆ ที่เรามองไม่เห็นเอง** — "วันนี้เธอลังเลน้อยลง ตอบเร็วขึ้น"

> ตัวอย่างเสียงน้องยินที่รวมทั้งสามมุม:
> *"จำได้ไหม เดือนมีนาเธอเขียน 朋友 ผิดหลายรอบ — วันนี้ใช้คำนี้คล่องเลย อาทิตย์นี้ลังเลน้อยลงเยอะ อีกนิดเดียวเธอจะอ่านการ์ตูนเล่มที่อยากอ่านได้แล้ว"*

### 4.2 🎯 "จะออกคำไหน" — คำสำคัญที่เรายังไม่แม่น

แรงบันดาลใจจากคลิปที่เห็น (เครื่องมือวิเคราะห์ข้อสอบ HSK จริง):
- เอา **ข้อสอบจริงหลายชุด** มานับว่าคำไหนออกบ่อย → เรียงให้ว่าควรท่องคำไหนก่อน
- แตะที่คำ → เห็น **ประโยคจริงจากข้อสอบ** ว่าคำนี้ใช้ยังไง
- กรองตามระดับ HSK1–6

**จุดที่น้องยินเหนือกว่าเครื่องมือในคลิป:** เครื่องมือนั้นให้คำตอบเดียวกันกับทุกคน
แต่น้องยิน *จำเราได้* → บอกได้ว่า **"คำไหนออกบ่อย *และ* เธอยังไม่แม่น"**
> เครื่องมือทั่วไป: "20 คำนี้ออกบ่อยสุด"
> น้องยิน: "จาก 20 คำนั้น เธอแม่นไปแล้ว 14 เหลือ 6 คำที่ยังพลาด มาตะลุยตรงนี้กันก่อน"

## 5. ขอบเขต — สิ่งที่เราจะ "ยังไม่ทำ" (กฎกันบ้านรก ⚠️)

เรามีกัน **2 คน เวลา 4 เดือน** — ของพวกนี้แต่ละอย่างคือ "บ้านทั้งหลัง" ที่บริษัทใหญ่ใช้คนเป็นร้อยสร้างหลายปี:

- ❌ **ไม่สร้าง Facebook ทั้งระบบ** — เอาแค่ "กลิ่น" ความรู้สึกมีเพื่อนร่วมทาง
- ❌ **ไม่สร้าง Notion ทั้งระบบ** — เอาแค่ "กลิ่น" มุมจดบันทึกเล็ก ๆ
- ❌ **ไม่ทำทุกภาษาพร้อมกัน** — โฟกัส **จีนก่อน** (จุดแข็งเรา) ภาษาอื่นค่อยต่อยอด
- ✅ **กฎทอง:** *ฝันให้กว้าง แต่สร้างทีละห้อง* + *ทำให้ใช้ได้จริงกับคนเดียว (บอล) ก่อน*

## 6. แบ่งงาน 2 คน (โครงเดิม "จิตวิญญาณ vs ร่างกาย" ยังใช้ได้)

| คน | รับผิดชอบ | บทบาท |
|---|---|---|
| **เรา (สมอง + จิตวิญญาณ)** | เนื้อหาภาษาจีน · ออกแบบว่าจะสอนยังไง · ตรรกะ "รู้ว่าผู้เรียนอ่อนตรงไหน" · บุคลิกน้องยิน | คนกำหนดหัวใจ |
| **บอล (ร่างกาย + เครื่องยนต์)** | ① เครื่องวิเคราะห์ข้อสอบ/นับความถี่ ② ระบบตัดสินใจ "ทวนคำไหนเมื่อไหร่" ③ หลังบ้าน/ฐานข้อมูล/แอป **+ เป็นผู้ใช้จริงคนแรกที่คอยทดสอบ** | คนทำให้มันมีชีวิต |

> 💡 บอลเพิ่งเรียนจีนเริ่มต้น + อยากพัฒนาภาษาตัวเอง → เขาจึงมี **สองบทบาท**: ทั้งวิศวกรที่สร้างเครื่องยนต์ และผู้เรียนตัวจริงที่ลองขับมันเอง
> ตอน defense บอลเล่าได้เต็มปาก: *"ผมสร้างส่วนนี้ และผมคือคนแรกที่พิสูจน์ว่ามันช่วยผมเรียนจีนได้จริง"*

## 7. แก่นวิชาการ — ยังต้องทำให้คมขึ้น (ข้อที่ต้องคิดต่อ)

เพื่อให้เป็น "โปรเจกต์จบ" ไม่ใช่ "แค่แอป" — แก่นวิชาการคือ:
> **ระบบที่เรียนรู้ว่าผู้เรียนแต่ละคนอ่อนตรงไหน แล้วปรับเนื้อหา/จังหวะการทวนให้เฉพาะคน (learner model / personalization)**

- ต่อยอดจาก **Memory Engine** ในแผนเดิม (สกัดข้อเท็จจริง → โปรไฟล์ผู้ใช้ → ความจำจางแบบมนุษย์)
- ต้องมี **การวัดผล** (เช่น ผู้เรียนจำคำได้ดีขึ้นจริงไหม เทียบมี/ไม่มีระบบปรับให้เฉพาะคน)
- 🔧 **ยังต้องนิยามให้ชัดขึ้น** ว่าจะวัดอะไร อย่างไร — เก็บไว้คุยกับอาจารย์ต่อ

## 8. ความเชื่อมโยงกับแผนเดิม

- แผนเดิม (น้องยินบน LINE + File Vault + Memory Engine) **ไม่ถูกลบ** ยังอยู่ในไฟล์ `แผนโปรเจกต์-น้องยิน-ฉบับรวม.md` ฯลฯ
- **สะพานเชื่อม** = ระบบ "จำเรา + เรียนรู้ตัวตนเรา" อันเดียวกัน เปลี่ยนแค่ "ใช้เพื่ออะไร" (จากผู้ช่วยชีวิต → ติวเตอร์ภาษา)
- ของบางอย่างจากแผนเดิมหยิบมาใช้ซ้ำได้ (แนวคิด memory, การวัดผล, ฯลฯ) — ค่อยพิจารณาตอนสร้างจริง

## 9. ก้าวต่อไป (เบา ๆ ไม่ต้องรีบ)
