# สไลด์ 2 — Proposed Solution

**หัวเรื่อง:** Proposed Solution
**หัวเรื่องรอง (ตัวเล็กข้างหัวเรื่อง):** โมดูลหลัก 8 ตัว สำหรับระบบติวเตอร์เตรียมสอบ HSK

> วาง 8 กล่อง 2 คอลัมน์ × 4 แถว · แต่ละกล่อง = ไอคอน + ชื่อ EN (แดง) + คำอธิบายไทย + 4 บูลเล็ต (แบ่ง 2 คอลัมน์ย่อย)

### กล่อง 1 · VOCABULARY & FLASHCARD
คลังคำศัพท์ + บัตรคำ
- บัตรคำ HSK 1 ครบ 300 คำ
- ตัวจีน + พินอินสี + คำแปลไทย + เสียง
- เรียนตามหมวด 5 หมวด
- ใช้ได้ครบทุกฟังก์ชันแม้ไม่มีเน็ต

### กล่อง 2 · LEARNER MODEL (pyBKT)
แบบจำลองผู้เรียนรายทักษะ
- บันทึกทุกการตอบเป็นข้อมูลเรียนรู้
- Q-matrix จับคู่ข้อสอบ ↔ ทักษะ
- คำนวณความแม่นรายทักษะ (mastery)
- วัดผลด้วย AUC + ablation

### กล่อง 3 · THAI-L1 DIAGNOSIS
วินิจฉัยจุดผิดเฉพาะคนไทย
- คลังจุดผิดคนไทย 15 จุด มีงานวิจัยรองรับ
- ตัวลวงข้อสอบสะท้อนจุดผิดจริง
- บอก "ผิดเพราะอะไร" เป็นภาษาไทย
- จ่ายแบบฝึกเจาะจุดอัตโนมัติ

### กล่อง 4 · SPACED REPETITION (FSRS)
ทบทวนเว้นช่วงอัจฉริยะ
- คิว "ทวนวันนี้" ตามจังหวะลืม
- ให้คะแนนความจำ 4 ระดับ
- ทวนออฟไลน์ได้ + sync อัตโนมัติ
- เทียบ retention กับวิธีเดิม (baseline)

### กล่อง 5 · LISTENING PRACTICE
ฝึกการฟัง
- ข้อฟังรูปแบบ HSK จริง (เสียงล้วน)
- ฝึกหูคู่เสียงยาก 2/3 · zh/ch/sh
- ฟังบทสนทนาสั้น → ตอบคำถาม
- ปรับความเร็วเสียงเฉพาะโหมดฝึก

### กล่อง 6 · READING PRACTICE
ฝึกการอ่าน
- เลือกความหมาย / พินอิน / จับคู่
- เรียงคำเป็นประโยค + โน้ตไวยากรณ์
- คุมระดับคำอัตโนมัติด้วย jieba
- ตรวจด้วยเฉลยตายตัว ไม่ใช้ AI ตัดสิน

### กล่อง 7 · MOCK EXAM & QUIZ
สอบจำลอง + ควิซท้ายหมวด
- ควิซ 10 ข้อ/หมวด ผ่าน ≥ 7/10
- Mock เต็มชุด ฟัง 20 + อ่าน 20 จับเวลา
- คิดคะแนนสเกล 200 ผ่าน 120 (เกณฑ์จริง)
- ใช้เป็น pre/post วัดพัฒนาการ

### กล่อง 8 · PROGRESS DASHBOARD
ผลการเรียน + ความพร้อมสอบ
- กราฟความแม่นรายทักษะ
- จุดอ่อน Thai-L1 ล่าสุด + ปุ่มเจาะฝึก
- ความพร้อมสอบเทียบเกณฑ์ 120/200
- ประวัติการฝึก + streak

## สไลด์ 4 — ภาพรวมโมดูล

**หัวเรื่อง:** VOCABULARY & FLASHCARD (PWA)

### Platform Types
- Next.js PWA — ติดตั้งบนมือถือได้ ไม่ต้องโหลดจาก App Store
- ใช้งานได้เต็มรูปแบบแม้ไม่มีเน็ต (หลังเปิดครั้งแรก)

### User Permissions
- ผู้เรียน (Member) — เรียน / ฟังเสียง / ดูคืบหน้าของตัวเอง
- แอดมิน — เพิ่ม-แก้-ลบคำศัพท์ หมวด และประโยคตัวอย่าง
- ผู้อนุมัติเนื้อหา (หฤทัย) — ยืนยันคำแปล/พินอิน (ธง th_reviewed)

### User Capabilities (กล่องซ้าย)
- เรียนศัพท์ HSK 1 ครบ 300 คำ (ต่อยอด HSK 2 รวม 500 คำ)
- เห็นตัวจีน + พินอินสีตามวรรณยุกต์ + คำแปลไทยที่ตรวจแล้ว
- กดฟังเสียงอ่านได้ทุกคำ แม้อยู่ในโหมดเครื่องบิน
- เลือกเรียนจาก 5 หมวด พร้อมเห็น % ความคืบหน้าแต่ละหมวด
- ซ่อน/โชว์พินอิน เมื่อพร้อมอ่านตัวจีนล้วน
- ดูประโยคตัวอย่าง 5–10 ประโยคต่อหมวด (ใช้เฉพาะคำที่เรียนแล้ว)
- ดูรูปประกอบคำรูปธรรม + ลำดับขีดการเขียน
- ตั้งเป้าจำนวนคำต่อวันเอง (5 / 10 / 15 / 20 คำ)

### Core Functions (กล่องขวา — เรียงบนลงล่าง)
**HSK 3.0 Word List Import**
นำเข้าคำจากลิสต์มาตรฐาน 3.0 · HSK1 = 300 คำ / HSK2 = 500 คำสะสม + version-stamp

**Thai Meaning Pipeline**
จีน + อังกฤษ (CC-CEDICT) → แปลไทยทีเดียว → ผ่านการตรวจครบ 300/300 คำ

**Pre-generated Audio (edge-tts)**
สร้างไฟล์เสียงล่วงหน้าเป็นชุด + cache ในเครื่อง ไม่เรียก TTS สดตอนผู้ใช้กด

**5-Category Learning Path**
จัดคำลง 5 หมวดตามสถานการณ์ใช้จริง + การ์ดหมวดพร้อมแถบคืบหน้า

**Offline Flashcard Engine**
Serwist (Service Worker) + Dexie/IndexedDB — เปิดบัตรคำและเล่นเสียงได้ไม่ต้องมีเน็ต

**Pinyin & Stroke Display**
pypinyin ระบายสีวรรณยุกต์ + hanzi-writer แสดงลำดับขีด + ปุ่มซ่อนพินอิน

**Daily Learning Goal**
คำนวณแผนรายวันจากคำตอบตอนสมัคร (ไม่ตอบ = 10 คำ/วัน) แก้ได้ตลอดในโปรไฟล์

### NOTIFICATION (แถบล่าง — ในแอป)
- แจ้งเป้าหมายวันนี้ + แถบคืบหน้า "วันนี้ 10 / 20 คำ"
- การ์ดเตือนบนหน้าแรก "มี X คำรอทวน"
- ข้อความกำลังใจโทนเพื่อนติว (กลับมาเมื่อไหร่ก็ต้อนรับ ไม่ตำหนิ)
- แจ้งเมื่อเรียนครบหมวด → ชวนทำควิซท้ายหมวด

## สไลด์ 5 — Function (1/2)

**หัวเรื่อง:** Function
**หัวเรื่องย่อย:** VOCABULARY & FLASHCARD (B2C)
**คำโปรย:** เรียนศัพท์ HSK ทีละคำ ครบทั้งตัวอักษร เสียง ความหมาย และลำดับขีด — ใช้งานได้แม้ไม่มีสัญญาณ

### คอลัมน์ 1 — Word Card
บัตรคำศัพท์
- ตัวจีน + พินอิน + คำแปลไทย ในการ์ดเดียว
- พินอินระบายสีตามวรรณยุกต์ 4 เสียง
- ปุ่มฟังเสียงเจ้าของภาษา
- พลิกการ์ด = เริ่มนับว่า "เรียนแล้ว"
- ปุ่มซ่อน/โชว์พินอิน ฝึกอ่านตัวจีนล้วน

### คอลัมน์ 2 — Category Path
เส้นทางเรียน 5 หมวด
- หน้าเลือกหมวดแบบการ์ด 5 ใบ
- แถบ % คืบหน้าของแต่ละหมวด
- แนะนำลำดับหมวด แต่ไม่ล็อกทางเดิน
- เมนูหมวด: เรียน / ฝึก / ควิซ ในที่เดียว
- กลับมาเรียนต่อจุดที่ค้างได้ทันที

### คอลัมน์ 3 — Audio & Pronunciation
เสียงอ่านและการออกเสียง
- ไฟล์เสียงสร้างล่วงหน้าทุกคำ (edge-tts)
- cache ในเครื่อง → เล่นได้ออฟไลน์
- เสียงชาย/หญิงให้เลือกฟัง
- ปรับความเร็ว 0.75x–1x เฉพาะโหมดฝึก
- เสียงทุกไฟล์ผ่านการตรวจก่อนใช้จริง

### คอลัมน์ 4 — Offline Mode
โหมดออฟไลน์
- โหลดครั้งแรกครั้งเดียว ใช้ได้ทั้งชุด
- เก็บการ์ด/คิวทวน/คำตอบไว้ในเครื่อง
- ตอบค้างไว้ → ส่งขึ้นระบบอัตโนมัติเมื่อมีเน็ต
- ส่งซ้ำไม่ทำให้ข้อมูลซ้ำ (idempotent)
- หน้า fallback เฉพาะเมื่อออฟไลน์

## สไลด์ 6 — Function (2/2)

**หัวเรื่อง:** Function
**หัวเรื่องย่อย:** VOCABULARY & FLASHCARD (B2C)
**คำโปรย:** ต่อยอดจากบัตรคำสู่การใช้งานจริง — ประโยคตัวอย่าง ลำดับขีด เป้าหมายรายวัน และคลังคำที่ดูแลโดยทีมเนื้อหา

### คอลัมน์ 1 — Example Sentences
ประโยคตัวอย่าง
- 5–10 ประโยคต่อหมวด พร้อมเสียง
- ใช้เฉพาะคำที่ผู้เรียนเรียนถึงแล้ว
- ตรวจระดับคำอัตโนมัติด้วย jieba
- คำแปลไทยกำกับทุกประโยค
- ผ่านการตรวจจากผู้เชี่ยวชาญก่อนขึ้นระบบ

### คอลัมน์ 2 — Stroke & Image
ลำดับขีด + รูปประกอบ
- แสดงลำดับขีดด้วย hanzi-writer
- เล่นซ้ำ/หยุดดูทีละขีดได้
- รูปประกอบคำรูปธรรม ~150–200 คำ
- ใช้สื่อฟรี/ลิขสิทธิ์เปิดเท่านั้น
- ไม่คิดคะแนน — เป็นตัวช่วยจำ

### คอลัมน์ 3 — Daily Goal
เป้าหมายรายวัน
- เลือกเอง 5 / 10 / 15 / 20 คำต่อวัน
- โชว์ผลลัพธ์สดตอนเลือก "ครบ 300 คำใน ~30 วัน"
- เกิน 20 คำ/วัน = เตือนแต่ไม่ห้าม
- แถบคืบหน้าประจำวันบนหน้าแรก
- แก้เป้าหมายย้อนหลังได้ตลอดในโปรไฟล์

### คอลัมน์ 4 — Word Bank Admin
คลังคำหลังบ้าน
- ตารางคำ 300 คำ ค้นหา/กรองตามหมวด
- เพิ่ม-แก้ คำแปล พินอิน หมวด
- แก้แล้วติดธง "รอตรวจ" ขึ้นคิวผู้อนุมัติ
- ลบต้องยืนยันเสมอ + เตือนถ้ามีข้อสอบอ้างอยู่
- แก้ประโยค → สั่งสร้างเสียงใหม่อัตโนมัติ

## สไลด์ 9 — ภาพรวมโมดูล

**หัวเรื่อง:** LEARNER MODEL (pyBKT ENGINE)

### Platform Types
- FastAPI Engine — โฮสต์บน Hugging Face Spaces (Docker)
- แสดงผลผ่าน PWA · เทรนโมเดลแบบ offline/batch แยกจากระบบที่ผู้ใช้เรียก

### User Permissions
- ผู้เรียน — เห็นความแม่นรายทักษะ "ของตัวเอง" เท่านั้น (Row-Level Security)
- แอดมิน — ดูบันทึกการตอบรวมทุกคน เพื่อใช้เทรนโมเดล
- ผู้เรียนทุกคนต้องให้ความยินยอม PDPA ก่อนระบบเริ่มเก็บบันทึก

### User Capabilities (กล่องซ้าย)
- รู้ว่าตัวเอง "แม่น" ทักษะไหนแค่ไหน ไม่ใช่แค่นับข้อถูก
- เห็นความแม่นแยกเป็นด้าน: คำศัพท์ / ไวยากรณ์ / วรรณยุกต์ / พยัญชนะ
- ค่าความแม่นอัปเดตทันทีหลังตอบแต่ละข้อ
- ระบบหยิบข้อที่ทักษะอ่อนมาให้ฝึกก่อนโดยอัตโนมัติ
- ดูพัฒนาการย้อนหลังเป็นกราฟตามช่วงเวลา
- ให้/ถอนความยินยอมการเก็บข้อมูลได้เอง
- ขอลบบัญชีและข้อมูลของตัวเองได้ตามสิทธิ PDPA

### Core Functions (กล่องขวา)
**Attempt Logging (Append-only)**
ทุกการตอบ = 1 บันทึก (ผู้ใช้ / ข้อ / ทักษะ / ถูก-ผิด / เวลาที่ใช้) ห้ามแก้-ห้ามลบ

**Q-Matrix Mapping**
ตารางจับคู่ข้อสอบ ↔ ทักษะ — ทุกข้อผูกทักษะอย่างน้อย 1 ตัว ไม่มีตารางนี้โมเดลไม่รู้ว่าจะอัปเดตอะไร

**Knowledge Component Registry**
คลังทักษะ: คำศัพท์ · ไวยากรณ์ 48 จุด (HSK1) / 129 จุด (สะสม HSK2) · วรรณยุกต์ · พยัญชนะ · จุดผิดคนไทย

**BKT Posterior Engine**
โหลดพารามิเตอร์ที่เทรนไว้ล่วงหน้า → คำนวณความแม่นใหม่ทุกครั้งที่ตอบ (เบา เร็ว ตอบสนองทันที)

**Offline Training Pipeline**
ส่งออกบันทึกการตอบ → เทรน pyBKT เป็นรอบ ๆ นอกระบบจริง → เขียนพารามิเตอร์กลับฐานข้อมูล

**Cold Start Handling**
ผู้ใช้ใหม่ยังไม่มีข้อมูล → ใช้ค่าตั้งต้นจากงานวิจัย แล้วค่อยแทนที่ด้วยค่าที่เทรนจากข้อมูลคนไทยจริง

**Model Evaluation (AUC + Ablation)**
แบ่งข้อมูล train/test วัด AUC (ช่วงปกติของงานสายนี้ ~0.70–0.85) + เทียบเวอร์ชันมี/ไม่มีทักษะ Thai-L1

### NOTIFICATION (แถบล่าง — ในแอป)
- แจ้งเมื่อทักษะใดเลื่อนขึ้นเป็น "แม่นแล้ว"
- แจ้งเมื่อพบทักษะที่ความแม่นตกลง → ชวนกลับไปฝึก
- แจ้งสถานะซิงก์ข้อมูล (ตอบค้างไว้ X ข้อ กำลังส่งขึ้นระบบ)
- แจ้งสถานะความยินยอม PDPA ก่อนเริ่มเก็บบันทึกครั้งแรก

### คอลัมน์ 2 — Q-Matrix
ผังข้อสอบ ↔ ทักษะ
- ทุกข้อผูกทักษะอย่างน้อย 1 ตัว

- เก็บภาพย้อนหลังไว้พล็อตพัฒนาการ
- ผู้ใช้ใหม่ใช้ค่าตั้งต้นจากงานวิจัย
- ใช้จัดลำดับว่าจะป้อนข้อไหนต่อ

### คอลัมน์ 4 — Adaptive Item Serving
จ่ายข้อตามจุดอ่อน
- หยิบข้อที่วัดทักษะซึ่งความแม่นต่ำก่อน
- กันข้อซ้ำจนผู้เรียนจำเฉลย
- ผสมข้อทวนกับข้อใหม่ในสัดส่วนที่เหมาะ
- ข้อที่ยังไม่อนุมัติจะไม่ถูกหยิบมาเด็ดขาด

- ตรวจทานพร้อมข้อสอบทุกข้อ

### คอลัมน์ 3 — Remediation Queue
คิวเจาะจุดอ่อน

- ไม่ขัดจังหวะบทเรียนหลัก
- เข้าจากปุ่มบนหน้าผลการเรียนได้ตลอด

### คอลัมน์ 4 — Content Governance

## สไลด์ 19 — ภาพรวมโมดูล

**หัวเรื่อง:** SPACED REPETITION (FSRS ENGINE)

### Platform Types
- ทำงานทั้งบนเครื่องผู้ใช้ (ทวนออฟไลน์) และบนเซิร์ฟเวอร์ (ตัวจริงของตาราง)
- ซิงก์สองทางอัตโนมัติเมื่อกลับมาออนไลน์

### User Permissions
- ผู้เรียน — ทวน ให้คะแนนความจำ และดูคิวของตัวเอง
- ระบบ — คำนวณวันทวนถัดไป (ผู้ใช้แก้ตารางเองไม่ได้)
- แอดมิน — ดูภาพรวมพฤติกรรมการทวนเพื่อวิเคราะห์

### User Capabilities (กล่องซ้าย)
- เห็นคิว "วันนี้ต้องทวนกี่คำ" ตั้งแต่เปิดแอป
- ทวนคำ "ตอนกำลังจะลืมพอดี" ไม่เสียเวลากับคำที่จำแม่นแล้ว
- ให้คะแนนความจำ 4 ระดับ: ง่าย / พอได้ / ยาก / ลืม
- เห็นทันทีว่าจะได้เจอคำนี้อีกครั้งเมื่อไหร่
- ทวนจนจบรอบได้แม้ไม่มีเน็ต แล้วข้อมูลไม่หาย
- ความคืบหน้าผูกกับบัญชี ใช้ข้ามเครื่องได้
- ทวนแทรกจากหน้าแรกได้ทุกเมื่อ ไม่ต้องรอเวลา

### Core Functions (กล่องขวา)
**FSRS v6 Scheduler**
คำนวณวันทวนถัดไปจากสถานะความจำรายการ์ด (ความยาก / ความคงทน / โอกาสจำได้)

**Daily Review Queue**
สร้างคิวทวนประจำวันจากการ์ดที่ถึงกำหนด เรียงตามความเร่งด่วน

**4-Level Rating**
ให้คะแนนความจำ 4 ระดับ พร้อมแสดงรอบทวนถัดไปของแต่ละตัวเลือกก่อนกด

**Offline Review (ts-fsrs)**
คำนวณตารางทวนในเครื่องได้เอง ทวนครบรอบได้โดยไม่ต้องมีสัญญาณ

**Outbox Sync**
เก็บผลทวนไว้ในเครื่องเมื่อออฟไลน์ → ส่งขึ้นเป็นชุดเมื่อออนไลน์ → ยึดค่าจากเซิร์ฟเวอร์

**Cross-Device Progress**
ผูกความคืบหน้ากับบัญชีผู้ใช้ เปลี่ยนเครื่องแล้วคิวทวนตามไปด้วย

**Retention Benchmark**
เทียบอัตราการจำได้กับวิธีตั้งตารางแบบเดิม (baseline) ตอนประเมินผลโครงงาน

### NOTIFICATION (แถบล่าง — ในแอป)
- การ์ดหน้าแรก "มี X คำถึงกำหนดทวนวันนี้"
- แจ้งเมื่อทวนครบคิว → ชวนเรียนคำใหม่ต่อ
- แจ้งเมื่อมีคำค้างสะสมหลายวัน (โทนชวน ไม่ตำหนิ)
- แจ้งสถานะซิงก์ผลทวนขึ้นระบบ

**Audio-Only Rule**
โจทย์ข้อฟังห้ามแสดงตัวจีน/พินอินของสิ่งที่ให้ฟัง — กันข้อสอบเฉลยตัวเอง

**Minimal Pair Drill**
ฝึกคู่เสียงที่ต่างกันจุดเดียว วินิจฉัย "หู" ได้โดยไม่ต้องใช้ระบบรู้จำเสียงพูด

**Dialogue Comprehension**
บทสนทนาสั้นเสียงล้วน → ตอบคำถามความเข้าใจ (ใครทำอะไร เมื่อไหร่)

**Playback Control**
ปรับความเร็ว เลือกเสียงผู้พูด และฟังซ้ำ — เปิดเฉพาะโหมดฝึกเท่านั้น

**Pre-generated Audio Bank**
คลังไฟล์เสียงสร้างล่วงหน้าทั้งคำและข้อสอบ + เก็บแคชในเครื่องเพื่อฟังออฟไลน์

### NOTIFICATION (แถบล่าง — ในแอป)
- แจ้งผลทันทีรายข้อในโหมดฝึก (ถูก/ผิด + เฉลยเสียง)
- แจ้งเมื่อผ่านด่านฝึกหูตามเกณฑ์ (~80%)
- แจ้งเมื่อระบบพบว่ายังแยกคู่เสียงใดไม่ได้ → แนะนำฝึกซ้ำ
- แจ้งเมื่อมีชุดฝึกหูแทรกในคิวประจำวัน

## สไลด์ 29 — ภาพรวมโมดูล

**หัวเรื่อง:** READING PRACTICE (PWA)

### Platform Types
- Next.js PWA — ข้อฝึกที่โหลดแล้วทำต่อได้ออฟไลน์
- รองรับการลาก-แตะบนมือถือ (แบบฝึกเรียงประโยค/จับคู่)

### User Permissions
- ผู้เรียน — ฝึกทำข้อ ดูเฉลย และดูสถิติของตัวเอง
- แอดมิน — สร้าง/แก้ข้อสอบอ่านเข้าคลังข้อสอบ
- ผู้อนุมัติเนื้อหา — อนุมัติหรือตีกลับทุกข้อก่อนถึงผู้เรียน

### User Capabilities (กล่องซ้าย)
- ฝึกข้ออ่านตามรูปแบบข้อสอบจริง (เลือกความหมาย / เลือกพินอิน / จับคู่ / ถูก-ผิด)
- ฝึกเรียงคำเป็นประโยคพร้อมโน้ตไวยากรณ์เมื่อเรียงผิด
- เล่นเกมจับคู่คำ–ความหมายเพื่อทวนแบบเร็ว
- เจอเฉพาะคำที่ตัวเองเรียนถึงแล้ว ไม่เจอคำเกินระดับ
- เห็นเฉลยและคำอธิบายทันทีรายข้อในโหมดฝึก
- เลือกฝึกเฉพาะประเภทข้อที่อยากซ้อมได้
- ฝึกต่อได้ทันทีจากจุดที่ค้างไว้

### Core Functions (กล่องขวา)
**HSK-Format Reading Items**
ข้ออ่านตามรูปแบบจริง: เลือกความหมาย · เลือกพินอิน · จับคู่ · ถูก-ผิด · เติมคำจากคลังคำ

**Sentence Ordering Drill**
เรียงคำเป็นประโยคด้วยการลาก/แตะ — ตรวจกับชุดคำตอบที่ยอมรับได้ พร้อมโน้ตไวยากรณ์

**Vocabulary Level Control (jieba)**
ตัดคำอัตโนมัติเพื่อยืนยันว่าทุกประโยคใช้เฉพาะคำในระดับที่กำหนด ก่อนเข้าคลังข้อสอบ

**Rule-Based Grading**
ตรวจด้วยการเทียบเฉลยเท่านั้น ถูกต้อง 100% — ไม่ใช้ AI ตัดสินคำตอบ

**Matching Game**
เกมจับคู่คำกับความหมาย ใช้ทวนคำในหมวดแบบเร็วและสนุก

**Instant Explanation**
เฉลยรายข้อทันทีในโหมดฝึก พร้อมเหตุผลว่าทำไมตัวเลือกอื่นผิด

**Item Bank Workflow**
ข้อทุกข้อผ่านวงจร ร่าง → รออนุมัติ → อนุมัติ → (ตีกลับ) → ระงับ ก่อนถึงผู้เรียน

### NOTIFICATION (แถบล่าง — ในแอป)
- แจ้งผลทันทีรายข้อ + เหตุผลของตัวเลือกที่ผิด
- แจ้งโน้ตไวยากรณ์เมื่อเรียงประโยคผิดลำดับ
- แจ้งเมื่อฝึกครบชุด → ชวนทำควิซท้ายหมวด
- แจ้งเมื่อพบรูปแบบความผิดซ้ำ → แนะนำแบบฝึกเจาะจุด

### Platform Types

- ตรวจคำตอบและคิดคะแนนฝั่งเซิร์ฟเวอร์ (ไม่ส่งเฉลยไปเครื่องผู้ใช้ในโหมดสอบ)

### User Permissions
- ผู้เรียน — ทำควิซและสอบจำลอง ดูใบรายงานผลของตัวเอง
- แอดมิน — ประกอบชุดข้อสอบ ดูสถิติภาพรวม
- ผู้อนุมัติเนื้อหา — อนุมัติข้อทุกข้อที่จะถูกสุ่มเข้าชุดสอบ

### User Capabilities (กล่องซ้าย)
- ทำควิซท้ายหมวด 10 ข้อ (ฟัง 4 + อ่าน 4 + เขียน 2) ผ่านที่ ≥ 7/10
- ทำสอบจำลองเต็มชุด ฟัง 20 + อ่าน 20 ข้อ แบบจับเวลาเหมือนสอบจริง
- รู้คะแนนแบบเกณฑ์จริง — สเกล 200 คะแนน ผ่านที่ 120
- ทำทีละข้อ มีแถบคืบหน้า และย้อนกลับไปแก้ได้ (เฉพาะพาร์ตอ่าน)
- รีเฟรชหรือหลุดกลางคันแล้วกลับมาทำต่อได้ คำตอบไม่หาย
- ดูใบรายงานผลแยกรายทักษะ + จุดผิดคนไทยที่เจอ
- เทียบคะแนนกับครั้งก่อนเพื่อดูพัฒนาการ
- สอบใหม่ได้ไม่จำกัดในโหมดฝึก (ชุดวัดผลถูกล็อกไว้)

### Core Functions (กล่องขวา)
**Category Quiz (10 ข้อ)**
สุ่มจากคลังข้อสอบของหมวดนั้น ผ่าน ≥ 7/10 → แนะนำหมวดถัดไป (ไม่ล็อกทางเดิน)

**Full Mock Exam (40 ข้อ)**
ประกอบชุดฟัง 20 + อ่าน 20 ตามโครงสร้างข้อสอบจริง จับเวลาทั้งชุด

**Exam Mode Rules**
เสียงเล่น 2 รอบ · ห้ามหยุด · ห้ามย้อนข้อฟัง · ไม่โชว์เฉลยระหว่างทำ

**Real Scoring (200 / 120)**
คิดคะแนนตามสเกลจริง 200 คะแนน เกณฑ์ผ่าน 120 พร้อมสถานะผ่าน/ไม่ผ่าน

**Session Persistence**
บันทึกสถานะการสอบตลอดเวลา — ปิดแอปหรือรีเฟรชแล้วกลับมาทำต่อได้

**Result Report**
ใบรายงานผลแยกคะแนนรายทักษะ ชี้จุดผิดคนไทยที่เจอ และเทียบกับครั้งก่อน

**Pre / Post Assessment**
ชุดวัดผลก่อน-หลังใช้งาน สำหรับวัดพัฒนาการของผู้เรียน (gain score)

### NOTIFICATION (แถบล่าง — ในแอป)
- แจ้งเตือนเวลาคงเหลือระหว่างสอบ (ช่วงท้ายเน้นชัด)
- แจ้งผลทันทีเมื่อส่งข้อสอบ: คะแนน + ผ่าน/ไม่ผ่าน
- แจ้งเมื่อผ่านควิซครบ 5 หมวด → ชวนทำสอบจำลองเต็มชุด
- แจ้งว่ามีข้อสอบค้างอยู่ระหว่างทำ → ปุ่มกลับไปทำต่อ

**คำโปรย:** กระจกสะท้อนผู้เรียน — บอกว่าตอนนี้อยู่ตรงไหน อะไรแม่นแล้ว และควรทำอะไรต่อ

### คอลัมน์ 1 — Skill Mastery
ความแม่นรายทักษะ
- กราฟแยกด้าน: คำศัพท์ / ไวยากรณ์ / เสียง / วรรณยุกต์
- อัปเดตหลังทุกการฝึกและการสอบ
- ทักษะที่แม่นแล้ว vs ที่ต้องเจาะ
- ดูพัฒนาการย้อนหลังตามช่วงเวลา
- กดที่ทักษะเพื่อดูรายละเอียดต่อได้

### คอลัมน์ 2 — Category Progress
ความคืบหน้ารายหมวด
- คำที่เรียนแล้วในแต่ละหมวด
- คะแนนควิซดีที่สุดของหมวดนั้น
- หมวดที่ค้างและหมวดที่ยังไม่เริ่ม
- แถบคืบหน้ารวมทั้ง 300 คำ
- ทางลัดกลับไปเรียนต่อจุดที่ค้าง

### คอลัมน์ 3 — Exam Readiness
ความพร้อมสอบ
- ตัวเลขความพร้อมโดยประมาณ
- แสดงคู่เกณฑ์ผ่านจริง 120/200 เสมอ
- อิงคะแนนสอบจำลองล่าสุด + ความแม่นรายทักษะ
- สื่อสารตรงไปตรงมา ไม่เคลม "โอกาสสอบผ่าน"
- แนะนำสิ่งที่ควรเจาะก่อนสอบจริง

### คอลัมน์ 4 — Weakness Panel
จุดอ่อนที่ต้องเจาะ
- จุดผิดคนไทยที่พบบ่อยที่สุด
- เรียงตามความถี่และความสำคัญ
- คำอธิบายสั้นว่าพลาดเพราะอะไร
- ปุ่มเข้าแบบฝึกเจาะจุดทันที
- อัปเดตทุกครั้งที่มีผลใหม่

## สไลด์ 41 — Function (2/2)

**หัวเรื่อง:** Function
**หัวเรื่องย่อย:** PROGRESS DASHBOARD (B2C + ADMIN)
**คำโปรย:** ส่วนที่ทำให้ผู้เรียนอยากกลับมา และส่วนที่ทำให้ทีมดูแลระบบได้จริง

### คอลัมน์ 1 — Activity & Streak
สถิติการฝึก
- จำนวนวันต่อเนื่อง (streak)
- จำนวนข้อที่ทำและเวลาที่ใช้
- ปฏิทินการเข้าใช้งานย้อนหลัง
- สรุปประจำสัปดาห์
- โทนให้กำลังใจ ไม่ตำหนิเมื่อขาดช่วง

### คอลัมน์ 2 — Daily Plan
แผนรายวัน
- เป้าหมายคำต่อวันที่ตั้งไว้
- สิ่งที่ต้องทำวันนี้: ทวน → เรียนใหม่ → ฝึก
- ปุ่มเดียวพาไปทำงานถัดไปที่ควรทำ
- ปรับเป้าหมายได้ตลอดในโปรไฟล์
- คำนวณวันที่จะเรียนครบใหม่ทันทีเมื่อปรับ

### คอลัมน์ 3 — Account & Privacy
บัญชีและความเป็นส่วนตัว
- โปรไฟล์และเป้าหมายการสอบ
- แก้คำตอบตอนสมัครย้อนหลังได้
- จัดการความยินยอมการเก็บข้อมูล
- ขอลบบัญชีและข้อมูลของตัวเอง
- เห็นได้เฉพาะข้อมูลของตัวเองเท่านั้น

### คอลัมน์ 4 — Admin Overview
ภาพรวมหลังบ้าน
- คิวเนื้อหารอตรวจ (คำแปล/ข้อสอบ)
- จำนวนข้อในคลังแยกตามหมวดและสถานะ
- ปริมาณข้อมูลการตอบที่เก็บได้
- ความคืบหน้าของแผนงานทั้งโครงงาน
- แจ้งเตือนเมื่อข้อในหมวดเหลือน้อยกว่าขั้นต่ำ

## สไลด์ 42 — Site Map

**หัวเรื่อง:** PROGRESS DASHBOARD Site Map
**แถบนำทาง:** หน้าแรก | ผลการเรียน | จุดอ่อน | โปรไฟล์ | หลังบ้าน

### กล่อง 1 — Home (หน้าแรก)
- ปุ่มใหญ่ "สิ่งที่ควรทำต่อ"
- แถบเป้าหมายรายวัน + streak
- การ์ดคำรอทวน
- สรุปความพร้อมสอบแบบย่อ

### กล่อง 2 — Progress (ผลการเรียน)
- กราฟความแม่นรายทักษะ
- ความคืบหน้ารายหมวด
- ประวัติการฝึกและการสอบ
- ตัวเลขความพร้อมสอบ + เกณฑ์ 120/200

### กล่อง 3 — Weakness (จุดอ่อน)
- จุดผิดคนไทยที่พบบ่อย
- คำที่มักตอบผิดซ้ำ
- ปุ่มเข้าแบบฝึกเจาะจุด
- ความคืบหน้าของแต่ละจุดอ่อน

### กล่อง 4 — Profile (โปรไฟล์)
- เป้าหมายระดับที่จะสอบ + วันสอบ
- จำนวนคำต่อวัน
- การตั้งค่าเสียงและการแจ้งเตือน
- ความยินยอมข้อมูล / ลบบัญชี

### Sub-Pages (หน้าเสริม)
- หน้าสรุปรายสัปดาห์
- หน้าแผนงานโครงงาน (roadmap) สำหรับนำเสนอความคืบหน้า
- หน้าหลังบ้าน: คิวรอตรวจ + สถิติคลังข้อสอบ

### แถบล่าง — Tech Stack
- Next.js (Frontend / PWA)
- Recharts (กราฟทั้งหมด)
- FastAPI (ค่าความแม่น + รายงานวินิจฉัย)
- Supabase PostgreSQL + RLS (ข้อมูลรายผู้ใช้)

### แถบล่าง — Module Functions
- Skill Mastery Chart
- Category Progress
- Exam Readiness Indicator
- Weakness Panel + Review Queue
- Streak & Admin Overview

### แถบล่าง — Library / Integration
- Zustand (สถานะในแอป)
- Dexie (ข้อมูลออฟไลน์)
- Supabase Auth (บัญชีผู้ใช้)
- Vercel / Cloudflare Pages (โฮสต์เว็บ) · Hugging Face Spaces (โฮสต์ระบบประมวลผล)
